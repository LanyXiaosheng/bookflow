## 九、从以上爆款提炼的写作铁律

### 开头三不原则
1. **不介绍主角**——不写"我叫XX，今年XX岁"
2. **不交代背景**——不写"那是一个XX的日子"
3. **不铺设定**——不写"在这个世界里，修仙者分为XX等级"

### 开头三必须
1. **第一句必须有事件或状态**（"他把合同推到我面前"、"我在幽冥宗卧底五年"）
2. **前三句必须包含一个"不对劲"**（让读者产生"然后呢？"的冲动）
3. **前五句必须让读者知道主角的处境有多荒诞/危险/委屈**

### 开头节奏模板（从真实爆款归纳）

**模板A：直接冲突入场**
> [具体动作/对话] + [立刻的情感/物理反应] + [读者产生的问号]
> 例："去妇科看病，遇到了前男友" → 尴尬场景+好奇后续

**模板B：反常数字/事实**
> [一个荒谬的事实陈述] + [更荒谬的对比] + [主角的一句反应]
> 例："年终奖0.5元，同事400万" → 数字对比+愤怒驱动

**模板C：童言揭秘**
> [孩子说了一句话] + [大人的恐惧/震惊反应] + [悬念挂起]
> 例："妈妈在衣柜藏了37天" → 童言无忌+恐怖悬疑

**模板D：身份错位**
> [日常场景] + [突然发现一个不该出现的人/物] + [认知翻转]
> 例："前男友是妇科医生" → 社死+禁忌感

**模板E：病娇暴露**
> [表面正常的关系描述] + [一个细节暴露真面目] + [读者的"危！"感]
> 例："他每周炖骨头汤，我才知道他从不去菜市场" → 细思极恐

### 标题公式（从真实爆款归纳）
| 类型 | 公式 | 例子 |
|------|------|------|
| 事件+反转 | 做了X，结果Y | 被丢在高速上的妻子 |
| 身份暴露 | 隐藏身份+意外曝光 | 摸了校花尾巴后才知道全校就我一个人类 |
| 数字冲击 | 极端对比 | 年终奖0.5元同事400万 |
| 反常行为 | 本该X却做了Y | 我都化神了你还让我给筑基认错 |
| 时间+转折 | X年后突然 | 当了三年金丝雀，金主忽然说要结婚了 |
| 设问式 | 极端处境+反问 | 杀妻证道杀到我头上了，不知道我是邪修吗 |
| 病娇揭示 | 日常+一个恐怖细节 | 男友炖了三月骨头汤，我才知道他从不去菜市场 |
| 童言炸弹 | 孩子说的话+成人世界真相 | 女儿喊妈妈在衣柜藏了37天 |
