# 现言破镜重圆

## 赛道定义

曾深爱的两人因误会、隐瞒、外力或一方的骄傲而错过、离婚或分开，多年后重逢，在悔恨与心动中重新靠近，最终解开心结、重归于好。

## 核心公式

`[相爱的两人] + [错过/离婚的真相] + 重逢后 [一方追悔/一方设防] + 揭开 [当年误会] + 重新在一起`

## 常见死局

- 当年因误会离婚，各自隐忍多年
- 一方为对方牺牲，却被误解为背叛
- 孩子/家庭变故成为无法言说的隔阂
- 骄傲让两人谁都不肯先低头
- 重逢时对方身边已有他人

## 常见反杀（破冰点）

- 当年真相被第三方揭穿
- 一方发现对方一直默默守护
- 孩子成为重新连接的纽带
- 生死关头才说出口的真心话
- 一方放下骄傲主动挽回

## 标签体系

| 层级 | 推荐标签 |
|------|----------|
| 主分类 | 虐心婚恋 |
| 情节 | 破镜重圆、追妻火葬场、先婚后爱、暗恋 |
| 角色 | 前夫、前妻、总裁、初恋 |
| 情绪 | 虐、心疼、意难平、甜 |

## 选题方向

- 离婚三年后，才知道当年的孩子是他的
- 她签字那天他在国外，回来时人去楼空
- 重逢在葬礼上，他才读懂她当年的信
- 当年拉黑他，是为了替他挡下一场灾祸
- 他追悔莫及时，她已经准备嫁给别人
