# 现言真假千金

## 赛道定义

豪门认亲，真千金流落在外自立自强，假千金鸠占鹊巢享尽资源。真相揭开时，真千金早已凭本事另立山头，反而是全家追着来道歉、假千金原形毕露。

## 核心公式

`[抱错/走失] + 假千金 [占据身份享资源] + 真千金 [底层逆袭成大佬] + 认亲时她先 [不稀罕/打脸]`

## 常见死局

- 从小被抱错，在贫苦家庭长大
- 假千金处处打压、抢功、泼脏水
- 全家偏心假千金，不信真千金
- 认亲后被要求「懂事」「让一让」
- 真千金的成就被说成运气/心机

## 常见反杀

- 真千金的真实身份/事业先曝光
- 假千金的伪装先被拆穿
- 真千金先甩出证据，全家打脸
- 真千金先转身，不认这门亲
- 假千金想抢的东西，本就是真千金的

- 认亲宴上被要求让出房间，她甩出自己名下的房产证

- 全家逼她给假千金道歉，她转身宣布断绝关系
- 真千金被说高攀，其实豪门才高攀了她
