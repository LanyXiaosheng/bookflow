# 古言宫斗权谋

## 赛道定义

女主入宫/入朝堂，身处后宫或世家倾轧的漩涡，凭借心计、隐忍与布局，一步步扳倒仇敌、站上权力顶端，护住自己想护的人。

## 核心公式

`[被迫卷入宫廷/朝堂] + [仇敌步步紧逼] + 她先 [布局隐忍] + 关键时刻 [一击翻盘]`

## 常见死局

- 家族获罪，被迫入宫为奴/为妃
- 被高位妃嫔/权臣构陷
- 帝王多疑，恩宠即是枷锁
- 身边人被收买、被威胁
- 一步走错满盘皆输

## 常见反杀

- 先握住对方的把柄
- 先在帝王面前铺好证据
- 先策反对方的心腹
- 先借刀杀人，让仇敌内斗
- 先示弱麻痹，再雷霆一击

- 冷宫弃妃手握先帝密诏，一朝翻盘
- 被构陷失宠那夜，她反手掀了对方的老底
- 世家嫡女入宫，替满门讨一个公道
- 帝王赐死当日，她亮出通敌铁证反杀
- 姐妹反目，庶妹步步紧逼终被反噬
