# 悬疑规则怪谈

## 赛道定义

主角进入一个有诡异规则的封闭环境（医院/工厂/宿舍/小区），必须遵守规则才能活下来，同时逐步发现规则背后的真相。

## 核心公式

`进入 [封闭环境] + 发现 [诡异规则] + 违反规则的人 [消失/死亡] + 主角发现 [规则背后的真相]`

## 常见死局

- 夜班/值班遇到不该存在的东西
- 新环境的规则越来越离谱
- 身边的人一个个消失
- 发现自己可能也是「规则」的一部分

## 常见反转

- 规则保护的不是活人
- 制定规则的人已经死了
- 主角自己就是规则的来源
- 所谓的「安全区」才是最危险的地方

## 标签体系

| 层级 | 推荐标签 |
|------|----------|
| 主分类 | 悬疑惊悚 |
| 情节 | 规则怪谈、反转、烧脑、细思极恐 |
| 角色 | 普通人、值班员、新人、调查者 |
| 情绪 | 紧张、恐惧、震惊 |
| 背景 | 医院、工厂、宿舍、封闭空间 |

## 选题方向

- 夜班/值班遇到多出来的人/楼层/床位
- 考勤机/系统里出现不该存在的名字
- 规则说不能做的事，有人做了之后消失
- 查失踪案，发现失踪的人是自己
- 时间循环/记忆错位类
