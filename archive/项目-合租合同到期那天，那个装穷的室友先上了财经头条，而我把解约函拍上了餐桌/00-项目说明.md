# 项目说明｜合租合同到期那天，那个装穷的室友先上了财经头条，而我把解约函拍上了餐桌

## 项目定位

- 平台方向：番茄短篇
- 题材：现言 / 同居错位 / 甜宠壳 / 身份掉马 / 清醒切割
- 核心卖点：女主和“穷室友”合租三个月，合同到期那天才知道对方先上了财经头条；她没有感动，而是先把解约函拍上餐桌
- 当前阶段：`2026-04-21` 首轮立项

## 一句话故事

合租合同到期这天，许枝意刚准备和那个天天蹭她电饭煲、装穷说创业失败的室友说再见，就在财经头条上看见了他的脸。原来所谓落魄室友江叙白，是刚完成并购案的新贵。所有人都以为她会被这场掉马甜到，许枝意却先把解约函拍上餐桌。因为她最讨厌的，从来不是穷，而是骗。

## 当前阶段目标

第一阶段先完成：

1. 钉死财经头条掉马和餐桌解约双钩子
2. 完成 `00 / 02 / 03 / 04 / 07` 五件套
3. 把它做成 `甜宠壳 + 身份位争夺` 的新样板，而不是普通霸总马甲文

## 读点判断

- `装穷室友` 自带高反差
- `财经头条掉马` 是极直给的公开翻面
- 女主第一反应是切割，不是心动，能把旧甜宠壳拉出新鲜感

## 爽点 / 爆点方向

- 开头就给财经头条和女主解约动作
- 中段补齐同居期间的隐瞒、资源试探和身份错位
- 后段让男主从“我可以解释”变成“你先把边界给我补上”
- 结尾回本点是女主先定规矩，不是被豪门身份吓住
