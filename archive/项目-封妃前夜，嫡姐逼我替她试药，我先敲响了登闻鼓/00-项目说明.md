# 项目说明｜封妃前夜，嫡姐逼我替她试药，我先敲响了登闻鼓

## 项目定位

- 平台方向：番茄短篇
- 题材：女频古言 / 宫斗宅斗 / 姐妹反杀 / 公开翻案 / 登闻鼓反打
- 核心卖点：嫡姐即将封妃，沈家上下都逼庶妹替她试“安胎药”，说是为了皇家血脉。女主前世就是死在这碗药里，这一世她没再咽下去，而是端着药碗、带着脉案，直接去宫门外敲响登闻鼓。

## 一句话故事

封妃前夜，沈家让沈知微替嫡姐试安胎药，说贵妃娘娘的身子不能有半点差池。前世她信了，喝下那碗药，第二天就被扣上“冲撞龙胎、偷换药方”的罪名乱棍打死。这一世，她端着那碗还冒着热气的药，提着被换过的脉案，直接去宫门外敲响登闻鼓。她倒要看看，等尚药局、内廷和满朝命妇一起看见这碗药时，沈家和未来贵妃还怎么踩着她进宫。

## 读点判断

- `封妃前夜` 自带高围观和高代价，读者一眼就懂这事闹大了
- `逼她试药` 是直接羞辱和生命威胁，不是轻飘飘误会
- `登闻鼓` 是古言里天然的公开场，读者会想看她怎么把私事打成官面丑闻
- `药碗 + 脉案 + 尚药局` 都是硬物件，不靠空吵推进

## 为什么这条比“皇城夜禁后，卖长生丹的人开始挨个失踪”更适合老番茄短篇读者

### 上一条的问题

- 冷概念太多：皇城夜禁、长生丹、黑市摊贩失踪，进戏慢
- 读者第一秒不知道该站谁、恨谁、替谁出气
- 更像志怪悬疑，不像番茄女频短篇最稳的“压迫即反打”结构

### 这条的优势

- 第一屏就知道谁被欺负、谁在逼她、她要怎么翻桌
- 有家族压迫、有姐妹踩头、有宫门公开场，读者代入快
- 爽点是连续公开翻车，不需要读者耐心等谜底

## 爽点 / 爆点方向

- 开局就是封妃前夜被逼试药
- 女主不喝药，直接端药碗去敲登闻鼓
- 第一炸是药方和脉案对不上
- 第二炸是嫡姐根本没怀龙嗣
- 第三炸是沈家和太医联手造假
- 结尾回本点不是“女主得宠”，而是“她活下来，也把这条踩着她进宫的路亲手砸断”
