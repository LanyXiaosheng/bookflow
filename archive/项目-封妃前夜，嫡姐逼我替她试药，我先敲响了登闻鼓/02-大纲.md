# 大纲｜封妃前夜，嫡姐逼我替她试药，我先敲响了登闻鼓

## 故事定位

- 古言女频短篇
- 路线：前世惨死 -> 重生当夜掀桌 -> 宫门公开场 -> 脉案翻车 -> 假孕/假脉案/太医串局 -> 沈家与嫡姐封妃路断 -> 女主保命回本

## 核心设定

- 女主：沈知微，庶女，亡母出身医家，自幼会辨药识脉
- 嫡姐：沈明珠，沈家嫡女，借“有孕”将被抬入宫封妃
- 反派链：父亲沈承礼 + 继母王氏 + 嫡姐沈明珠 + 买通的太医
- 核心物件：药碗、药方、脉案、尚药局复脉记录、登闻鼓

## 一句话主线

前世，沈知微死在替嫡姐试药的那碗安胎药里；这一世，她端着药碗敲响登闻鼓，让整件原本要被沈家悄悄压下去的“试药夜”，变成了一场谁都撤不掉的公开翻案。

## 主要冲突

### 外部冲突

1. 沈家要用她的命替嫡姐封妃铺路
2. 嫡姐所谓龙胎和安胎脉案存在巨大漏洞
3. 一旦敲登闻鼓，女主面对的不是一家人，而是整个内廷和官面压力

### 内部冲突

1. 女主前世死于“听话”，这一世必须在第一步就彻底不退
2. 她不是只想保命，还要把“她们踩着她上位”的路掀掉
3. 她必须决定，是只证明药有问题，还是把假孕和欺君一并翻出来

## 故事推进

### 第一段：封妃前夜，药碗压脸

- 嫡姐即将封妃，沈家上下逼女主试药
- 女主认出药碗和药方里的杀机
- 她端药直奔宫门，敲响登闻鼓

### 第二段：宫门第一炸，药方和脉案对不上

- 禁军、内侍、尚药局先后到场
- 女主当众指出药中有孕妇禁用药
- 沈家赶来压事，想把事情说成庶女发疯

### 第三段：第二炸，嫡姐根本没怀

- 尚药局复脉，发现脉象不对
- 女主抛出前世记忆里的关键药渣和旧脉案漏洞
- 假孕和封妃局开始松动

### 第四段：第三炸，太医和沈家联手造假

- 太医私改脉案、收沈家银票的证据被翻出
- 沈家真正目的不是保胎，是借“有孕封妃”抬全族
- 父亲和继母试图弃车保帅，把锅往女主身上甩

### 第五段：结局回本

- 嫡姐封妃路断，假孕欺君坐实
- 太医和沈家一并翻车
- 女主洗清前世“冲撞龙胎”“偷换药方”的污名
- 她拿回亡母留下的医书与药铺，不再留在沈家当垫脚石

## 回本点设计

- 她没喝那碗药
- 她没再替嫡姐背锅
- 她让嫡姐最想体面进宫的那一夜，变成最难看的那一夜
- 她争回来的不只是命，还有以后再也不替别人试毒的人生
