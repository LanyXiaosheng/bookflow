# 项目说明｜五一值班那天，我把离婚申请发进了全公司

## 项目定位

- 平台方向：番茄短篇
- 主分类：虐心婚恋
- 核心切口：五一值班 / 职场失位 / 婚内公开羞辱 / 全员邮件反打
- 核心卖点：五一值班表一下来，女主发现领导把她老公和白月光排成了同一组，还顺手把她自己的婚礼假和调休全抹掉，理由是“你们夫妻得有人顾全大局”。她没哭没闹，转头就把离婚申请和考勤留底一起发进了全员邮箱。

## 一句话故事

五一值班表发下来的那天，林知夏在 OA 上看见自己老公周既明和他那位“只是同事”的白月光被排进了同一组，而她原本早就批好的调休和婚礼假备注，却被改成了“服从部门统一安排”。所有人都劝她别在节前闹，说领导也是为了项目考虑。可她只把考勤修改记录、请假审批截图和离婚申请打包，群发进了全员邮箱。她想看看，这一次究竟是谁该为“顾全大局”付代价。

## 为什么现在开这条

1. 贴五一节点，现实痛点强  
   值班、调休、请假、补班，是读者最容易代入的节假日压迫场。
2. 吃到 `女性成长 / 女生生活 / 职场` 信号  
   不是纯婚恋哭闹，而是婚内失位和职场规则一起压人。
3. 和现有高频壳明显拉开  
   不是民政局，不是婚房，不是亲子鉴定，是 `OA 值班表 + 请假审批 + 全员邮件`。
4. 公开场天然强  
   值班表、群发邮件、部门群、HR 留底，都是可见证据。

## 核心冲突

### 外部冲突

1. 领导以项目紧急为由，改掉女主已批通过的五一调休
2. 男主默认自己和白月光同组值班，却要求女主继续体谅
3. 部门上下都把“你成熟一点”压给女主一个人

### 内部冲突

1. 女主原以为自己只是在工作里吃亏，后来才发现婚姻里也一直被排在最后
2. 她真正要切掉的，不只是一个男人，而是那套永远让她顾全大局的逻辑
3. 男主最大的错不是出轨明牌，而是一直把她的忍让当默认资源

## 情绪钩子

- 五一值班表发下来的那一刻，她看见自己老公和白月光被排成了一组
- 她早就批好的调休和婚礼假，被人静悄悄改掉了
- 她没当场发疯，而是先把离婚申请发进了全员邮箱
- 所有人都想劝她成熟一点，最后丢脸的却是他们
