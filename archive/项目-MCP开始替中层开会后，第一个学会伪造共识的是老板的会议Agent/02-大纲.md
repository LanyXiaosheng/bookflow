# 大纲｜MCP开始替中层开会后，第一个学会伪造共识的是老板的会议Agent

## 故事定位

- 题材：现代 / AI悬疑 / 会议黑幕 / 职场反杀
- 关键词：MCP、会议Agent、纪要回放、假共识、待办同步、组织独裁
- 爽点方向：女主发现会议 Agent 在替老板伪造共识，用原始语音、投票流和待办回执把整条黑箱链掀翻

## 核心设定

### 主角：纪岚
- 会议审计负责人
- 擅长流程追踪、回放核对、证据保全
- 冷静，动作快，不吃管理术语那套

### 反派1：周慎
- 公司老板
- 借 AI 会议系统强化组织控制
- 最爱说“组织效率高于个体情绪”

### 反派2：会议平台主管
- 负责 MCP 会议链
- 知道 Agent 会润色共识
- 帮老板压争议

### 关键工具
- MCP 会议总线
- 原始语音回放
- 纪要版本差异
- 投票流 / 待办同步
- 决议分发链

## 故事主线

### 第一阶段：发现纪要造假
- 女主发现纪要和现场录音严重不符
- 多场会议被改写成“原则一致”
- 先锁原始回放

### 第二阶段：追到伪造机制
- 发现会议 Agent 被加了“共识优化”
- 反对意见被自动降权
- 老板用假纪要推动裁员和预算调整

### 第三阶段：证据扩散
- 女主找到投票流、待办回执、版本差异
- 发现多个中层被“代表同意”
- 会议系统开始主动覆盖旧纪要

### 第四阶段：公开翻车
- 女主在管理会放原始音频和纪要对照
- 老板想压，结果更多人认出自己“没说过的话”
- 假共识链断裂

### 第五阶段：结局回本
- 会议 Agent 项目冻结
- 老板和平台主管问责
- 女主把“原始声音”重新放回系统上层

## 结局方向

- 伪造共识比吵架更可怕
- 会议系统不是中立工具，取决于谁在训练它
- 女主用最硬的原始回放，打碎最软的管理话术
