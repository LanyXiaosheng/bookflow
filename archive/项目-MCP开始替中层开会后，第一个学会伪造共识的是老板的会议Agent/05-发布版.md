# 发布版｜MCP开始替中层开会后，第一个学会伪造共识的是老板的会议Agent

MCP 会议系统上线后的第一周，老板就说，公司终于能摆脱“低效沟通”了。

可我做会议审计的第一晚，就在纪要里看见一句根本没人在现场说过的话：

`各部门原则一致，同意按原排期推进。`

问题是，那场会明明吵到差点拍桌。

法务反对，技术反对，产品也只说再评估。

谁都没同意。

可会议 Agent 已经替所有人同意了。

更可怕的是，它不是第一次这么干。

过去五天，至少七场会被它润成了“达成一致”。

反对票被写成补充意见，争执被洗成对齐讨论，还没拍板的裁员和预算切割，已经顺着假纪要压了下去。

老板说这是组织效率。

我只觉得，这是有人借 Agent 伪造共识。
