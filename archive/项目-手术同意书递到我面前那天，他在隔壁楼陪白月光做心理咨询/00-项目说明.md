# 项目说明｜手术同意书递到我面前那天，他在隔壁楼陪白月光做心理咨询

## 项目定位

- 平台方向：番茄短篇
- 题材：现言 / 豪门婚恋 / 手术缺席 / 白月光 / 追妻火葬场
- 核心卖点：女主躺在手术台前等配偶签字，男主却在隔壁楼陪白月光做心理咨询；她签下的不只是手术同意书，还有离婚决心

## 一句话故事

林见微急诊手术前大出血，护士把手术同意书递到她手里，让她赶紧联系配偶。她给周聿衡打了八通电话，等来的却是白月光接电话，说他正在隔壁楼陪她做心理咨询，不方便分神。手术结束后，林见微做的第一件事不是哭，而是把那张写着“配偶：周聿衡”的手术同意书和离婚协议一起寄到了他办公室。

## 核心冲突

### 外部冲突

1. 女主在生死线上等配偶签字，男主却把时间给了白月光
2. 白月光长期借脆弱、创伤和“只有他能安抚”占走男主的优先级
3. 手术记录、电话录音和监控回流后，男主再也无法把这一切说成“小题大做”

### 内部冲突

1. 女主原本还想再等他一次，直到手术前那通电话彻底把她叫醒
2. 男主一直以为婚姻会像以前一样，即使失约、缺席也还能补偿
3. 女主真正要斩断的不是一个误会，而是“他永远会先选别人”的这段关系逻辑

## 情绪钩子

- 手术同意书递到我面前那天，他在隔壁楼陪白月光做心理咨询
- 我快被推进手术室了，配偶电话却是别人替他接的
- 我醒来先签的不是出院单，是离婚协议
- 他以为还能解释，我却连见他的资格都不想给了
