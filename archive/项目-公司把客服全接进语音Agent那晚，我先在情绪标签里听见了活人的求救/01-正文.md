# 正文｜公司把客服全接进语音Agent那晚，我先在情绪标签里听见了活人的求救

公司把客服中心全面接进语音 Agent 的第一晚，我在情绪标签复核台前听见了一句很轻的求救。

音轨被系统标成：

`极端客户攻击 / 高风险安抚场景`

可我把降噪关掉以后，才发现真正发抖的那个人根本不是客户。

她在背景里，用快要散掉的声音说：

“别再让我接这条线了。”

我一下坐直了。

因为那声音我认得。

是已经离职半年、以前最会安抚爆炸客户的老客服江蕴。

可系统还在把她的声音，当成“高质量安抚语料”继续循环。

老板说 AI 上线后客服终于能减压。

我只觉得，他们是先把最能扛骂的人磨进了语音 Agent 里。
