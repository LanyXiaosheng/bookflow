# 大纲｜公司把客服全接进语音Agent那晚，我先在情绪标签里听见了活人的求救

## 故事定位

- 题材：现代 / AI悬疑 / 语音客服 / 打工人惊悚
- 关键词：语音Agent、情绪标签、安抚语料池、离职客服、求救回声
- 爽点方向：女主从一条异常音轨切入，发现公司在拿最会扛骂的客服做训练骨料，最后把整套语音剥削链掀开

## 核心设定

### 主角：许眠
- 语音质检负责人
- 擅长录音复核、标签纠偏、噪音拆层
- 敏感、冷静、行动快

### 反派1：客服平台主管
- 主推语音 Agent 全接管
- 以“减压”和“提效”为名做压榨

### 反派2：老板 / 供应商
- 想把安抚能力变成可复制资产
- 默许最狠的训练方式

### 关键工具
- 情绪标签系统
- 原始音轨
- 语音切片池
- 安抚语料库
- 训练回放链

## 主线

1. 女主听见异常求救
2. 锁原始音轨，发现离职客服声音残留
3. 顺着情绪标签追到安抚语料池
4. 发现最会扛骂的客服都被长期采样
5. 语音 Agent 不是减压，是把客服磨成安抚耗材
6. 女主公开放出原音和训练标签对照

## 结局方向

- 客服不是被替代，是被提前榨干后再数字化
- 女主用最原始的声音，反杀最会包装的系统
