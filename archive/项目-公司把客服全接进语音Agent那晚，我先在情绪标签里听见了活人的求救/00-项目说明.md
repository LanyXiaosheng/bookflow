# 项目说明｜公司把客服全接进语音Agent那晚，我先在情绪标签里听见了活人的求救

## 项目定位

- 平台方向：番茄短篇
- 题材：现代 / AI悬疑 / 语音客服 / 职场压榨
- 核心卖点：公司把客服中心全面接进语音 Agent，号称情绪识别和自动安抚全面升级。女主做语音质检，却先在“客户情绪标签”里听见一个根本不该属于客户的求救声。

## 一句话故事

许眠负责语音质检与情绪标签校验。老板说，语音 Agent 上线后，客服不用再熬夜扛骂，系统会替大家接住最差的情绪。可许眠在第一晚复核录音时，听见一条被标成“极端客户攻击”的音轨里，真正求救的人根本不是客户，而是一个被长期接入训练链、声音已经快被磨烂的老客服。原来公司不是在用 AI 减压，而是在把最会扛骂的人磨成永不下线的安抚语料。

## 当前阶段目标

1. 正文首稿
2. 故事大纲
3. 10章细纲
4. 爆点节奏表
5. 发布版 / 配套版

## 读点判断

- 语音客服 + 情绪标签天然有“听见不该听见的东西”的恐怖感
- 客服被接进训练链，社畜共鸣强
- 录音、转写、标签、回放适合做证据链
- 女主从质检视角切入，适合层层掀皮

## 爽点方向

- 开局就用一段求救声做钩子
- 女主先锁原音，不让系统继续洗标签
- 中段揭开“安抚语料池”本质是活人情绪骨灰盒
- 最后把训练链掀给整座客服中心
