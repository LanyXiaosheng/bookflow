# 标题简介AB版｜公司把客服全接进语音Agent那晚，我先在情绪标签里听见了活人的求救

## A版

### 标题

`公司把客服全接进语音Agent那晚，我先在情绪标签里听见了活人的求救`

### 简介

公司说语音 Agent 上线后，客服终于不用再扛最恶心的情绪了。可我做标签复核的第一晚，就在一条“极端客户攻击”音轨里听见一句很轻的：`别再让我接这条线了。` 更可怕的是，那声音属于半年前已经离职的老客服。原来他们不是用 AI 替客服减压，是先把最能扛骂的人磨成了安抚语料。

### 简介

语音 Agent 越像真人，我越确定，真人先被磨进去了。
