# 项目说明｜我流产那天，他还在陪白月光过生日

## 项目定位

- 平台方向：番茄短篇
- 题材：现言 / 婚恋虐反转 / 流产 / 白月光 / 追妻火葬场
- 核心卖点：女主流产当天独自进手术室，男主却在给白月光过生日，知道真相后彻底崩塌

## 一句话故事

林知夏流产那天，给傅承砚打了十七个电话都没接。等她从手术室出来，才在热搜上看见他陪白月光吹生日蜡烛。那一刻她终于明白，这段婚姻里死掉的，不止那个孩子。

## 核心冲突

- 外部：流产、白月光介入、男主长期偏袒、婚姻彻底破裂
- 内部：女主从“再等等他”走到“我不要他了”，男主从习惯被原谅走到失去后发疯
