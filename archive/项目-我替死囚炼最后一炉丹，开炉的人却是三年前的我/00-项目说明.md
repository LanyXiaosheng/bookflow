# 项目说明｜我替死囚炼最后一炉丹，开炉的人却是三年前的我

## 项目定位

- 平台方向：番茄短故事
- 账号方向：`守丹客`
- 题材：古风志怪悬疑 / 炼丹旧案 / 死囚临刑 / 因果翻案
- 核心卖点：死囚行刑前夜，主角奉命替其炼最后一炉“赎罪丹”；可丹炉开时，来验丹的人却是三年前已经死在丹火里的自己
- 当前阶段：`2026-05-05` 首轮立项

## 一句话故事

大理寺狱中的死囚临刑前，按旧例可求一炉赎罪丹。寒门丹师谢沉奉命入狱开炉，本以为这只是权贵消灾的旧规，直到丹炉开封那一刻，前来验丹的人竟是三年前死在观中丹火里的“自己”。谢沉这才明白，那场被所有人定成意外的丹火旧案，从来没有结束，而眼前这个死囚，也根本不是来求命的。

第一阶段先完成：

1. 钉死 `死囚炼丹 + 三年前旧我现身` 双钩子

## 读点判断

- `死囚最后一炉丹` 自带临刑倒计时和禁忌感
- `开炉见到三年前的自己` 是强反常识钩子
- `丹炉 / 狱案 / 旧火 / 替身` 都是硬物件，不靠空吓
- 爽点不是单纯见鬼，而是主角一路把丹火旧案和权贵借丹换命的局翻出来

## 爽点 / 爆点方向

- 开局先把死囚、牢狱、最后一炉丹压到主角头上
- 中段把丹火旧案、假死替身、赎罪丹真用途串成完整局
- 后段不拖氛围，直接让主角用当年烧不净的丹炉灰翻回证据
- 结尾回本点不是“成仙”，而是主角把三年前该死的人和该翻的案都翻了回来
