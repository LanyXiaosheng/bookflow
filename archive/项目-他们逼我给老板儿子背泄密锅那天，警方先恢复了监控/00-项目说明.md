# 项目说明｜他们逼我给老板儿子背泄密锅那天，警方先恢复了监控

## 项目定位

- 平台方向：番茄短篇
- 题材：女频现代 / 职场反杀 / 豪门公司 / 公开打脸
- 核心卖点：公司核心投标方案泄密后，老板第一时间把锅扣到女主头上，逼她签“自愿离职及保密事故认责书”，为自己废物儿子挡灾。所有人都以为女主这次会认栽，结果警方先恢复了被删除的监控、门禁和拷贝记录，当场把老板儿子从“太子爷”打回“泄密主犯”。

## 一句话故事

昱盛科技价值三亿的核心投标方案外泄，董事长周明成在内部追责会上直接把嫌疑推给项目负责人林知夏，说她是最后一个接触文件的人，只要签字认责，公司就不报警。林知夏笑着把认责书推了回去，因为她已经先一步报案，还申请了警方恢复被删掉的监控。很快，监控、门禁和文件水印一起亮了出来，真正把方案卖给竞对的人，正是老板那个靠空降进公司的儿子周子谦。

## 读点判断

- “老板让员工给亲儿子背泄密锅”天然愤怒值高
- 职场里“认责书 + 离职 + 不报警换闭嘴”很有现实压迫感
- 监控恢复、门禁记录、文件水印、转账流水适合连续翻车
- 女主不是被开掉后才反击，而是提前报警，主动做局

## 爽点 / 爆点方向

- 开局就是追责会拍认责书
- 女主不是哭着解释，而是让警察带着恢复记录进场
- 删除监控失败是第一炸，文件水印和竞对转账是第二炸
- 老板、太子爷、HR、IT一起翻车
- 结尾要做到：他们想用她的职业生涯给太子爷垫背，她先把所有人的脸钉进了案件笔录里
