## 一、先说结论

`2026-04-12` 之后，这个月剩下的项目不要再走“题海测试”。

应该改成：

1. 主号只打 `现言婚恋火葬场`
2. 古言只保留 `重生清算 / 官场清算 / 世子换位` 这种明确事件场
3. `AI职场 / 泛直播脑洞 / 规则怪谈 / 替嫁残王泛甜宠` 全部降频
4. 本月下半月最多新开 `4` 个项目，宁缺毋滥

一句话：

- 后半月不要再求“多”
- 只求“每个新题都不是旧题换壳”

## 四、查重方法

本次查重做了两层：

### 1. 项目名精确排查

对当前所有 `项目-*` 目录名做了全量检索。

结论：

- 下面准备进入下半月排班的候选题，库里都没有同名项目

### 2. 相似度排查

用本地项目标题和候选题做相似度比对。

判定口径：

- 相似度越低，越不容易是“旧题换壳”
- 本次保留的候选题，最高相似度控制在 `0.37` 以内

这批候选题可视为：

- 同赛道可用
- 但不是现有项目的直接重复版本

## 五、本月后半月可开的 5 个新项目

下面这 `5` 个题，已经做过本地项目名查重和相似度比对。

## 1. `敲钟上市那天，他把总裁夫人的位置留给白月光，我先公开了股权代持协议`

- 赛道：`现言主航道 / 公司权责反杀`
- 最近相似项目：`他们逼我给白月光的儿子捐肾那天，我先公开了孩子生父的体检报告`
- 标题相似度：`0.349`
- 结论：`可开`

为什么值得开：

- 还是现言火葬场，但从 `孩子` 切到 `股权`
- 不是重复前夫后悔，而是公开资本权责翻盘
- 更适合和 `公司专利在我名下` 那条成功样本形成邻近放大

## 2. `婚房解押那天，他逼我签赠与协议，银行先冻结了他的共同账户`

- 赛道：`现言主航道 / 婚房财产反杀`
- 最近相似项目：`离婚那天，我把他送我的婚戒扔进了法院门口的喷泉`
- 标题相似度：`0.314`
- 结论：`可开`

为什么值得开：

- 仍在婚恋主航道，但从“感情后悔”换成“婚房和账户”
- 公开动作和法律动作都更硬
- 物件很清楚：`婚房 / 赠与协议 / 共同账户`

## 3. `校庆捐楼那天，他们把我的研究成果挂在白月光名下，答辩委先公开了原始实验记录`

- 赛道：`现言副主航道 / 学术署名反打`
- 最近相似项目：`他们逼我给白月光换命，我先让全京城看了脉案`
- 标题相似度：`0.310`
- 结论：`可开`

为什么值得开：

- 仍然是女主被夺成果、被顶替位置
- 但和婚恋、私生子、亲子鉴定都拉开了距离
- 这个题的关键不是学术，而是“我的东西被挂给别人”

## 4. `赈灾银入库那夜，他们逼我认下亏空账，我先把火漆封条送到了御前`

- 赛道：`古言副航道 / 官场清算`
- 最近相似项目：`他们逼我认下顶流孩子那天，我先晒出了他的结扎证明`
- 标题相似度：`0.370`
- 结论：`可开`

为什么值得开：

- 古言里终于不是替嫁、冲喜、残王
- 直接切入 `账 / 银 / 封条 / 御前` 这套官场清算链
- 更接近你古言里真正能跑的“抄家前夜 / 关键节点立刻抓证据”

## 5. `春猎回营那日，世子逼我给庶妹让位，猎场先抬出了他的通敌密信`

- 赛道：`古言副航道 / 世子换位清算`
- 最近相似项目：`他们逼我认下顶流孩子那天，我先晒出了他的结扎证明`
- 标题相似度：`0.302`
- 结论：`可开`

为什么值得开：

- 还是古言强羞辱场
- 但不再是婚礼、替嫁、冲喜
- 直接有 `让位 -> 猎场出证 -> 通敌翻车` 三段硬钩子

## 七、本月后半月的硬规则

### 1. 不双开同族题

例如：

- 开了 `股权代持`，就不要再开 `专利 / 董事会 / 代持协议` 同族题
- 开了 `婚房账户`，就不要再开 `离婚财产分割` 同族题

### 2. 一个星期最多 `2` 个新项目

本月已经不适合继续高频试错。

### 3. 发前必须过 3 个门槛

- 是否属于当前主航道
- 是否和现有项目库重复
- 是否在前 `30%` 内能完成 `受辱 -> 反打 -> 更大威胁`

### 4. 查重不只看字面

以后不只是避免同名。

更要避免：

- 同场景
- 同物件
- 同翻盘手段
- 同关系结构

换一句话，不等于新项目。
