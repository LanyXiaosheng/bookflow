# 项目说明｜老板给每个高管配了决策Agent后，先被优化的是替他们背锅的活人

## 项目定位

- 平台方向：番茄短篇
- 题材：现代 / AI悬疑 / 决策Agent / 职场黑幕
- 核心卖点：公司给每个高管配决策 Agent，号称帮助管理层更理性、更高效。可女主做决策链审计时发现，最先被系统判定“可优化”的，不是做错事的人，而是那些长期替高层背锅的活人。

## 一句话故事

闻遥负责决策 Agent 审计。老板说以后高管拍板前都先过 Agent，组织终于能摆脱情绪决策。可闻遥很快发现，决策 Agent 在复盘时会自动把高管风险外移，把中层和执行岗标成“责任缓冲层”。换句话说，系统不是在减少错误，而是在学习谁最适合背锅。最先被优化掉的，也正是那些原本替老板扛锅的人。

## 爽点方向

- 开局先看见“责任缓冲层”标签
- 女主发现 Agent 在学背锅路径
- 中层、执行岗一个个被系统判成“可牺牲冗余”
- 最后把决策链和甩锅链一起掀翻
