# 读者为什么读｜返岗第一天，我把交接邮件抄送了集团人事

## 一句话结论

这题能撑到约 `1w` 字，不是因为“工位被占”这一下够狠，而是因为：

`返岗失位的恶心感 + 制度替位的寒意 + 公开翻盘的快感 + 女性向上走的回本`

这四条线能连续给读者情绪，不会只剩一场办公室闹剧。

## 读者为什么点进来

1. “返岗第一天”是现实里很熟的场景
2. 实习生坐上自己的工位，羞辱感直接且具体
3. “交接邮件抄送集团人事”说明这不是小打小闹，是要翻制度桌子

## 读者为什么会继续读到 3000 字

1. 工位被占不是终点，后面还有：
   - 账号被换
   - 抽屉被清
   - 交接未确认
2. 她不是吵架，而是查系统、查审批、查权限
3. 第一炸后很快会出现第二炸：她连客户线和署名都一起被人拿走了

## 读者为什么会继续读到 6000 字

1. 制度线开始升级  
   交接邮件、默认同意、审批日志、群权限，这些都比单纯撕脸更能拖着读者往下走。
2. 群体压迫感越来越恶心  
   不是一个坏领导，而是一整屋人默认她病过就该让位置。
3. 女主越查越发现，这不是临时顶岗，而是一整条替位链

## 读者为什么会继续读到 1w 字

1. 后段还有必须兑现的大场面：
   - 会议室摊证据
   - 集团人事介入
   - 实习生搬出她工位
   - 她不只是拿回位置，还往更高一层走
2. 这题最值钱的不是“回来坐回原位”，而是“她终于不再替任何人顾全大局”
3. 那种被拿来替位、被迫懂事、病着还要让的恶心感，本身足够撑长

## 最值钱的情绪按钮

1. 返岗第一眼看见别人坐在自己工位上
2. 那封交接邮件发件人写着自己，却根本不是自己发的
3. 所有人都一脸平静地告诉她“先适应”
4. 客户群和项目署名一起被转走
5. 会议室里终于没人敢再把她说成情绪化
6. 她最后不是回原位，而是直接往上走

## 哪些桥段扩长最值钱

1. 工位现场和抽屉被清的第一场
2. 交接邮件、审批流、权限被换的查证过程
3. 客户线和项目署名被人偷走的寒意
4. 会议室对质
5. 她决定不坐回原位而是转岗上行

## 哪些地方一扩就会泄

1. 大段回忆她生病过程
2. 重复写实习生委屈
3. 重复解释公司流程和组织架构
4. 一直停在“她很委屈”，没有新证据推进

## 最终判断

这题值得做约 `1w` 字长稿。

因为它不是只靠开头一封邮件，而是：

`工位失位 -> 权限被偷 -> 客户线被夺 -> 会议室翻盘 -> 转岗上行`

这条线很稳，而且越往后越有回本感。
