# Story Enrichment

当任务进入下面任一阶段时，读这份 reference：

- 扩写 `02-大纲.md`
- 细化 `03-10章细纲.md`
- 拉 `01-正文.md`
- 优化 `08-前30%试读优化.md` / `09-前30%精修版.md`
- 扩到 `12-长篇版-约1万字.md`

目标不是“把字数写长”，而是：

`让故事更有层次、更有画面、更有张弛，同时不写成流水账。`

## 1. 丰富的底层判断

丰富不等于堆字。

每次扩写，至少要新增下面 1 项：

- 新信息
- 新阻力
- 新情绪变化
- 新关系变化
- 新伏笔
- 新余波

如果只是把同一件事换说法重讲，或把同一类情绪反复写，就算灌水。

## 2. 情节扩写三段法

每个核心情节默认拆成：

`铺垫 -> 过程 -> 余波`

### 2.1 铺垫

作用：

- 让转折不突兀
- 提前埋证据、反应或异常
- 给后文留“原来前面早就写了”的回收点

常用铺垫：

- 人物反常
- 环境异常
- 旧物线索
- 对话停顿
- 关系裂纹

### 2.2 过程

不要只写“事情发生了”，要写清：

1. 人物想做什么
2. 遇到什么阻力
3. 怎么尝试
4. 第一次结果如何
5. 是否出现更大压力或更高代价

核心：

- 允许尝试
- 允许失败
- 允许拉扯
- 允许局势反复

过程越清楚，爽点、痛点、期待感越足。

### 2.3 余波

任何重要事件后，至少落一种后果：

- 情绪余波
- 关系余波
- 身份余波
- 证据余波
- 新隐患

没有余波，情节会像“用完即丢”的一次性桥段。

## 3. 代入感先贴主角

第三人称不等于旁观视角。

读者要像贴在主角皮肤上一起疼、一起慌、一起忍，而不是站在天花板上看剧情介绍。

### 3.1 用“我”的感受写“他”

- 少写抽象判断，如“他很愤怒”“她很难过”
- 多写当下反应：血往上涌、手发麻、胃一沉、喉咙发紧、后槽牙咬住
- 让读者先感到，再让读者总结

### 3.2 五感代替概述

- 关键入场、发现、羞辱、反杀，优先落气味、温度、触感、声音、视线
- 门是不是卡涩，灯是不是刺眼，地上踩到了什么，空气里飘着什么味，都比“他走进房间”更能带人进去

### 3.3 主角先普通，再逆袭

- 开局先给现实压力：上班、房贷、欠款、家庭拉扯、被人拿捏、身体疲惫
- 先让读者觉得“这事像会落到我头上”，后面的翻盘才更上头

### 3.4 多造“如果是我”时刻

- 被同事抢功
- 被伴侣冷待
- 被丈母娘或岳父母看不起
- 被当众比较
- 被规则卡死却没人替你说话

这类贴近日常屈辱或渴望的场景，最容易形成代入。

## 4. 场景不要写成空景

环境描写只在 3 种情况下保留：

1. 烘托人物情绪
2. 增强场景压迫或温度
3. 为后续动作埋伏笔

题材侧重点：

- 玄幻：异象、宗门、灵气、压迫感
- 悬疑：阴影、噪音、死角、违和感
- 言情：光线、天气、距离感、身体细节
- 现实：烟火气、工作场、家庭场、生活摩擦

硬规则：

- 超过 100 字的纯风景或纯情绪段落，必须自查是否在水
- 不写脱离人物视角的风景介绍
- 少用“很伤心”“很温柔”这类空词，优先写动作、反应、细节

## 5. 节奏必须有紧有松

不要全程打架，也不要全程唠嗑。

句长也要跟着节奏走：

- 短句制造绷紧、出手、揭穿、反杀
- 长句承接余波、回忆、迟疑和情绪回落

建议按下面思路排：

- 大冲突后，补一个短余波或轻日常
- 轻日常后，必须带出新钩子、新裂缝或新悬念
- 同一段连续两个大反转后，给读者一个消化口
- 慢场不是停滞，慢场也要推进关系、情绪或伏笔

### 5.1 高潮场景

高潮要细写，但只细写有价值的部分：

- 人物选择
- 局势翻转
- 代价变化
- 观众反应
- 结果兑现

高潮段可以连续用短句压拍，但翻盘后要给读者半口气，不然容易一直绷到麻木。

### 5.2 轻日常场景

日常可以写，但不能写成流水账。

每段日常至少承担 1 个功能：

- 关系升温
- 情绪缓冲
- 伏笔埋设
- 角色反差
- 下一冲突预热

如果没有功能，就删或并。

## 6. 对话抗流水账规则

温馨、有趣、日常，不等于一直聊天。

对话至少做到：

- 像真人说话，不像台词板
- 口语化，有情绪，不端着
- 贴人设
- 贴场景
- 有动作停顿
- 有潜台词
- 有一处关系推进或信息推进

避免：

- 所有人说话一个味
- 两个人来回解释
- 只靠嘴说关心
- 紧张场面硬插闲聊

## 7. 自检清单

扩写完后，至少自检下面 12 条：

- [ ] 关键转折是不是只有结果，没有铺垫和过程
- [ ] 事件结束后，是否留下了情绪、关系或线索余波
- [ ] 本章是否新增了信息、关系、压力中的至少一种
- [ ] 第三人称是否贴着主角即时感受，而不是旁白总结
- [ ] 关键场景是否落到五感，而不是只说“发生了什么”
- [ ] 主角前段是否先露出普通人处境或现实压力
- [ ] 有没有一个让读者想“如果是我也会炸”的场景
- [ ] 环境描写是否在服务人物和剧情，而不是单独看风景
- [ ] 日常场景是否承担了明确功能
- [ ] 对话是否像真人说话，而不是书面腔互念
- [ ] 有没有重复表达同一类情绪
- [ ] 有没有为了凑字数而重复争吵、重复解释、重复回忆
- [ ] 节奏是否做到“紧一下、松一下、再带新钩子”
- [ ] 爽点和紧张点是否用短句提速，余波和回落是否有适度放缓

## 8. 一句话执行标准

真正的丰富，是：

`每一段都在给故事加层次，而不是只给文本加长度。`
