# Default Start Prompt

优先使用结构化入口，不再默认使用一整段自由文本。

## 模板 A：只立项

```text
开始执行完整流程。
主 agent 负责监督审查，子 agent 负责实际执行。
任务类型：只立项
题目：【题目】
赛道：【赛道】
选题来源：我直接给你题目
执行要求：按默认模板严格执行
```

### 只立项硬要求

- 最低骨架固定为 `00 / 02 / 03 / 04 / 07`
- `01-正文.md` 不属于只立项最低产物
- 主 agent 负责分工、去重审查、共享文件整合
- 子 agent 负责实际写入，默认使用 `gpt-5.4`

## 模板 B：立项+平台发布链路

```text
开始执行完整流程。
主 agent 负责监督审查，子 agent 负责实际执行。
任务类型：立项+平台发布链路
题目：【题目】
赛道：【赛道】
选题来源：我直接给你题目
执行要求：按默认模板严格执行，别写成流水账
```

### 平台发布链路硬要求

- 补到 `10-平台发布完整稿.md`
- `10` 是平台可发主稿，不和 `12` 混用
- 写 `10` 前先过前 30% 起爆检查
- 正文和平台稿都要过反流水账检查
- 正文和平台稿都要过一次 `去 AI 味儿` 检查

## 模板 C：完整项目封板

```text
开始执行完整流程。
主 agent 负责监督审查，子 agent 负责实际执行。
任务类型：完整项目封板
题目：【题目】
赛道：【赛道】
选题来源：我直接给你题目
执行要求：按默认模板严格执行，别写成流水账
```

### 完整项目封板硬要求

- 在平台发布链路基础上继续补 `12-长篇版-约1万字.md`
- 写 `12` 前先补“读者为什么读”
- 答不出“为什么能继续读到 3000 / 6000 / 1w 字”，就不要强拉长稿
- `01 / 10 / 12` 都要额外过一次 `去 AI 味儿` 检查

## 模板 D：批量跑

```text
开始执行完整流程。
主 agent 负责监督审查，子 agent 负责实际执行。
任务类型：立项+平台发布链路
赛道分配：军婚 1 个，现言婚恋火葬场 1 个，悬疑反转短篇 1 个
选题来源：从现有选题库里挑
执行要求：按默认模板严格执行，别写成流水账
```

补充：

- 如果用户明确说 `去AI味` / `不要像AI总结稿`，默认优先级高于“先补量”
- 宁可少一点，也不要整齐、顺滑、空泛到像模板稿

## 使用规则

- 用户已经给题目：直接替换字段
- 用户没给题目：按赛道和选题来源筛题
- 批量任务默认一项目一 worker，共享文件最后由主 agent 统一更新
