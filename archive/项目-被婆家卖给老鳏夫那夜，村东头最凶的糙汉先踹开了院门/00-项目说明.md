# 项目说明｜被婆家卖给老鳏夫那夜，村东头最凶的糙汉先踹开了院门

## 项目定位

- 平台方向：改编向中篇 / 番茄短剧向
- 题材：年代 / 乡村 / 糙汉甜宠 / 婆家反杀 / 发家逆袭
- 核心卖点：女主被婆家当成彩礼筹码，差点被卖给老鳏夫；全村都怕的退伍糙汉一脚踹开院门，把她从狼窝里拎出来。后续不只谈恋爱，还接 `分家 / 工分 / 户口 / 发家 / 前夫回乡翻车`

## 一句话故事

周家把林秋禾按着头要卖给六十岁的老鳏夫换彩礼那夜，村东头脸上带疤、出了名不好惹的程野直接踹开了周家院门。所有人都以为她是从一个火坑掉进了另一个火坑，谁也没想到，这个看起来最凶的男人，偏偏最护她。林秋禾从被卖、被欺、被踩进泥里，到拿回嫁妆、工分和户口，再跟程野一起把日子过起来，最后让前夫一家眼睁睁看着她成了他们再也高攀不起的人。

## 核心冲突

- 外部：婆家想卖她换彩礼，老鳏夫和媒婆盯着她，失踪前夫家还想继续拿她当活招牌
- 内部：女主一开始不敢信任何人，男主嘴硬手狠，但只会用行动给她安全感
