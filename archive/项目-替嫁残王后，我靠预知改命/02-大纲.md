# 大纲｜替嫁残王后，我靠预知改命

## 故事核心

沈昭宁被家族逼着替嫁给众人口中的残王，本以为自己只是从侯府火坑跳进王府死局，却因能提前预见危机，一次次改掉原本会发生的血案、构陷与暗杀。她与男主从互相试探到真正并肩，最终联手掀翻沈家和幕后黑手，完成身份、情感与命运三重逆转。

## 主角设定

### 女主：沈昭宁
- 沈家庶女
- 长期被压迫，外柔内硬
- 能短时预知即将发生的致命危机
- 初期只想活命，后期主动夺回命运、清算沈家

### 男主：萧承砚
- 残王，表面双腿有疾、性情阴冷
- 实则一直藏锋装弱，暗查王府与朝局旧敌
- 起初把女主当可用之人，后期真正信她、护她

## 核心反派
1. 沈明姝：嫡姐，自私恶毒，临阵悔婚却想把女主推进死局
2. 沈夫人和沈大人：重嫡轻庶，把女主当随时可牺牲的棋子
3. 王府内鬼：负责火案、换药、递消息
4. 宁郡王府及兵部旧臣：真正布局王府与朝堂的人

## 故事主线

### 第一阶段：替嫁入局
- 女主被逼替嫁
- 新婚夜预知偏库起火和刺杀
- 女主救下男主，保住自己第一条命
- 男主开始试她、用她

### 第二阶段：试探结盟
- 男主审她、试她
- 女主用预知和观察力揪出第一批内鬼
- 两人形成“她负责预警，他负责收网”的脆弱联盟
- 王府信任开始转移到女主手中

### 第三阶段：回击娘家
- 沈家发现女主没死，反而在王府站稳
- 女主借残王妃身份回门打脸
- 沈家开始反过来求她保命

### 第四阶段：局势升级
- 女主预知宫宴兵符构陷、猎场暗箭
- 男主逐渐信她，也开始将真正的权交给她
- 两人关系从交易走向真正并肩

### 第五阶段：真相揭开
- 查出替嫁本就不是临时意外，而是早就挑好的弃子布局
- 沈家与王府内鬼、宁郡王府勾连的线被全部挖出
- 沈家被逼吐出旧账与手书

### 第六阶段：改命兑现
- 男主不再装弱，朝堂收网
- 沈家、内鬼、幕后黑手一并被清算
- 女主彻底摆脱庶女身份阴影，成为唯一王妃
- 结尾补足“娘家后悔 + 感情落稳 + 唯一王妃”

## 节奏要求
- 前1000字完成替嫁 + 新婚夜预知危机
- 前30%完成第一次改命 + 交易联盟
- 中段持续推进“预知改命 + 王府内鬼 + 娘家后悔”
- 结尾明确兑现“装弱翻盘 + 娘家清算 + 唯一王妃”
