# 项目命名与查重规则

## 为什么现在必须做这一步

现在库里的项目已经很多。

如果开题前不先查重，最容易出现三种问题：

1. 同一赛道重复写
2. 只是换几个词，本质还是旧题换壳
3. 同月排班里几个项目互相抢流量，连自己都分不清差别

所以以后任何新项目，在立项前都要先过命名和查重。

---

## 一、先判它是不是“重复项目”

下面四项里，只要有三项一样，就按重复项目处理，不立项：

1. **事件场一样**
   - 比如都是 `离婚当天 / 民政局`
   - 比如都是 `替嫁冲喜 / 残王`
   - 比如都是 `电梯 / 医院怪谈`

2. **关系结构一样**
   - 比如都是 `前夫 + 白月光 + 女主后悔流`
   - 比如都是 `庶妹 + 世子 / 王爷 + 替嫁`
   - 比如都是 `老板 + AI + 死人工号`

3. **翻盘物件一样**
   - 比如都是 `亲子鉴定`
   - 比如都是 `遗嘱录像`
   - 比如都是 `专利 / 股权 / 账户冻结`

4. **公开翻盘手段一样**
   - 比如都是 `大屏公开`
   - 比如都是 `民政局门口`
   - 比如都是 `直播公开`

不是换个近义词就算新题。

## 二、当前高密度项目族

本月开题前，先避开这些已经明显过密的方向：

### 1. 现言离婚当天 / 民政局 / 前夫后悔

- `离婚那天，他在民政局外站了一整夜`
- `离婚冷静期最后一天，他堵在民政局外求我撤回申请`
- `离婚后，所有人都以为我会回头，只有他跪了一夜`
- `我提离婚后，那个从不低头的男人疯了`

### 2. 私生子 / 亲子鉴定 / 认孩子 / 捐器官

- `他们逼我给私生子捐骨髓那天，我把亲子鉴定甩上了大屏`
- `他们逼我认下顶流孩子那天，我先晒出了他的结扎证明`
- `他们逼我给白月光的儿子捐肾那天，我先公开了孩子生父的体检报告`

### 3. 替嫁 / 冲喜 / 病王 / 残王 / 世子

- `替嫁残王后，我靠预知改命`
- `替嫁将死王爷后，我靠验毒翻了全府旧案`
- `替庶妹嫁给病弱王爷后，他竟夜夜装病`
- `被送去给世子冲喜那夜，我先掀了侯府牌位`

### 4. AI职场 / Skill / 老板 / 工号 / 死人复活

- `Skill下架那天，我看见公司把整个技术部炼成了赛博万魂幡`
- `老板说要用AI抓码奸那天，大模型先指认了他自己的工号`
- `凌晨两点，老板还在用死去员工的账号给我发需求`

### 5. 电梯 / 医院 / 病房怪谈

- `如果电梯停在第十八层，千万别说你住几楼`
- `我值夜班那天，医院多出了一层不存在的楼`
- `凌晨三点后，13号病房会多出一个病人`

## 三、开题前查重流程

### 第一步：先过项目名精确查重

先看库里有没有同名或近同名项目。

可直接用：

```bash
rg --files | rg '项目-'
```

再用关键词缩小范围，例如：

```bash
rg --files | rg '离婚|民政局|白月光|亲子鉴定|替嫁|残王'
```

### 第二步：再过结构查重

问自己这四个问题：

1. 这个题的事件场，和现有项目是不是同一类？
2. 这个题的关系结构，和现有项目是不是同一类？
3. 这个题的翻盘物件，和现有项目是不是同一个？
4. 这个题的公开翻盘方式，和现有项目是不是同一种？

如果有三项以上差不多，就不要开。

### 第三步：必须写出“差异点”

任何新项目立项前，至少写出：

- 最近相似项目是哪个
- 这次和它最大的差异是什么
- 为什么这次不是旧题换壳

如果写不出来，说明这题还不够新。

## 四、命名规则

### 推荐命名骨架

优先用：

- `事件日/夜 + 被逼失位/被抢资源 + 证据/制度/物件翻盘`

例子：

- `婚房解押那天，他逼我签赠与协议，银行先冻结了他的共同账户`
- `赈灾银入库那夜，他们逼我认下亏空账，我先把火漆封条送到了御前`

### 不推荐命名

不要再高频使用：

- `离婚那天...`
- `前夫跪着求我...`
- `替嫁残王后...`
- `直播爆火后...`
- `AI接入公司那天...`

这些不是不能用，而是当前库里已经太多了。

---

## 五、立项通过标准

一个题只有同时满足下面三条，才允许进入新项目目录：

1. 在当前项目库里没有明显重复标题
2. 不是高密度项目族的换词版本
3. 能一句话说清楚这次的新变量是什么

### 新变量示例

- 从 `亲子鉴定` 换到 `股权代持`
- 从 `离婚回头` 换到 `婚房账户冻结`
- 从 `替嫁残王` 换到 `赈灾银亏空清算`

如果新变量只是一句口气变化，不算。

---

## 六、以后开题的最简执行法

以后每次想开新项目，先做这 `4` 步：

1. 先写题目
2. 用关键词在 `项目-*` 里搜一次
3. 找出最近相似项目
4. 写一句“这次到底新在哪”

做不到这一步，不立项。
