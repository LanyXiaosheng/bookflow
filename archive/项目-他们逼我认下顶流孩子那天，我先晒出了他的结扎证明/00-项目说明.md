# 项目说明｜他们逼我认下顶流孩子那天，我先晒出了他的结扎证明

## 项目定位

- 平台方向：番茄短篇
- 题材：女频现代 / 娱乐圈反杀 / 隐婚背刺 / 直播打脸
- 核心卖点：顶流和公司为了压住绯闻，逼隐婚妻子在直播里认下“怀孕”传闻。女主表面答应，官宣现场却直接晒出顶流两年前的结扎证明，让全网当场看明白，这场怀孕官宣从头到尾就是个局。

## 一句话故事

裴叙的绯闻对象白薇疑似怀孕后，公司和婆婆把一份假的孕检单推到程雾面前，要她以“裴太太”身份出镜认下孩子，承诺事后公开名分。程雾点头答应，转头却把结婚证、假孕检单、转账记录和裴叙亲手签字的结扎同意书一起备好。直播官宣开始那一刻，他们等她承认怀孕，她先让所有人看见：这个男人，根本不可能让我怀上。

## 当前阶段目标

第一阶段先完成：
1. 正文首稿
2. 完整故事大纲
3. 10章细纲
4. 爆点节奏表
5. 标题简介AB版

## 读点判断

- “认下顶流孩子”天然高压，围观和愤怒入口都很强
- 隐婚妻子被推出去挡枪，比普通出轨更狠
- 直播官宣 + 结扎证明是强记忆点，适合疯批反杀
- 可同时满足婚姻背刺、娱乐圈黑幕、公开打脸和身份回本

## 爽点 / 爆点方向

- 开局就是假孕检单和官宣直播施压
- 女主不是哭着求名分，而是拿着证据反向赴局
- 结扎证明只是第一炸，后面还有假报告、隐婚、转账和白薇线补刀
- 丈夫、经纪人、婆婆、白薇一起翻车，打脸密度高
- 结尾要做到：他们想拿她的肚子救顶流人设，她先把这个男人的生育谎言和婚姻骗局一起掀了
