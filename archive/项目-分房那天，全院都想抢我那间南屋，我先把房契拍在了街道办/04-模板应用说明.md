# 模板应用说明｜分房那天，全院都想抢我那间南屋，我先把房契拍在了街道办

## 题型归类

- 赛道：四合院年代反杀
- 变体：分房抢房 / 房契公开打脸型
- 核心结构：父亲刚去世 + 全院逼分房 + 女主先拍房契 + 街道办重判 + 旧账反追

## 本项目重点模板

### 1. 开头钩子模板

- 直接用“葬礼后堵门抢屋”开场
- 前 `300` 字内必须出现：
  - 三叔逼分房
  - 南屋被盯上
  - 女主把房契拍出来

### 2. 群像施压模板

- 不能只写一个反派
- 要写成：
  - 三叔讲“家里规矩”
  - 继母讲“姑娘迟早出嫁”
  - 邻居讲“先让一让”
  - 街道办最初想和稀泥

这样打脸时才会更爽。

### 3. 证据反杀模板

这篇最值钱的不是吵赢。

而是女主一步步把：

- 房契
- 补修登记
- 木料旧账
- 修房垫款

全拿出来。

四合院题如果只有嘴硬，没有这种硬证据，很容易写成普通邻里吵架。

### 4. 情绪推进模板

- 第一落点：父亲刚去世，房子就被人盯上
- 第二落点：全院都默认她守不住房
- 第三落点：她不解释，直接上房契
- 第四落点：分房会变成清账会

### 5. 结局兑现模板

结局必须同时回收两件事：

1. 南屋产权坐实
2. 侵吞修房钱的人吐账

只保住房，不追旧账，结尾力度会差一截。

## 发布建议

- 适合番茄短篇年代反杀 / 四合院群像路线
- 标题必须保留 `分房 / 南屋 / 房契 / 街道办` 里的至少两个钩子
- 前 `30%` 优先强化：堵门、拍房契、街道办开会、第一笔旧账翻出
