# 发布版｜代码评审全面交给Agent后，唯一还在熬夜修Bug的人其实三个月前就离职了

## 标题候选

1. `代码评审全面交给Agent后，唯一还在熬夜修Bug的人其实三个月前就离职了`
2. `离职九十三天后，他又在公司仓库里提了hotfix`
3. `他们说是代码Agent，我先认出了死活只有他会写的那句日志`

## 推荐简介

公司把代码评审和修 Bug 全交给 Agent 后，所有人都在夸效率革命。

只有我在凌晨两点的 hotfix 提交里，先看见了一个不该再出现的名字。

闻哲。

他三个月前就离职了。

可现在，这个账号还在深夜补丁、写 review、留下一句只有他会写的兜底备注。

公司说那只是模板。

我却越看越明白，他们不是在纪念一个好工程师。

他们是想把他最好用的那部分留下，再把活着的人慢慢请出去。

## 试读开头

我第一次发现闻哲还在给公司修 Bug，是在他离职后的第九十三天。

凌晨两点，线上核心服务突然抖了一下。

- 适合 Agent / 赛博惊悚 / 研发替代方向点击测试
- 核心卖点是“离职工程师被做成影子开发者”
