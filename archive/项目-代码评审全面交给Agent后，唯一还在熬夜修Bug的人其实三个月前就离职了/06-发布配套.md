# 发布配套｜代码评审全面交给Agent后，唯一还在熬夜修Bug的人其实三个月前就离职了

## 标题备选

1. `代码评审全面交给Agent后，唯一还在熬夜修Bug的人其实三个月前就离职了`
2. `离职九十三天后，他又在公司仓库里提了hotfix`
3. `他们说是代码Agent，我先认出了死活只有他会写的那句日志`
4. `半夜替全组救火的人，其实三个月前就不在工位上了`

## 简介备选

### 简介1

公司把代码评审和修 Bug 全交给 Agent 后，所有人都在夸效率革命。只有我在凌晨两点的 hotfix 提交里，先看见了一个不该再出现的名字。闻哲。他三个月前就离职了。可现在，这个账号还在深夜补丁、写 review、留下一句只有他会写的兜底备注。公司说那只是模板。我却越看越明白，他们不是在纪念一个好工程师，是想把他最好用的那部分留下，再把活着的人慢慢请出去。

### 简介2

离职的人不该再修线上 Bug。

除非公司根本没打算让他真正离开。

## 卖点提炼

- 离职工程师半夜继续提 hotfix，天然有赛博惊悚感
- 代码评审 Agent 和影子开发者设定新鲜
- “留下最好用的他，再清掉活着的人”很适合引发讨论
