# 项目说明｜代码评审全面交给Agent后，唯一还在熬夜修Bug的人其实三个月前就离职了

## 项目定位

- 平台方向：番茄短篇
- 题材：女频现代 / Agent / 代码评审 / 赛博惊悚 / 科技悬疑
- 核心卖点：公司把代码评审和修复建议全交给 Agent 后，女主发现每次深夜自动修 Bug、补注释、写 hotfix 的“最佳贡献者”，竟然是一个三个月前就已经离职的资深工程师账号。她越查越发现，公司根本没停掉那位前同事的开发影子，还在拿他的提交风格、排错习惯和架构判断持续产出，甚至准备借它替代整个核心组。

## 一句话故事

周既白是平台研发组长。公司全面接入代码 Agent 后，所有人都夸自动评审系统神乎其神，连最难啃的线上 Bug 都能半夜自己修。可周既白在提交记录里发现，那个总在凌晨补丁的账号，竟然属于三个月前已经离职的老同事闻哲。她顺着 review 轨迹查下去，才知道公司把闻哲的代码风格、架构判断和修复路径做成了隐藏开发 Agent，还准备用这套“数字资深工程师”逐步替掉整个高薪研发团队。

## 读点判断

- `离职工程师还在深夜修 Bug` 是很强的 AI 惊悚钩子
- 代码评审 Agent、自动 hotfix、数字工程师替代感都很新
- 能结合“离职账号”“影子开发者”“公司偷走工程师脑子”这些爆点
- 有强烈赛博职场感，也有一点毛骨悚然的味道

## 爽点方向

- 开局就是离职账号深夜继续提交补丁
- 女主顺着 commit 风格、review 习惯、异常工时一路反查
- 公司高层嘴上说提效，实际在偷工程师人格做替身
- 最终让整个“数字资深工程师计划”公开翻车
