# 前30%试读优化｜代码评审全面交给Agent后，唯一还在熬夜修Bug的人其实三个月前就离职了

## 目标

- 前 30% 内迅速完成“离职同事半夜还在修 Bug”的惊悚感
- 让读者尽快知道：这不是纪念模板，是公司在偷偷养影子工程师
- 第一波高潮落在“女主确认那句日志只有他会写”

## 优化重点

### 1. 开头 300 字内直接让离职账号出现

- 第一屏必须出现半夜 hotfix 和离职账号名
- 同时明确他已经离职三个月
- 读者立刻产生毛感

### 2. 尽快把“像他”写成“就是他那套手法”

- 补丁顺序、兜底方式、日志口癖都要具体
- 让读者跟女主一起认出“这个人”
- 情绪从惊悚转成背后发凉

### 3. 迅速建立女主与离职同事关系

- 她跟他长期并肩作战
- 她最懂他的提交习惯
- 她不是自己吓自己，而是真认出来了

### 4. 前30%必须炸一次

- 公司说那只是 Agent 模板
- 女主翻出训练日志或影子项目痕迹
- 读者确认：公司真在把人做成开发替身

## 建议卡点句

`模板不会在日志后面写那句“别赌线上”。`

`那是闻哲。`

`或者说，是公司从他身上留下来的最好用的那部分。`
