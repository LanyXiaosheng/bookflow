# 项目说明｜订婚官宣那天，他让白月光戴上我母亲留下的祖母绿，公证处先调出了授权书

## 项目定位

- 平台方向：番茄短篇
- 题材：现言 / 豪门婚恋 / 珠宝品牌 / 身份失位 / 权益反杀
- 核心卖点：订婚官宣自带公开场；男主让白月光戴上女主母亲留下的祖母绿，当众完成失位；女主反手调出公证授权书，直接从情绪羞辱切到权益清算
- 当前阶段：`2026-04-21` 首轮立项

## 一句话故事

订婚官宣那天，周聿川让苏曼宁戴上了林见夏母亲留下的那枚祖母绿胸针，还把她安排在了主位中央。所有人都以为林见夏今天会当场失态，她却只叫停了灯光，然后让公证处把那份母系遗产授权书投上了大屏。周聿川以为自己是在官宣订婚，实际上，他是在直播里亲手证明，自己根本没资格碰那枚祖母绿，也没资格替她母亲留下的品牌做主。

## 当前阶段目标

第一阶段先完成：

1. 钉死官宣现场失位和授权书反打两个爆点
2. 完成 `00 / 02 / 03 / 04 / 07` 五件套
3. 把这条线从普通婚恋争风吃醋，压成“公开失位 + 权益清算”的现言副航道样板

## 读点判断

- `订婚官宣` + `品牌发布会` 双公开场天然适合番茄短篇
- 母亲遗物被别人戴上，情绪刀很直
- `公证授权书` 是硬翻盘物件，不靠嘴仗
- 男主不是后悔型核心，核心是他想借官宣把女主母系资产彻底剥离

## 爽点 / 爆点方向

- 开局先给白月光戴祖母绿，直接打出失位
- 中段补齐母系遗产、品牌授权、设计稿和借壳融资的旧账
- 后段让公证处、董事会、甲方视线一起回流到现场
- 结尾回本点不是“他求我原谅”，而是“我当场撤回了你赖以站台的全部资格”
