# 模板应用说明｜随军名额批下来那天，婆家先逼我把房让给小姑

## 题型归类

- 赛道：军婚婚恋
- 变体：随军批文 + 婆家抢位 + 房本票据反杀型
- 核心结构：随军名额终于下来 + 婆家马上抢房 + 女主不让 + 账本票据压场 + 男主回来重新站位

## 本项目重点模板

### 1. 开头钩子模板

- 直接用 `随军批文到手 + 婆婆开口要房` 起爆
- 前 `300` 字内必须明确：
  - 名额来之不易
  - 小姑想拿房结婚
  - 女主不愿意再让

### 2. 资源争夺模板

军婚的“抢房”不能写成四合院翻版。

这里最值钱的不是房本本身。

而是：

- 她为了随军熬了三年
- 她刚拿到资格
- 婆家立刻拿这个资格当交换条件

### 3. 家属院施压模板

除了婆家，还要补：

- 亲戚说她都要走了
- 家属院说房空着浪费
- 小姑用结婚卖惨

这样女主的拒绝才不是小题大做。

### 4. 男主回收模板

男主不能只说“我妈不是那个意思”。

真正有效的动作是：

- 看账
- 认票据
- 把房和随军边界说清
- 当众告诉婆家：随军不是她该付的代价

### 5. 结局兑现模板

结尾必须回收：

1. 房子保住
2. 随军资格不再被情分绑架
3. 男主和婆家的边界被重新划清

## 发布建议

- 适合番茄短篇军婚 / 婆家资源争夺路线
- 标题必须保留 `随军 / 房 / 小姑 / 批文` 至少两个钩子
- 前 `30%` 优先强化：批文到手、婆家开口、女主第一句拒绝、房本票据伏笔
