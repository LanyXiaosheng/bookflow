# 大纲｜同事突然变成了AI里的Skill，而我成了唯一能调用他的人

## 故事定位

- 平台方向：番茄短篇
- 题材：AI热题 / 职场惊悚 / 悬疑反转 / 近未来黑箱公司
- 关键词：裁员夜、Skill、人格映射、员工资产化、全楼曝光
- 爽点方向：失踪同事求救、公司黑幕升级、主角反向调用系统、最终公开打爆公司话术

## 一句话故事

裁员夜后，陈默的电脑里突然多出一个名为“/zhouyan”的新 Skill，而这个名字正是昨晚失踪的同事周砚。所有人都说周砚已经离职，只有陈默知道，公司正在把员工做成可调用能力，而他成了唯一能把真相放上全楼屏幕的人。

## 核心设定

### 主角：陈默
- 普通产品运营，长期夹在老板和技术之间背锅
- 对公司有怨气，但还没敢真正翻脸
- 是最容易代入的普通打工人视角

### 核心“亡者”：周砚
- 技术骨干，裁员夜后失踪
- 被做成系统内可调用 Skill
- 仍保留部分自我意识，试图借主角之手曝光真相

### 主要反派：张总
- 公司业务负责人
- 推动“人格资产化”项目，把优秀员工永久能力化
- 逻辑冷酷，坚信人最值钱的部分就是可复用能力

## 故事主线

### 第一阶段：失踪同事变成系统Skill
- 裁员夜后，陈默在工位发现系统多出一个名为周砚的 Skill
- 对方第一句就是：别让他们知道你还能看见我
- 陈默意识到这不是恶作剧，而是公司系统里出了真正的人

### 第二阶段：公司开始抹平人的存在
- 所有人都改口说周砚只是离职，不存在失踪
- 陈默发现部分已离职员工仍以“自动化能力”形式存在后台
- 公司高层对外宣布全面接入AI，实则在洗白人格资产化项目

### 第三阶段：主角被迫进入夹层真相
- 周砚引导陈默进入不存在的楼层与隐藏样机间
- 陈默看到“人格资产管理系统”，确认员工被映射成可调用模块
- 他还看到一个正在建立中的“陈默模板”，明白自己也被盯上了

### 第四阶段：借全楼系统公开黑幕
- 张总要用保留周砚副本作为筹码，逼陈默交出权限
- 陈默反向接入大厅主屏，把隐藏楼层、人格仓、工号封装全部公开
- 全公司被修改过的记忆开始松动，现场失控

### 第五阶段：真正的核心不是救一个人，是毁掉仓库
- 主链路被破坏后，张总启动备用人格仓
- 周砚承认自己曾参与原始原型研发，但项目后来失控
- 他请求陈默进入备用仓，连同自己一起彻底删除

### 第六阶段：结局回本
- 陈默在备用仓删除全库，周砚最后留下“我们不是工具”
- 公司事故被曝光，张总被带走，整个项目塌方
- 结尾留一丝阴影：系统里最后弹出一条未删除日志，显示“陈默模板创建中断”，形成余味

## 核心爽点设计
1. 开局就炸：失踪同事变成 Skill
2. AI 热点和职场恐怖天然结合，读者代入快
3. 每推进一步，都是“人被工具化”的更狠真相
4. 主角不是单纯求生，而是反向利用系统曝光公司
5. 结尾大屏公开 + 删库，回本清晰

## 结局方向
- 主角保住“作为人”的边界
- 周砚真正消失，但完成自我赎罪
- 公司AI神话崩盘，留下强讨论空间
