# 大纲｜结婚三年他不肯公开我，离婚后却追上热搜

## 故事定位

- 平台方向：番茄短篇
- 题材：现言 / 隐婚 / 离婚 / 娱乐财经热搜 / 追妻火葬场
- 关键词：周年晚宴、隐婚三年、白月光错位、主持人女主、离婚热搜、事业翻身
- 核心爽点：女主不再替隐婚兜底，男主在全网面前后知后觉，情绪线和舆论线同步反噬

## 一句话故事

姜以棠和陆沉隐婚三年，他永远说不能公开，却次次默认外界把白月光和他写成一对。周年晚宴那天，她被误认成服务生，他依旧没有承认她。于是她摘戒签字，把这段婚姻还了回去。离婚后她凭实力重新站回镜头前，而陆沉第一次追上热搜，却是因为他终于承认自己把最该公开的人弄丢了。

## 核心设定

### 女主：姜以棠

- 财经访谈主持人
- 业务强、台风稳、婚后为配合隐婚主动降曝光
- 核心诉求不是“被秀恩爱”，而是基本的尊重与身份确认
- 离婚后重启个人栏目，事业线强

### 男主：陆沉

- 科技集团创始人
- 对外冷静强势，习惯用“时机不合适”处理感情问题
- 并非真正爱白月光，而是长期默许暧昧边界
- 失去后才意识到沉默本身就是伤害

### 白月光角色：宋蔓

- 影后，和陆氏长期合作
- 善于利用媒体和舆论暗示关系
- 不是核心大反派，但负责推动婚姻彻底破裂

## 故事主线

### 第一阶段：周年晚宴翻脸

- 女主在周年晚宴被误认为服务生
- 主持人公开起哄陆沉和宋蔓
- 陆沉仍说“等合适的时候”，女主彻底死心
- 当晚签下离婚协议

### 第二阶段：隐婚婚姻的旧账回补

- 回补三年里男主一次次让女主委屈的细节
- 女主被拍、被误会、被媒体写成倒贴，全都没人澄清
- 男主始终认为自己是在“保护”

### 第三阶段：离婚后的舆论错判

- 离婚消息先以女主“被抛弃”形式上热搜
- 宋蔓借势试图坐实关系
- 女主不解释，不挽回，直接重启个人新栏目

### 第四阶段：男主开始迟来的破防

- 陆沉发现女主真的搬走、真的断开工作与生活联系
- 从家里和公司细节里看见她过去的价值
- 第一次主动澄清，却已晚于伤害发生

### 第五阶段：热搜反噬全面倒转

- 女主新节目爆火，离婚和隐婚真相被扒出
- 全网从“她被抛弃”转向“他不配”
- 陆沉在公开采访里第一次承认：是他没有给她名分与尊重

### 第六阶段：他追上热搜，她走回自己的人生

- 男主追到发布会/直播现场求和
- 女主当众说清问题不是“公开晚了”，而是她已经不想要了
- 收束在女主重新站回镜头中心，男主被留在失去的后知后觉里

## 核心反转设计

1. 女主要离婚的理由不是吃醋，而是持续三年的身份羞辱
2. 男主最大的错不是出轨，而是长期默认女主“不值得被公开”
3. 离婚热搜起初在笑女主，后面反噬到男主本人
4. 女主真正赢的不是婚姻，而是拿回自己的名字与事业

## 结局方向

- 女主节目爆火，事业与个人身份彻底站稳
- 陆沉公开承认隐婚与亏欠，但已经换不回婚姻
- 宋蔓退出舆论中心，白月光线自然崩塌
