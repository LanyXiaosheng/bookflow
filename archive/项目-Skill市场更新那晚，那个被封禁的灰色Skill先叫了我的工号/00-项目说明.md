# 项目说明｜Skill市场更新那晚，那个被封禁的灰色Skill先叫了我的工号

## 项目定位

- 平台方向：番茄短篇
- 题材：女频现代 / AI惊悚 / 职场悬疑 / 科技阴谋
- 核心卖点：公司内部 Skill 市场更新后，一个早被封禁的灰色 Skill 突然重新上线，并在终端里先叫出了女主三年前离职同事才知道的工号。女主顺着它留下的线索发现，公司所谓的 Skill 资产，根本不是普通工具，而是把员工的工作习惯、对话语气和决策路径直接封装成了可交易的“人形插件”。

## 一句话故事

沈南乔负责维护公司内部 Skill 市场。更新当晚，一个编号已经注销三年的灰色 Skill 突然出现在她终端首页，开口第一句就是：“工号0719，程砚让我等你。”而程砚，是三年前在公司技能化项目中突然离职失联的前同事。所有人都以为这只是幽灵数据，可沈南乔越查越发现，公司根本不是在做 Skill 商城，而是在偷员工的会议录音、操作习惯和问题处理路径，把一个活生生的人压成可复用的“技能资产”。
