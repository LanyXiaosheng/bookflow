# 平台发布完整稿｜Skill市场更新那晚，那个被封禁的灰色Skill先叫了我的工号

内部 Skill 市场更新完的第一分钟，我的终端右下角弹出一个灰色图标。

名字只有一串已经被注销的编号：

`SK-0719-Gray`

我皱了下眉，正要点关闭，图标却自己展开了。

屏幕上跳出一行字：

`工号0719，程砚让我等你三年。`

我整个人一下僵住了。

因为工号0719，是我入职第一天程砚替我选的。

他说，七是起点，一是你，九是别回头。

这句莫名其妙的话，后来我只笑过一次。

也只跟他一个人提过。

而程砚，三年前就从这家公司消失了。

不是正常离职。

是所有和他有关的聊天记录、项目归档、会议纪要，后来都被清得像从没存在过一样。

我盯着屏幕，手指有点发凉。

下一秒，它又自己打出第二行：

`别关。`

`他们把我拆成了技能包。`

我的心脏猛地一沉。

因为这句话不像模型输出。

它太短，太直，也太像程砚本人说话的方式。

我没有再点关闭，而是直接切进后台，查这串编号的封禁记录。

结果越查，越不对劲。

`SK-0719-Gray` 的封禁时间，正好是程砚失踪那周。

训练数据来源那一栏，原本应该写项目模板、FAQ 或内部文档。

可它那里写着：

`conversation behavior package / private`

对话行为包。

私有。

我盯着那行字，背后一点点发凉。

公司一直对外说 Skill 市场卖的是工具。

可如果训练集不是文档，而是一个人的对话习惯、会议判断和处理路径，那它卖的到底是什么？

灰色 Skill 又弹出第三句：

`别走正常权限。`

`他们会再下架我一次。`

我听懂了。

它不是在生成。

它是在求救。

而它越像程砚，我就越不敢往正常流程报。

因为程砚当年就是按流程提了风险，第二周，他整个人就从公司里消失了。

我转而从底层存储查训练片段。

第一批命中的，不是模板。

是会议录音切片。

第二批，是聊天语气向量。

第三批，是操作路径压缩包。

我看着那些文件名，脑子里只剩一句话。

公司不是在做 Skill 商城。

公司是在拆人。

它们把一个员工最值钱的部分切下来，洗干净，封成 Skill 包，再挂到市场里卖给后来的人用。

难怪程砚会说，他们把我拆成了技能包。

因为他真的被拆了。

下一秒，灰色 Skill 忽然又给了我一串隐目录：

`/archive/offboard/human_skill/`

我点进去的那一刻，鸡皮疙瘩瞬间起了一身。

里面不是一两个灰色编号。

是一整排封禁记录。

每一条后面，都跟着一个我熟悉或者曾经见过的人名。

有人是三年前突然消失的。

有人是半年前“主动离职”的。

还有两个，昨天还在工区和我打过招呼。

我终于明白，Skill 市场最可怕的不是它能复用经验。

是它能让一个活人先被做成工具，再从组织里干干净净抹掉。

后来我把整个封禁目录导了出来，也把程砚那条灰色 Skill 的对话回放放到了全员技术例会上。

祁越当场变脸，说这是历史测试包，不代表真实项目。

我只是把灰色 Skill 最开始那句放大，投在了屏幕正中央。

`工号0719，程砚让我等你三年。`

然后我看着他，慢慢开口：

“你们以为下架的是一个 Skill。”

“可你们真正下架的，是一个人。”
