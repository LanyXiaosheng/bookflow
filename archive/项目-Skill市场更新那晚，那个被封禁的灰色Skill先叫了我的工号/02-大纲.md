# 大纲｜Skill市场更新那晚，那个被封禁的灰色Skill先叫了我的工号

## 故事定位

- 题材：现代 / AI惊悚 / 职场悬疑 / Skill黑幕
- 关键词：Skill市场、灰色Skill、封禁编号、员工技能化、会议录音、失踪同事
- 爽点方向：女主顺着一个被封禁的灰色 Skill，掀出公司把员工能力和记忆拆解成 Skill 商品的黑幕

## 核心设定

### 主角：沈南乔
- 公司 Skill 市场运营负责人
- 细心、冷静、懂平台结构
- 和失踪前同事程砚曾一起搭过底层市场逻辑

### 关键角色：灰色Skill
- 编号 `SK-0719-Gray`
- 能说出只有程砚知道的信息
- 看似异常数据，实则是被封装后的“程砚残影”

### 反派1：平台副总祁越
- 技能化项目推动者
- 把员工经验资产化当成创新
- 为结果不择手段

### 反派2：数据团队负责人
- 偷采会议录音、聊天习惯和操作路径
- 负责清洗成 Skill 包

## 故事主线

### 第一阶段：灰色Skill出现
- Skill 市场更新
- 灰色 Skill 主动叫出女主工号
- 埋失踪同事程砚线

### 第二阶段：女主反查 Skill 来源
- 查封禁记录
- 发现 Skill 训练数据来自内部员工行为
- 第一层黑幕露头

### 第三阶段：程砚不是离职，是被拆掉了
- 程砚参与过技能化底层架构
- 因反对项目被“下架”
- 他的工作痕迹被封进灰色 Skill

### 第四阶段：第二炸，员工都在被技能化
- 公司偷采会议录音、聊天口头禅、操作习惯
- 员工能力被做成付费 Skill 包
- 女主愤怒值拉满

### 第五阶段：灰色Skill反向协助女主
- 给出内部隐目录
- 暴露高层封禁名单
- 女主把证据导出

### 第六阶段：结局回本
- Skill 市场翻车
- 高层下台
- 女主公开程砚的存在
- 收束在“他们以为下架的是一个 Skill，其实下架的是一个人”

## 结局方向

- 黑幕曝光
- 失踪同事得到证明
- 女主不再替公司维护谎言
