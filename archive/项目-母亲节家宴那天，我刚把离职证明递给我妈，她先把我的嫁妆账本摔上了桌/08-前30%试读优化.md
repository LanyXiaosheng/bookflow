# 前30%试读优化｜母亲节那天，我妈先把账本摔上了桌

## 当前前段最值钱的钩子

1. 母亲节家宴天然是公开场
2. 女主刚把离职证明递上去，全桌人就开始算她还能帮什么
3. 第一炸不是她翻脸，是母亲先摔账本
4. 账本比哭诉更硬，能直接把“懂事”翻译成金额

## 前30%必须完成的事

1. 第一屏看见离职证明压桌
2. 前 `500` 字内看见：
   - 亲戚轮番劝她先顾家
   - 弟弟婚房首付缺口
   - 前任创业旧账被轻描淡写带过
3. 前 `1000` 字内完成第一炸：母亲摔账本
4. 前 `3000` 字内接第二炸：念出弟弟婚房定金和前任借款
5. 最好卡在：母亲问弟弟要不要现在就把定金还回来

## 试读区最怕的问题

1. 一开头就回忆失业经过太多
2. 家宴上的人只会骂，没有现实逻辑
3. 母亲摔账本来得太晚
4. 账本只停在抽象“你亏了”，没有具体金额和对象

## 试读区建议断点

### 断点 A

母亲把账本摔到桌上。

### 断点 B

她翻开第一页，念出那笔嫁妆钱。

### 断点 C

她念到弟弟婚房定金，问他要不要现在就还。

当前最适合卡在 `B -> C` 之间，让读者追“这桌饭还能不能吃下去”。

## 去 AI 味儿重点

1. 少写“她终于明白家里都在吃她”，多写筷子声停住、账本摔桌、转盘不转这些现场反应
2. 家人说话要像现实里最会拿亲情压人的那种口气
3. 爽点句长要压短：
   - `那就先算账。`
   - `你先还。`
   - `今天别装了。`
4. 母亲不是一味心疼，是冷着脸替她翻旧账，这个人物反差要留住
