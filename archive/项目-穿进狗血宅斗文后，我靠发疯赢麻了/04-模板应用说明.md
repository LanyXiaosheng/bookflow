# 模板应用说明｜穿进狗血宅斗文后，我靠发疯赢麻了

## 题型归类

- 赛道：女频脑洞穿书
- 变体：穿书宅斗发疯反杀型
- 核心结构：穿书即敬茶羞辱 + 女主当场发疯掀桌 + 全府节奏被打乱 + 侯府主位重写

## 本项目重点模板

### 1. 开头钩子模板

- 直接用“穿书 + 敬茶 + 摔杯发疯”开场
- 首屏必须把“原书会忍到死”与“这一世不忍了”同时立住
- 让女主在第一场戏里就打破读者对传统宅斗文的预期

### 2. 发疯流推进模板

- 发疯不能只停留在骂人
- 要让每一次“不按套路”都推动一层旧账、规矩和关系翻车
- 每疯一次，都要让侯府失去一点对她的掌控

### 3. 宅斗清账模板

- 不是纯婆媳互撕
- 要把婆母、妯娌、白月光、冷情夫君和后院账目并成同一条压制线
- 中段重点写“她不是在闹，她是在拆旧规则”

### 4. 结局兑现模板

- 结局必须同时兑现两件事：
  1. 原书里害死她的宅斗节点全部失效
  2. 她从受气世子夫人翻成侯府主位制定者

## 情绪落点

- 第一落点：穿来第一秒就在被立规矩
- 第二落点：所有人都默认她会忍
- 第三落点：她越发疯，侯府越慌
- 第四落点：她靠发疯赢的不是脸面，是命和主导权

## 发布建议

- 适合番茄短篇女频脑洞强情绪路线
- 标题必须保留“穿进”“宅斗文”“发疯赢麻了”中的至少两个核心爆点
- 前 30%优先强化：敬茶羞辱、摔杯掀桌、白月光试探、账册开口
