# 模板应用说明｜替长姐冲喜后，我成了王府唯一的女主人

## 题型归类

- 赛道：古言替嫁冲喜
- 变体：替长姐冲喜夺权型
- 核心结构：替嫁入死局 + 新婚夜掀毒药 + 病弱世子藏锋 + 女主坐稳王府主母位

## 本项目重点模板

### 1. 开头钩子模板

- 直接用“替长姐冲喜 + 将死世子 + 新婚夜毒药”三连钩子开场
- 前 300 字内必须明确：女主不是来守寡，是被送来顶命
- 第一场高光必须是女主泼药，把被动局面抢成主动局面

### 2. 王府夺权模板

- 不能只写后院刁难
- 要把药房、账房、世子院、老王妃和二房权线并起来
- 每推进一层，都让“冲喜”更像借口，“夺权”更像真相

### 3. 男女主联手模板

- 前期是互相试探，不急着升温
- 中段靠查药、夺权、清后院建立信任
- 后期落到“夫妻联手清局”，不是单向保护

### 4. 结局兑现模板

- 结局必须同时兑现两件事：
  1. 世子不再装病，王府乱局彻底清完
  2. 女主从替嫁庶女翻成王府唯一的女主人

## 情绪落点

- 第一落点：替长姐出嫁，就是被送进死局
- 第二落点：新婚夜那碗药不是安神，是催命
- 第三落点：世子病弱是假，王府有人真想要他死
- 第四落点：她不是祭品，她是来接管整座王府的

## 发布建议

- 适合番茄短篇古言强钩子路线
- 标题必须保留“替长姐冲喜”“女主人”“王府夺权”中的至少两个核心爆点
- 前 30%优先强化：替嫁羞辱、毒药、新婚夜结盟、夺权起手
