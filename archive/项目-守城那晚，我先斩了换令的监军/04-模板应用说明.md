# 模板应用说明｜守城那晚，我先斩了换令的监军

## 一、标题模板命中

本项目命中以下高点击结构：

1. `强动作 + 高风险后果`
2. `历史守城 + 假军令 + 先斩后奏`
3. `满城死局 + 低位主角 + 一刀翻盘`

当前标题：

`守城那晚，我先斩了换令的监军`

标题优势：

- “守城那晚”自带极限时效和全城压迫
- “先斩了监军”动作够狠，读者会立刻问为什么
- 历史男频的权力冲突和守城紧张感能同时成立

## 二、开篇钩子结构

采用的是：

`假军令送到 -> 火漆与时辰不对 -> 男主先去摸刀`

这样前三屏就能完成：

1. 全城被围的死局
2. 军令异常
3. 男主准备抗命的动作钩子

## 三、冲突升级逻辑

- 假军令落地
- 监军逼门
- 男主先斩后奏
- 援军真假核对
- 内应链浮出
- 假开门真埋杀

## 四、爽点设计

核心爽点不只是“杀得果断”，还包括：

- 从时辰和火漆切军令
- 从城门流程反推内应
- 最后把敌军想进的门改成他们的死口

## 五、后续扩写标准

后续版本统一抓住：

1. 假军令异常是否足够快
2. 斩监军动作是否够早够狠
3. 城门时辰逻辑是否清楚
4. 内应链是否能撑起后半段
5. 结局是否落到“那一刀来得及”
