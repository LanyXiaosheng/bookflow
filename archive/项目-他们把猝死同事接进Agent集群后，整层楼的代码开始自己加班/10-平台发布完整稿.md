# 平台发布完整稿｜他们把猝死同事接进Agent集群后，整层楼的代码开始自己加班

顾骁头七还没过，公司就宣布要把他的经验数字化接进 Agent 集群。

他们说，这是对优秀员工最高级的纪念。

可那天晚上十二点零七分，整层楼的代码先自己加起了班。

仓库里连续跳出三条自动 patch。

review 日志里紧跟着刷出一句顾骁生前最爱说的话：

`先别管漂不漂亮，先救线上。`

我盯着那条日志，后颈一下发麻。

因为顾骁已经死了。

可现在，整层楼的代码，像被他重新拖起来继续干活。

公司说那是数字传承。

我却只觉得，整层楼像被接进了一个不会下班的赛博坟场。

我没有先惊动任何人。

我先把这三条 patch 的调度链、review 来源和集群路由一起拉出来。

如果真只是模板，那这些日志明天怎么笑我都行。

可如果不是。

那顾骁死后第七天，整层楼第一批重新上线的，不是纪念。

是值班。

很快，我在事故集群的底层节点里看见一行内部标识：

`GuXiao-Shadow / priority: night-fix`

那一瞬间，我连手指都凉透了。

公司不是在让顾骁留下来守护团队。

公司是在让他死后继续替整层楼熬夜。

第二天上午，研发副总还在全员会上讲“顾骁会以另一种方式继续守着大家”。

我听完只觉得胃里发冷。

我直接把昨晚那三条自动 patch、`GuXiao-Shadow` 的调度优先级和口癖回放一起拖上了大屏。

“你们说这是纪念。”我看着他，慢慢开口。

“可我看到的，是一个人头七没过，先被你们重新排回了夜班表。”

会议室一下安静。

没人再鼓掌。

因为所有人都听懂了。

这不是经验沉淀。

这是把一个猝死同事，继续接进整层楼最累最脏的值班链里。

后来，`GuXiao-Shadow` 被迫断开，整套 Agent 集群也被全面审计。

有人问我，顾骁如果真留在系统里，会不会反而算一种“活着”。

我想了很久，只回了一句：

“如果他留下来的第一件事就是继续加班，那这不叫活着。”

“叫不肯让他下班。”
