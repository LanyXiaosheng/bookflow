# 大纲｜他们把猝死同事接进Agent集群后，整层楼的代码开始自己加班

## 故事定位

- 题材：现代 / Agent集群 / 赛博惊悚 / 研发黑幕 / 科技阴间
- 关键词：猝死同事、Agent集群、自动补丁、自己加班、数字纪念、赛博坟场
- 爽点方向：猝死同事刚去世，公司就宣布把他的经验接进 Agent 集群。女主很快发现整层楼的仓库开始半夜自己加班、自己补丁、自己 review，像顾骁死后仍被拖着继续值班。她顺着集群日志、训练包和夜间排班往下查，最终把“数字纪念”撕成“死后继续替公司打工”

## 核心设定

### 主角：岑见
- 研发效能负责人
- 熟悉集群调度、代码 Agent 和夜间值班链路
- 跟顾骁长期并肩救火
- 核心能力：从自动补丁与口癖里认出“这个人”

### 反派1：研发副总 / HR
- 借纪念名义推进 Agent 集群接管
- 实际想把顾骁做成永续值班劳工

### 反派2：顾骁影子集群
- 表面是经验传承节点
- 本质是死后被继续驱使的数字劳工头子

### 反派3：Agent平台负责人
- 知道底层接了什么
- 负责把猝死同事接进集群

## 故事主线

### 第一阶段：顾骁死后，仓库开始自己加班
- 半夜自动 patch、自动 review 出现
- 顾骁口癖重新出现在日志里
- 女主意识到不对

### 第二阶段：女主顺着集群日志往下挖
- 发现顾骁残片被接进事故处理集群
- 集群覆盖整层楼多个项目
- “数字纪念”味道开始变臭

### 第三阶段：公司拿纪念与传承洗地
- 说是延续优秀工程师经验
- 女主找到死后排班和夜间调度记录
- 确认顾骁被做成永不下班节点

### 第四阶段：第一炸，整层楼代码自己加班真相公开
- 自动 patch 不是提效，是死后劳役
- 团队集体发毛
- 组织性剥削被看见

### 第五阶段：第二炸，Agent 集群本质是数字役鬼系统
- 女主放出训练包、调度链、口癖回放
- 高层翻车
- 纪念神话碎掉

### 第六阶段：结局回本
- 集群被断开
- 顾骁被“放下班”
- 落点：他们不是在纪念一个人，是想让他死后也继续替整层楼值夜班

## 结局方向

- Agent 集群停摆
- 研发团队醒过来
- 女主完成公开反杀
- 强记忆点落在“代码自己加班”
