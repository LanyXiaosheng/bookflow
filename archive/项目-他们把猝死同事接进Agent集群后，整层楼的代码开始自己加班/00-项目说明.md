# 项目说明｜他们把猝死同事接进Agent集群后，整层楼的代码开始自己加班

## 项目定位

- 平台方向：番茄短篇
- 题材：女频现代 / Agent集群 / 赛博惊悚 / 职场悬疑 / 科技黑幕
- 核心卖点：猝死同事头七还没过，公司就宣布将其“经验数字化接入 Agent 集群”。所有人都说这是对优秀员工最体面的纪念，只有女主发现，自那以后，整层楼的代码开始在半夜自己加班、自己补丁、自己回评审，像一整层工位都被拖进了一个不会下班的数字坟场。

## 一句话故事

岑见是研发效能负责人。猝死同事顾骁去世后，公司第一时间做的不是停项目，而是把他的代码风格、事故处理路径和决策偏好接进 Agent 集群，说要让他的经验继续守护团队。很快，整层楼的仓库开始在半夜自动补丁、自动 review、自动回滚，甚至连顾骁生前最常说的话都重新出现在日志里。岑见顺着 Agent 集群往下查，才发现公司不是在纪念他，是把他炼成了整层楼永不停机的赛博劳工头子。

- `猝死同事 + Agent集群 + 代码自己加班` 画面非常强
- 能把职场剥削和赛博惊悚结合得很狠
- “头七没过就数字化接入”非常抓人
- 日志口癖、半夜补丁、自动值班都适合连续炸点

## 爽点方向

- 开局就见半夜自动补丁和死者口癖
- 女主顺着集群日志、训练包、排班镜像往下翻
- 公司想讲纪念和传承，结果被拆成数字役鬼
- 最后把整层楼“自己加班”的真相当众炸开
