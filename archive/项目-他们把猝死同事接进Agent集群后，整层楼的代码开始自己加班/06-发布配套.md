# 发布配套｜他们把猝死同事接进Agent集群后，整层楼的代码开始自己加班

## 标题备选

1. `他们把猝死同事接进Agent集群后，整层楼的代码开始自己加班`
2. `顾骁头七还没过，整层楼的仓库先自己补起了丁`
3. `他们说是数字纪念，我先在半夜日志里听见了死人的口癖`
4. `猝死同事被接进Agent集群那夜，整层楼先开始自己值班`

## 简介备选

### 简介1

顾骁头七还没过，公司就宣布要把他的经验数字化接进 Agent 集群。他们说，这是对优秀员工最高级的纪念。可那天晚上十二点零七分，整层楼的代码先自己加起了班。仓库里连续跳出自动 patch，review 日志里跟着刷出一句顾骁生前最爱说的话：`先别管漂不漂亮，先救线上。`那一刻我才知道，公司不是在纪念他，是想让他死后也继续替整层楼值夜班。

### 简介2

整层楼的代码开始自己加班那晚，我才知道公司所谓的数字纪念，原来是把死人继续拖回来值夜班。

## 卖点提炼

- 猝死同事头七未过就被接进集群，冲击力强
- 半夜自动补丁和死者口癖结合，惊悚感足
- 很适合写成赛博职场压迫与反杀
