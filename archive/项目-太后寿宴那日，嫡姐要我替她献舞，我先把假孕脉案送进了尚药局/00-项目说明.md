# 项目说明｜太后寿宴那日，嫡姐要我替她献舞，我先把假孕脉案送进了尚药局

## 项目定位

- 平台方向：番茄短篇
- 题材：古代言情 / 宫斗宅斗 / 重生反杀 / 寿宴公审 / 假孕欺君
- 核心卖点：太后寿宴自带公开场；嫡姐假孕逼婚、又要庶妹替舞顶场；女主不再替人背锅，而是提前把假孕脉案送进尚药局，等着寿宴当场翻车
- 当前阶段：`2026-04-21` 首轮立项

## 一句话故事

前世，沈知鸢替嫡姐在太后寿宴上献舞，换来的却不是赏赐，而是“冲撞龙胎、欺君惑上”的死罪。重生回寿宴当天，她没有再替嫡姐挡这一场局，而是先把那份伪造出来的假孕脉案送进尚药局。她倒要看看，等尚药局女官当着太后和满朝命妇的面验脉时，沈家还怎么把这场假孕逼婚局唱下去。

## 当前阶段目标

第一阶段先完成：

1. 钉死寿宴公开场和假孕欺君双钩子
2. 完成 `00 / 02 / 03 / 04 / 07` 五件套
3. 让这条线和库里旧的 `册礼前夜 / 凤印簿 / 试毒` 明显拉开

## 读点判断

- `太后寿宴` 自带高围观和高代价
- `替舞` 让女主处在极被动的位置，天然出压迫
- `假孕脉案` 是清晰硬物件，不靠空吵
- 爽点不是单纯撕脸，而是让对方在最想体面上位的时候，当众验出她根本没怀

## 爽点 / 爆点方向

- 开局先压女主去替舞，立刻给出前世死局
- 中段把假孕、保胎药、尚药局、伪造印信串成完整局
- 后段寿宴上不拖沓，直接让尚药局女官入场验脉
- 结尾回本点不是“她得宠”，而是“她终于不再替别人赴死”
