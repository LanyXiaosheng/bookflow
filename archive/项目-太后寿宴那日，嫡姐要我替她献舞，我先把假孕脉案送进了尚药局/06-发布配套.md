# 发布配套｜太后寿宴那日，嫡姐要我替她献舞，我先把假孕脉案送进了尚药局

## 一、标题备选

### 主推组

1. `太后寿宴那日，嫡姐要我替她献舞，我先把假孕脉案送进了尚药局`
2. `她借龙胎逼我上台献舞，我先让尚药局进了太后寿宴`
3. `太后寿宴那天，嫡姐装孕逼婚，我先把她的脉案送进了尚药局`

### 补充组

4. `她拿假龙胎逼我替舞，我先让尚药局当众来验脉`
5. `替嫡姐献舞那天，我先把她的假孕脉案送进了宫里`
6. `她想借太后寿宴坐实龙胎，我先让满殿命妇看她脉象翻车`

## 二、简介备选

### 简介1

太后寿宴这天，嫡姐忽然捂着肚子，说自己胎息不稳，不能起舞。继母转头就让我戴上面纱，替她去跳那支《长生乐》。前世，我就是替她跳完这支舞，第二天便被扣上“冲撞龙胎、欺君惑上”的罪名，死在宫道上。这一世，我没有再替她背锅。我只是赶在开宴前，把她那份伪造出来的假孕脉案和保胎药方，一起送进了尚药局。

### 简介2

所有人都说，嫡姐怀了端王的孩子，所以太后寿宴上的舞只能由我替她去跳。可我知道，她根本没怀。她逼我上台，不是为了成全我，是为了等寿宴过后，把“冲撞龙胎”的罪全推到我身上。所以这一次，我先把她的脉案送进了尚药局。

### 简介3

前世，我替嫡姐跳完那支《长生乐》，第二天便死在宫道上。  
这一世，她要我替舞，我先把她的假孕脉案送进了尚药局。

## 三、卖点提炼

### 核心卖点

- `太后寿宴 + 替舞 + 假孕 + 尚药局验脉` 的事件链非常直
- 不是普通姐妹争宠，而是 `假孕逼婚 + 公开场翻车 + 欺君风险`
- 女主不是临场发疯，是提前布局，把公权力引进场
- 前世死局和今生反打形成强命运回收

### 情绪卖点

- 她不是被抢风头，是被拿去赴死
- 沈明珠和柳氏一边踩着她，一边想拿她去背“龙胎”旧锅
- 女主在最该低头的地方先抬手，把寿宴改成公审
- 结尾回本不是得宠，是终于不用替任何人去死

### 读者期待点

- 想看尚药局怎么当众验出她没怀
- 想看假脉案、药方、旧印怎么一层层翻
- 想看太后和端王会怎么接这场局
- 想看女主如何把前世那口“冲撞龙胎”的锅洗回来
