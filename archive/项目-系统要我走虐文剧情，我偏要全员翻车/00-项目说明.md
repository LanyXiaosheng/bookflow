# 项目说明｜系统要我走虐文剧情，我偏要全员翻车

## 项目定位

- 平台方向：番茄短篇
- 题材：古代言情 / 系统 / 穿书 / 虐文逆改 / 全员翻车
- 核心卖点：系统强迫女主走虐文剧情、女主反向卡bug、男主和反派都被她掀翻、人设和剧情一起失控

## 一句话故事

我一睁眼就被系统告知，必须按原剧情走完“被挖心、被误会、被虐死”的女主路线，否则立刻抹杀。可既然它非要我当受气包，那我就先让整本虐文的人设一起翻车。

## 核心冲突

### 外部冲突
1. 系统强制女主照原书虐文路线走
2. 原书男主、白月光、家族全都在等她按剧本吃亏
3. 女主必须在不被抹杀的前提下改剧情

### 内部冲突
1. 女主既要自救，又要找系统漏洞
2. 她越反抗，系统惩罚越重
3. 她从“保命改剧情”发展到“掀翻整本书”

## 情绪钩子

- 开局就被系统逼着吃苦
- 女主不认剧情，开始卡bug
- 原书所有人都按虐文套路压她
- 她一边保命，一边让全员翻车

## 当前阶段目标

第一阶段先完成：
1. 正文开头可读版
2. 完整故事大纲
3. 10章细纲
4. 女频脑洞赛道“系统强制剧情”样板
