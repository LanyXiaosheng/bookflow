# 周排产表

## 当前排产原则

周排产从 `2026-04-07` 起先遵守 3 条：

1. 先去重，再放大
2. 先用已成稿跨赛道轮转，再决定是否继续放大
3. 不再把 `离婚 / 白月光 / 亲子鉴定 / 和离 / 冲喜` 连着刷满一周

---

## 标准周节奏

### 每周固定动作

- 新增疯题 `20 个`
- 筛选出可立项题 `5 个`
- 补齐项目骨架 `3-5 个`
- 补正文首稿 `1-2 个`
- 做前 30% 试读优化 `1-2 个`
- 整理待发布稿 `1 个`
- 汇总后台数据并重排赛道优先级 `1 次`

### 每周固定分析日

- `周日` 为固定分析日
- 分析内容统一按 `06-周数据分析与选题放大机制.md` 执行
- 周日如果继续发 `6 篇`，发文走备稿，不占用分析时段

---

## 当前固定日排班

每天仍按 `6 篇` 跑，但结构不再写死成 `3A + 1B + 1C + 1D`。

当前去重版固定结构：

`2条现言主线 + 1条证据翻案 + 1条女频古言/穿书 + 1条悬疑/AI + 1条军魂或轮转位`

默认顺序：

1. `09:00`：`A池`
2. `11:30`：`轮转位`
3. `14:00`：`B池`
4. `16:30`：`A池 / C池` 混切
5. `19:30`：`C池 / E池`
6. `22:00`：`D池`

当前 6 池定义：

- `A池`：现言情绪火葬场
- `B池`：现言证据翻案
- `C池`：女频古言 / 穿书强钩子
- `D池`：悬疑 / AI / 规则怪谈
- `E池`：军魂 / 历史翻盘
- `F池`：四合院 / 年代反杀

轮转位优先级：

1. `E池`
2. `D池`
3. `F池`
4. 若前三者成稿不足，再回补 `A池`，但不能与当天其他现言重复关系模板

## 发文前去重检查

每篇发出去前，都先过这 4 条：

1. `72小时` 内同类关系模板不重复
2. `7天` 内同类起爆场景不重复
3. `7天` 内同类证据道具不重复
4. 同一天里不能同时出现两条“前夫 + 白月光 + 后悔”类标题

高危重复标签：

- `前夫 / 白月光 / 孩子 / 跪求`
- `民政局 / 手术室 / 婚礼 / 大婚`
- `亲子鉴定 / 流产记录 / 聊天记录 / 手术监控`
- `和离 / 冲喜 / 庶妹 / 王爷 / 世子`

## 项目阶段定义

每个项目统一用下面状态：

- `题目池`
- `已立项`
- `正文中`
- `试读优化中`
- `待发布`
- `完整项目`
- `已发布`

对应验收门槛统一为：

- `题目池`：只有题目，未建项目目录
- `已立项`：已补 `00 / 02 / 03 / 04 / 07`
- `正文中`：`已立项` + `01-正文.md`
- `试读优化中`：`正文中` + `08 / 09`
- `待发布`：`正文中` + `05 / 06 / 08 / 09 / 10`
- `完整项目`：`待发布` + `11-章节断点发布版.md` + `12-长篇版-约1万字.md`
- `已发布`：`待发布` 或 `完整项目` + 已回写 `03-项目生产/05-项目复盘表.md`

存量兼容判定：

- `11-章节拆分发布版.md` / `12-分章节发布版.md` / `12-章节断点发布版.md` 可兼容按 `11-章节断点发布版.md` 判定
- `12-长篇版-约1万字.md` 只计入 `完整项目`，不计入 `待发布`

## 使用方法

以后每做完一轮，就更新 4 件事：

1. 哪些项目从题目池进了已立项
2. 哪些项目从已立项进了正文中
3. 哪些项目进入试读优化和待发布
4. 周日分析后，把题材比例、去重规则和轮转位顺序写回本表
