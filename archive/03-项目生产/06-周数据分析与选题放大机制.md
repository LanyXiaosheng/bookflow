# 周数据分析与选题放大机制

## 这份文件解决什么问题

这份文件不讨论单篇怎么写，而是解决 4 个运营问题：

1. 后台数据看完以后，到底该放大什么
2. 每天发 `6 篇` 时，题材比例怎么排
3. 批量立项时，哪些题继续开，哪些题暂缓
4. 每周至少哪一天必须停下来分析一次

---

## 固定规则

以后这个项目固定执行两条：

1. 每天按排班发 `6 篇`
2. 每周至少 `1 天` 做后台数据分析和下周排班

固定分析日先定为：

- `周日`

如果周日临时要冲发布，也不能取消分析，只能改成：

- `周六晚 + 周日白天`

---

## 分析输入

每次分析后台数据，至少整理这些字段：

- 题目
- 赛道
- 标签
- 阅读量
- 字数
- 是否已签约 / 已展示
- 当前项目状态

如果后台还有下面这些，也一起带上：

- 点击率
- 完读率
- 发布日期
- 简介版本
- 封面版本

---

## 标准分析流程

### 第一步：先按阅读量排序

不是先看自己喜欢哪篇，而是先看：

1. 哪篇明显高于其他作品
2. 哪个题材连续占前排
3. 哪个标题结构反复出现

### 第二步：按题材桶归类

当前工作区从 `2026-04-07` 起统一按 `6 个池子` 看：

1. `A池`
现言情绪火葬场、离婚、追妻、误会后悔

2. `B池`
现言证据翻案、入狱、顶罪、白月光反噬、真相回流

3. `C池`
女频古言、穿书、宅斗、重生、替嫁、清算

4. `D池`
悬疑惊悚、规则怪谈、AI职场惊悚

5. `E池`
军魂、守城、粮道、军令、历史翻盘

6. `F池`
四合院、年代、分房、工位、房契、街道办

### 第三步：找出真正值钱的结构

不要只记题材名，要记标题结构，同时要看是不是在重复同一套角色和道具。

这批数据里已经跑出来、但已经开始过密的结构是：

1. `事件日 + 对方异常举动`
例：离婚那天，他在民政局外站了一整夜

2. `我先做决绝动作 + 对方失控`
例：我提离婚后，那个从不低头的男人疯了

3. `他先伤害我 + 后来真相反转`
例：他亲手把我送进监狱，后来查出真凶不是我

4. `所有人都以为我输了 + 实际我翻盘`
例：我退圈离婚那天，全网都以为我输惨了

5. `他们逼我做牺牲 + 我当场甩出证据反杀`
例：他们逼我给私生子捐骨髓那天，我把亲子鉴定甩上了大屏

下一步要补进去、专门用来去重的结构是：

6. `军中死局 + 我先违令`
例：我穿成了即将被斩首的小兵

7. `日常空间异常 + 我先发现规则`
例：凌晨四点后，如果物业敲门，千万别开门

8. `年代资源争夺 + 我先公开证据`
例：分房那天，全院都想抢我那间南屋，我先把房契拍在了街道办

### 第四步：判断下一周的题材比例

当前阶段统一按这个比例排：

1. `A池 33%`
2. `B池 17%`
3. `C池 17%`
4. `D池 17%`
5. `E池 8%`
6. `F池 8%`

换成每天 `6 篇`，执行口径是：

1. `A池 2篇`
2. `B池 1篇`
3. `C池 1篇`
4. `D池 1篇`
5. `E/F 轮转 1篇`

### 第五步：把结论写回项目

每次分析完，不只口头结论，要同步更新：

1. `04-周排产表.md`
2. `03-批量立项清单.md`
3. `05-项目复盘表.md`
4. 对应赛道资产库

## 当前样本结论

基于最近一批后台样本，当前优先级已经很清楚：

1. `现言离婚 / 追妻火葬场` 仍是主攻线
2. `现言证据翻案 / 亲子鉴定 / 顶罪反噬` 仍是副主线
3. `古言重生 / 替嫁 / 穿书` 继续保留稳定供给
4. `悬疑 / AI / 规则怪谈` 必须常驻，用来拆散婚恋重复
5. `军魂` 从测试位升级成正式轮转位
6. `四合院` 先建骨架，下轮接排班

已经验证的代表样本：

- `离婚那天，他在民政局外站了一整夜`：`11778`
- `他们逼我给私生子捐骨髓那天，我把亲子鉴定甩上了大屏`：`1698`
- `重生回抄家前夜，我先送继母进牢`：`1144`
- `他亲手把我送进监狱，后来查出真凶不是我`：`922`
- `我退圈离婚那天，全网都以为我输惨了`：`431`
- `所有人都以为我是废物，直到我预判了股市崩盘`：`256`
- `那个每晚准时给我打电话的人，三年前就死了`：`172`

所以当前策略不是继续多刷同类婚恋，而是：

`保留现言主线，但强制插入军魂、悬疑、AI和四合院，把角色、场景、证据全部拉开。`

## 每天 6 篇的固定排班

默认日排班先按这个顺序跑：

1. `09:00` 发 `A池`
2. `11:30` 发 `轮转位`
3. `14:00` 发 `B池`
4. `16:30` 发 `A池 / C池`
5. `19:30` 发 `C池 / E池`
6. `22:00` 发 `D池`

这样做的目的只有一个：

`主力题材继续吃量，但相同关系模板不能反复占坑。`

---

## 周节奏

### 周一到周六

- 按去重版 `2A + 1B + 1C + 1D + 1E/F轮转` 发文
- 每天看新增数据
- 表现差的题立刻标记
- 新爆出来的标题结构当天记进批量立项池

### 周日

- 汇总近 `7 天` 后台数据
- 按赛道桶重排优先级
- 调整下周排班比例
- 新增 `21 个` 标题库存
- 确认下周要推进的 `21 个` 立项目录

如果平台要求周日也维持 `6 篇`，则周日发布直接走已备稿，不占用分析时间。

---

## 止损规则

一个方向连续 `3 篇` 明显低于主攻线，就降级，不硬扛。

统一按这条线判断：

1. `A池` 永远保留，但不能三连刷同关系
2. `B池` 只要出现一篇强反馈，就继续放大
3. `C池` 看能不能稳定跑出次爆
4. `D池` 保持常驻，不再只留一个孤立测试位
5. `E池` 作为正式去重位使用
6. `F池` 成稿前先留在立项位，不硬上稿

---

## 批量立项目标

每周分析完后，标题库存至少保持：

1. `A池 6个`
2. `B池 4个`
3. `C池 3个`
4. `D池 3个`
5. `E池 3个`
6. `F池 2个`

也就是：

`至少 21 个可继续推进的题目库存。`
