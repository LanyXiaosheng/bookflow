## 简介 A 版(150 字内,情绪钩子型)

```
开标那天,陆时衍让我坐在台下。

林小雅穿着我挑的米白西装,站上讲台,念我熬到凌晨四点改了十八版的稿。

台下评委冲我点头——"乖,没让你白忙。"

当晚,陆时衍抱着我,笑得温柔:

"宝宝,今天委屈你了。"

他不知道——

林小雅是他"干爹"的情人,进公司就是为了挤走我。

他更不知道——

下个月要来收购他公司的那家盛北资本,董事长姓苏。

是我爸。
```

## 简介 B 版(150 字内,悬念推进型)

```
她念出第三个字,我才反应过来。

那是我的稿,一字不差。

男朋友三天前给我夹了一筷子虾仁:

"宝宝,这次开标你就别上了,压力大。"

"小雅嘴甜,评委吃这一套。"

"都一家人,谁讲不一样。"

我信了。

我把源文件打包给了她。

直到我发现——

"小雅"是他"干爹"的情人。

"干爹"是评委席第二位。

而下个月要来收购这家公司的"盛北资本董事长"——

是我爸。
```

## 首屏 300 字(平台展示用)

```
她念出第三个字的时候,我才反应过来。

那是我的稿。

一字不差。

开标厅冷气开得太足。

我坐在第三排,指尖贴着塑料扶手,凉得像按在铁片上。

台上聚光灯打下来。

林小雅穿着那件米白西装——

三周前在商场,陆时衍笑着说:"颜色衬她,宝宝你眼光真好。"

我当时,还帮她把吊牌剪了。

"各位评委,这套方案的核心逻辑——"

她的声音经过话筒,带着一丝电流的嗡。

温的。稳的。

像在念一个她想了一个多月的东西。

我后槽牙慢慢咬住。

三天前——

陆时衍给我夹了一筷子虾仁:"宝宝,开标你就别上了,压力大。小雅嘴甜,评委吃这一套。"

"都一家人,谁讲不一样。"

我笑着把虾仁嚼了。

回家以后,我把源文件、推演逻辑、给每位评委画的用户画像,打了个包,发给了她。

备注栏,我打了五个字:

`加油,辛苦。`
```
