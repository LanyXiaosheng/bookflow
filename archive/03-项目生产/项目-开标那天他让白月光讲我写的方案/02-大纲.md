# 02-大纲

## 一句话故事
男朋友把我熬了一个月的方案,送给了他"干爹"的情人讲——他不知道,他公司下个月要被收购的那家资方盛北资本,董事长是我爸。

## 题材标签
现言 / 职场背叛 / 商战 / 隐藏身份 / 逆袭复仇

## 人物关系

| 人物 | 身份 | 与女主关系 | 作用 |
|---|---|---|---|
| 苏晚(女主) | 26,总监 / 实则盛北资本董事长独女 | 主角 | 三年潜伏观察男友 |
| 陆时衍(男友) | 30,公司策略总监,陆振华义子 | 前男友 | 三年骗婚+偷稿+白月光被安插 |
| 林小雅(白月光) | 25,公司新晋策划,陆振华情人 | 被安插者 | 替代上台讲方案 |
| 陆振华 | 60,陆时衍义父,北城商界人物 | 反派头目 | 开标评委+安插白月光+关联交易 |
| 苏敬山(父亲) | 60,盛北资本董事长 | 女主父亲 | 默许三年观察,最终入场碾压 |
| 老周 | 35+,入职带我的老同事 | 旁观者 | 复盘会沉默支持 |

## 主线三段

### 第一段:背刺(楔子—第二章)
- **情绪**:开标被迫坐台下看白月光讲我的稿 → 发现"别告诉晚晚"邮件 + 义子 + 盛北资本 → 男友回家还在演
- **目标**:把读者情绪压到最低
- **字数**:约 3600 字

### 第二段:布局(第三章—第四章)
- **情绪**:自剖三年观察动机 → 复盘会当众甩时间戳+IP+转账
- **目标**:从"被背叛的女友"翻转成"本来就在布局的主导者"
- **字数**:约 3500 字

### 第三段:碾压(第五章—尾声)
- **情绪**:揭白月光与干爹关系 → 亮盛北董事长是我爸 → 雨夜前男友捧玫瑰被拒 → 新办公室"下一仗我自己讲"
- **目标**:情绪兑现+动作收尾
- **字数**:约 3000 字

## 核心反转五点

1. **偷稿反转**:白月光讲的每一个字都是我熬到凌晨的稿
2. **身份反转**:评委陆振华是男友"义子关系"的干爹
3. **白月光反转**:她不是白月光,她是干爹的情人,来卡我位置
4. **动机反转**:女主不是被背叛后觉醒,她本来就在观察男友
5. **终极反转**:盛北资本董事长姓苏,是我爸——男友和干爹都是棋子

## 情绪钩线(回旋词)

- **"宝贝"**:饭桌温情 → 办公室"别私下闹"改口"苏总监" → 雨夜追妻叫回"苏晚"
- **"一家人/都一家人"**:饭桌诱导 → 复盘会冷场 → 尾声"你不值得一个真心"
- **"主创"**:男友开场白说的三年顺口 → 会议室揭穿
- **米白西装/夹虾仁/桃花醉/须后水**:甜蜜细节 → 背刺 → 收割
