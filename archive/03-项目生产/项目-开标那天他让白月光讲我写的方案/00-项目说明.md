# 项目说明:开标那天他让白月光讲我写的方案

## 一句话定位

现代都市职场背叛 + 隐藏身份 + 逆袭复仇短篇。
女主被男友劝退上台,看"白月光"念自己的方案——她的真实身份是收购方独女,三年前入职就是为了观察他。

## 核心冲突设定

- **表面冲突**:开标被男友安排坐台下,白月光穿我挑的西装讲我熬一个月的稿。
- **二层冲突**:男友两个月前就内部串通白月光,邮件末尾五个字"别告诉晚晚"。
- **三层冲突**:白月光是男友"干爹"陆振华的情人,进公司是为了卡女主的位置。
- **终极反转**:女主是盛北资本董事长独女,下个月盛北就来收购公司——男友和干爹都是棋子。
- **女主人设**:苏晚,23 岁海归入职,隐身三年为观察,不是"被背叛后觉醒",而是"从第一天就在等这天"。

## 节拍节奏

楔子-她念出第三个字 → 一章-偷稿现场/身体反应密铺 → 二章-深夜查到"别告诉晚晚"+义子 → 三章-自剖三年布局动机 → 四章-复盘会当众亮证据链 → 五章-揭白月光与干爹关系 → 六章-盛北董事长姓苏 → 尾声-高跟鞋踩出走人

## 代入感钩子

- 首句"她念出第三个字的时候,我才反应过来。那是我的稿。"——3 秒钩人
- "宝宝""一家人""夹虾仁""别告诉晚晚"——甜蜜细节制造背刺反差
- 身体反应替代情绪总结:后槽牙/手心薄汗/嗓子发麻/指甲按手机壳/指腹贴铁桌角
- 动作收尾代替口号:包拉链"咔"/高跟鞋"咔咔咔"/白玫瑰滑落一地
