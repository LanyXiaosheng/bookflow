# 项目说明:结婚三年他不肯公开我,离婚后却追上热搜

## 一句话定位

现代都市隐婚 + 娱乐圈 + 追妻火葬场 + 隐藏身份短篇。
女主被顶流老公隐婚三年,离婚第三天他和新人官宣上热搜——当天她被 MUSE 巴黎总部召回,继任亚太 CEO。

## 核心冲突设定

- **表面冲突**:结婚三年从未公开,所有朋友圈/合影/年夜饭都没有她。
- **背刺引爆**:离婚第三天他上热搜官宣新人,新女友戴着女主送他的腕表,穿的毛衣也是女主挑的款。
- **身份反转**:女主是 MUSE 创始人苏振东独女,全球三大奢侈时装屋继承人。
- **动机线**:三年前女主选择隐身,是想赌"他能不能爱苏柠这个人,而不是苏家的女儿"。
- **结局兑现**:发布会公开身份 + 拒绝新人申请礼服 + 红毯自己穿"银河" + 微博"公开这件事现在我自己来" + 前夫雨夜追妻被拒。

## 节拍节奏

楔子热搜刀偏划伤 → 一章三年不被公开的具体痛点 → 二章当天热搜+MUSE 邮件引爆 → 三章自剖"我本来就清醒" → 四章巴黎父女对话+"不带伤口回来" → 五章发布会公开身份甩名单 → 六章红毯拒礼服+亲穿银河 → 尾声雨夜拒前夫+微博公开自己。

- **首句** "离婚第三天,他上了热搜"——3 秒钩人

- **五感落点**:须后水味/料理台凉/车窗雾气/红毯灯光/雨打肩头
- **甜蜜细节背刺**:米白毛衣/玫瑰金腕表/须后水"To my one and only"/加菲猫公仔
