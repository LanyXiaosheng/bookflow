# 02-大纲

## 一句话故事
顶流老公把我藏了三年,离婚第三天跟他公司新人官宣上热搜——他不知道,他睡了三年的那个"普通品牌策划",是他拼命想接代言的 MUSE 奢侈时装屋的独女。

现言 / 隐婚 / 娱乐圈 / 追妻火葬场 / 隐藏身份 / 逆袭 / 商战

## 主线三段

### 第一段:隐忍(楔子—第二章)
- **情绪**:隐婚三年的具体痛点 → 提离婚 → 前夫第三天官宣上热搜 → MUSE 召回邮件引爆
- **目标**:把读者情绪压到最低,让"爽点"有落差
- **字数**:约 3200 字

### 第二段:布局(第三章—第五章)
- **情绪**:自剖三年隐身动机 → 巴黎父女对话 → 发布会公开身份 + 甩名单震慑
- **目标**:从"被抛弃的女人"翻转成"本来就清醒的主导者"
- **字数**:约 4200 字

### 第三段:碾压(第六章—尾声)
- **情绪**:拒白月光礼服申请 → 自己穿"银河"走红毯 → 雨夜拒前夫 → 微博公开自己
- **目标**:情绪兑现+闭环回扣楔子的"公开"
- **字数**:约 2600 字

## 核心反转五点

1. **热搜反转**:离婚第三天,男主跟新人官宣——这一层先把读者情绪击穿
2. **身份反转**:女主是 MUSE 独女——第二章尾引爆
3. **动机反转**:女主不是被抛弃后觉醒,她本来就清醒,隐婚是她自己选择的"测试"——第三章引爆
4. **局势反转**:发布会甩名单,娱乐圈话语权倒挂——第五章引爆
5. **情感反转**:男主雨夜追妻,被女主一句"我更不会公开你"钉死——尾声引爆

## 情绪钩线(回旋词)

- **"宝贝"**:婚内日常 → 官宣叫"小晚" → 雨夜追妻叫回"苏柠"
- **"公开"**:三年不肯公开 → 给新人长文公开 → 尾声"公开这件事现在我自己来"
- **米白高领毛衣/玫瑰金腕表/须后水**:我给他的 → 转给新欢 → 雨夜仍在用被当场点破
