# 04-爆点节奏表

## 情绪曲线(10 章制)

```
章1  ▁▂       <- 钩子轻击(热搜+划伤)
章2  ▁▂▁      <- 痛点堆叠(读者憋气)
章3  ▁▂        <- 离婚动作(情绪小爆)
章4  ▁▁▁       <- 腕表背刺(读者愤怒峰)
章5  ▄▅▆       <- 身份引爆(第一次翻身感)
章6  ▃▄       <- 动机反转(人设被抬起)
章7  ▂▃        <- 父女锚定(短暂平缓)
章8  ▅▆▇      <- 公开身份(第二次翻身感)
章9  ▇▇▇      <- 拒绝礼服(爽点中段)
章10 ████      <- 碾压+闭环(情绪兑现峰)
```

情绪原则:**压低→压低→引爆→抬起→再压低→再引爆→收束**
(不是一路高爽,而是有落差,爽感才强。)

## 爽点配位策略

### 一层爽点(30% 处)——身份
第 4-5 章尾,先让读者看到"原来她不是普通人",打破悲情基调。

### 二层爽点(60% 处)——公开
第 8 章发布会亮身份,把主动权从男主手里抢走。

### 三层爽点(90% 处)——物件收割
第 9 章拒礼服 + 第 10 章"须后水是我们家的"——不是骂战,是冷刀。

### 终层爽点(100% 处)——情感闭环
微博"公开这件事现在我自己来"回扣楔子"三年不被公开",读者自动截图。

## 发文断点建议(番茄连载)

- **断点1(章3末)**:"那本红本子,咚一声,落进底部。像一颗石头,砸在我心口。"→ 吸引读者进下一章看热搜
- **断点2(章5末)**:"邮件只有三行字。——MUSE 亚太总部 CEO,由您继任。"→ 吸引读者进下一章看身份反转
- **断点3(章8末)**:沈屿经纪人脸白得像纸 → 吸引读者进下一章看红毯打脸
- **断点4(章10末)**:【全文完】前最后一行:"终于,重新,认识自己。"→ 收束+引导评论区"还想看后续"
