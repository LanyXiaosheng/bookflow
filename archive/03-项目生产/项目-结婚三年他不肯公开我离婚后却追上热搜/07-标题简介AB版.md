## 简介 A 版(150 字内,情绪钩子型)

```
结婚三年,沈屿从没跟任何人提起过我。

朋友圈没我,合影没我,年夜饭没我。

他总说:"宝贝,再等一下,下一部戏我们就公开。"

我等了三年零两个月。

直到离婚第三天。

他上了热搜——和公司新签的艺人官宣。

她手上那只玫瑰金腕表,是我当年送他的。

同一天,MUSE 巴黎总部发来邮件:

——"苏小姐,亚太 CEO 的位子,由您继任。"

三年来,他拼命想接的代言,是我家的牌子。

他藏了三年的老婆,是他跪着想签约的那个品牌的独女。
```

## 简介 B 版(150 字内,悬念推进型)

```
"宝贝,这次电影杀青,我们就去领喜饼。"

他说了三年。

朋友圈没我。合影没我。生日,只有片场盒饭。

我三十岁,签了离婚协议。

第三天,他上了热搜。

#沈屿 终于谈恋爱了#

新人戴着我送他的腕表,挽着他走红毯。

同一天,我收到一封邮件——

MUSE 亚太,请我回巴黎,继任 CEO。

三年,他不敢公开我。

现在,公开这件事——

我自己来。
```

## 首屏 300 字(平台展示用)

```
离婚第三天,他上了热搜。

我正蹲在厨房,拆一只快递。

手机在料理台上"嗡"地一震,屏幕亮起来——

#沈屿 苏小晚 糖#
#沈屿终于谈恋爱了#
#顶流的第一次公开恋情#

我手里的美工刀,"咔"地一下,划偏了。

刀尖划破了食指第二关节。

血慢慢渗出来。

我没动。

只是低头,看着那滴血,一点一点,在快递纸箱米白色的封口胶上,洇开一个小小的、红色的圆。

沈屿三年前娶我。民政局地下室,下午四点十七分。

那天,办事员抬头问我:"新娘子穿这件,行吗?"

我穿一件白衬衫。

领口有一点皱。

沈屿看我一眼,笑了:"宝贝,你穿什么都好看。"

三年里——我微博没有他,朋友圈没有他,生日没有他。

他总说:"再等一下。"

我等了三年。

今天——

他给公司新人,戴上了我送他的表。
```

## A/B 对比建议

| 维度 | 标题 A (《结婚三年他不肯公开我,离婚后却追上热搜》) | 标题 B (《离婚第三天,他给新欢戴上了我送的表》) |
|---|---|---|
| 钩子类型 | 对比式痛点 | 具象物件背刺 |
| 读者画像 | 25-35 岁职场/婚恋女性 | 20-30 岁短视频重度用户 |
| 平台适配 | 番茄连载推荐位 | 短视频/公众号拆条 |
| 点击率预估 | 高(情绪明确) | 更高(画面感强) |
| **建议** | 首发默认用 A 版,A 若 48 小时数据不及预期,切换 B 版 |
