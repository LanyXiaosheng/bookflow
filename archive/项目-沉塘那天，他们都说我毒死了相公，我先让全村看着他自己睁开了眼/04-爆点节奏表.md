# 爆点节奏表｜沉塘那天，他们都说我毒死了相公，我先让全村看着他自己睁开了眼

## 节奏总览

- 紧场：第 `1 / 2 / 4 / 6 / 7 / 8 / 9 / 10` 章
- 松场：第 `3 / 5` 章
- 松场功能：
  - 第3章：用修门、收屋、做饭把“恶媳”开始洗白，不让文本一直悬在喊打喊杀上
  - 第5章：把傅家被做空的根本原因摊开，为后面公开翻锅和发家线蓄力

## 爆点类型覆盖

- 关系反转：第 `1 / 3 / 7 / 10` 章  
  从全家都想赶她走，到傅行舟愿意把钥匙和旧账交给她，再到真正认她这个妻子
- 信息揭示：第 `2 / 4 / 5 / 6 / 7 / 8` 章  
  假药不是毒、烂腿被误治、田契有假、郎中吞钱、大房吃绝户、旧锅反扣
- 利益冲突：第 `5 / 6 / 7 / 9` 章  
  争的不是一句冤枉，而是傅家的田、钱、药和读书路
- 情绪失衡：第 `1 / 3 / 4 / 8 / 10` 章  
  沉塘翻活人、恶媳修门、拆臭药、全村公审、塘边回本

## 第1章炸点

- 开局就是沉塘局
- 女主不是哭喊，而是先逼众人回去看“死人”睁眼
- 第一刀不是洗白，是直接把全村的公审翻成全村打脸

## 第3章爆点

- 她没先跑，先修门
- 不是解释自己无辜，而是先把这个烂家里最碍眼的一处救回来
- 读者第一次意识到这条线不只是翻案，还有家和生路

## 第5章爆点

- 傅家越来越穷不是命差，是一直有人在抽他们的血
- 女主把恶媳洗白线和发家翻账线并到一处
- 故事从“她能不能活”抬到“这个家到底是谁弄垮的”

## 第8章爆点

- 她拿药、账、当票、田契一起上桌
- “恶媳”“毒妇”的锅被她一层层拆回去
- 不是情绪反驳，是证据反扣

## 第10章兑现点

- 女主恶名洗净
- 傅家田契、生计和夫妻关系一起被救回来
- 她不是来冲喜的，她是来把傅家从泥里拽出来的

## 前30%试读卡点

- 最好卡在：沉塘翻活人后，女主又在傅家当场拆出假药和烂腿误治
- 要求：
  - 前 `500` 字内出沉塘死局
  - 前 `1000` 字内出“相公自己睁眼”的翻局动作
  - 前 `30%` 内必须同时出现 `公审 / 第一层洗白 / 第二层更大问题`

## 最大反转点

- 真正差点害死傅行舟的，不是“恶媳下毒”，而是围着傅家吃绝户的一整圈人
- 女主开局背的不是一口锅，而是一整套方便别人吞傅家的脏名

## 情绪回本点

- 她从“该沉塘的毒妇”翻成“把活人、家和账都救回来的人”
- 真正回本的不是一句清白，而是她终于不用再低头求所有人信她
- 结尾塘边回望，完成从被按下去到自己站起来的情绪闭环

## 余波场设计

- 第3章：修门、做饭、收屋，给读者一个“她是真会过日子”的反差缓冲
- 第5章：从傅家穷困并到账线吃绝户，扩大故事不只是媳妇和婆婆争口气
- 第8章：全村公审前先把证据一件件摊平，给第9章爆发做蓄力
