# 模板应用说明｜他把津贴全寄回老家那年，我先把账本拍到了炕上

## 题型归类

- 赛道：军婚婚恋
- 变体：津贴账本 + 探亲夜翻账 + 婆家吸血反打型
- 核心结构：探亲夜当众翻账 + 小家长期失位 + 家属院群压 + 男主公开站边

## 本项目重点模板

### 1. 开头钩子模板

- 直接用 `炕上翻账` 起爆
- 前 `300` 字内必须明确：
  - 婆家先指责她不会过日子
  - 女主把账本拍上炕
  - 男主当场撞见最难堪的一幕

### 2. 证据反杀模板

这题最值钱的不是哭诉。

是：

- 津贴汇款单
- 借款记录
- 药费水电单
- 赊账本

情绪要靠证据撑，不要只靠吵架撑。

### 3. 军婚现实模板

军婚味不能只停在“丈夫当兵”。

必须补出：

- 家属院怎么议论
- 军属身份怎么压人
- 小家为什么总被“大局”吞掉
- 男主最后怎么把纪律和偏爱一起落成动作

### 4. 群像施压模板

除了婆家，还要补：

- 家属院嫂子说她计较钱
- 卫生所和赊账旧事反向证明她一直在扛
- “你是军嫂就该懂事”这套公共话术

这样后面反打才不是单纯婆媳吵架。

### 5. 男主回收模板

男主不能只说：

- 我不知道
- 你辛苦了
- 我以后改

真正有效的动作必须是：

- 查清汇款去向
- 公开划清小家和老家的账
- 当众把妻子的位置立住
- 不再让她一个人对着婆家和舆论

### 6. 结局兑现模板

结尾必须回收：

1. 津贴去向重新调整
2. 女主不再替别人白垫命
3. 婆家和家属院知道她不是爱计较，是终于不再吃亏
4. 男主站边不是嘴上说，而是公开落动作

## 发布建议

- 适合番茄短篇军婚 / 婆家吸血 / 现实婚姻反杀路线
- 标题必须保留 `津贴 / 账本 / 老家 / 炕上` 至少两个硬钩子
- 前 `30%` 优先强化：炕上翻账、汇款单、赊药费、家属院议论、男主第一次被打醒
