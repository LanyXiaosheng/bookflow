# 模板应用说明｜家属院都说我配不上他，我先把离婚报告递到了团部

## 题型归类

- 赛道：军婚婚恋
- 变体：家属院群压 + 团部递离婚报告 + 公开站位型
- 核心结构：家属院长期轻视女主 + 男主提干后沉默加剧伤害 + 女主把离婚报告递进团部 + 逼关系公开选边

## 本项目重点模板

### 1. 开头钩子模板

- 直接用 `团部递报告 + 楼下喊提干` 双场景起爆
- 前 `300` 字内必须明确：
  - 她是真的在递离婚报告
  - 他刚提干
  - 家属院一直在说她配不上

### 2. 群压模板

军婚这题不能写成单纯夫妻误会。

真正压她的是：

- 嫂子们的嘴
- 婆婆的暗示
- 热心人替他重新介绍对象
- 男主默认沉默

### 3. 公共场景模板

这篇最值钱的不是家里争吵。

而是：

- 团部
- 家属院
- 提干喜讯

这三个公开场景一起压上，军婚识别度才足。

### 4. 男主回收模板

男主补救不能只靠私下解释。

真正有效的是：

- 在家属院公开站边
- 在团部确认她的位置
- 让所有人知道：她不是拖累，也不是附属品

### 5. 结局兑现模板

结尾必须回收：

1. 女主不再被“配不配”绑住
2. 男主公开护她
3. 关系是否重建，由她决定

## 发布建议

- 适合番茄短篇军婚 / 家属院群像压迫路线
- 标题必须保留 `家属院 / 团部 / 离婚报告 / 提干` 至少两个钩子
- 前 `30%` 优先强化：递报告、提干喜讯、配不上她的议论、男主长期沉默
