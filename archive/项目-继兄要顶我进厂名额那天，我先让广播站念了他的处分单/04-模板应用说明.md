# 模板应用说明｜继兄要顶我进厂名额那天，我先让广播站念了他的处分单

## 题型归类

- 赛道：四合院年代反杀
- 变体：顶岗名额争夺 / 广播站公开打脸型
- 核心结构：病退留岗 + 继兄抢名额 + 女主抓处分单 + 广播站先播报 + 公示栏再落锤

## 本项目重点模板

### 1. 开头钩子模板

- 直接用饭桌摊牌开局
- 前 `300` 字内必须明确：
  - 顶岗名额只有一个
  - 继父和继兄已经默认拿走
  - 女主手里有一张没公开的处分单

### 2. 厂里反杀模板

这篇不能写成家里吵架。

真正的爽点在于：

- 家属院里他们以为稳了
- 女主直接去厂里拿流程、拿记录、拿处分单
- 广播站和公示栏替她公开说话

### 3. 证据模板

最有效的道具组合是：

- 处分单
- 夜班值班登记
- 仓库丢件记录
- 公示栏候选名单

有了这套链，顶岗就不是“谁家关系硬”，而是谁先翻车。

### 4. 情绪推进模板

- 第一落点：饭桌上被当场排除
- 第二落点：继兄得意，家属院劝她别争
- 第三落点：她不吵，直接去广播站
- 第四落点：广播先念名字，整个家属院一起听见他丢脸

### 5. 结局兑现模板

结局必须同时兑现：

1. 继兄资格被取消
2. 女主正式接岗

只写“他丢脸”还不够，必须写“她上岗”。

## 发布建议

- 适合番茄短篇年代打脸 / 工厂题材路线
- 标题必须保留 `继兄 / 顶岗 / 广播站 / 处分单` 至少两个钩子
- 前 `30%` 优先强化：饭桌摊牌、处分单伏笔、广播站出手、公示前夜
