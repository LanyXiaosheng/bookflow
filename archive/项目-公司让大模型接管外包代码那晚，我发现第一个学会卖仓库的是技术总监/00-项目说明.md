# 项目说明｜公司让大模型接管外包代码那晚，我发现第一个学会卖仓库的是技术总监

## 项目定位

- 平台方向：番茄短篇
- 题材：女频现代 / 大模型 / 外包黑幕 / 码奸 / 商战泄密
- 核心卖点：公司为了降本，开始让大模型接管外包代码整合与生成。所有人都以为问题在外包不可靠，只有女主发现，真正借模型把整座私有仓打包卖出去的人，不是外包，而是负责大模型接入的技术总监。他把卖仓库包装成“训练共享”“跨团队知识蒸馏”，差点把全公司核心资产一起送进竞品嘴里。

## 一句话故事

林祈负责管理公司与外包团队之间的代码交接。大模型接入后，技术总监宣布以后外包代码先走模型统一整理、补全和合并，说这是“降本增效”。结果上线第一周，林祈就在模型补全日志里发现，公司内部从不外发的基础架构模块，竟被自动打进了外包共享上下文。她一路往回查，才知道技术总监早就借“大模型协同”之名，把核心仓、接口文档和业务规则一批批送进合作方训练池，真正会卖仓库的人，根本不是外包，是负责管外包的人。

## 读点判断

- `外包 + 大模型接管代码 + 卖仓库` 非常容易勾起行业共鸣
- “大家都怀疑外包，结果技术总监才是第一个卖仓库的人” 有强反转
- 模型上下文、共享训练池、合并日志都适合做证据链
- 既有职场斗法，也有很强的现实技术感

## 爽点方向

- 开局就是模型日志里出现不该进外包上下文的核心模块
- 女主不是吵外包，而是追上下文打包链和共享池权限
- 技术总监、采购、合作方一起翻车
- 最终把“训练共享”撕成“披着 AI 外衣的卖仓行为”
