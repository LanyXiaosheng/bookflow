# 项目说明｜竞标会开标那天，他把我做了三年的旗舰方案署给白月光，招标办先调出了源文件时间戳

## 项目定位

- 平台方向：番茄短篇
- 题材：现言 / 婚恋背刺 / 职场成果反杀 / 白月光顶位 / 追妻火葬场
- 核心卖点：竞标会开标当天，男主把女主做了三年的旗舰方案署给白月光，当众让女主“先别闹，顾全大局”。所有人都以为女主又会替他忍一次，结果她没闹，只是等招标办把源文件时间戳、初版提报记录和邮件回执一起调了出来。

## 一句话故事

沈砚秋陪顾承彦从小工作室做到行业头部，三年里最值钱的旗舰方案是她熬了无数通宵一点点磨出来的。可竞标会开标这天，顾承彦却让白月光顾问程蔓站上主讲位，把那套方案堂而皇之署成了对方的名字，还当众示意沈砚秋先忍一忍，等项目拿下再解释。沈砚秋没有吵，也没有哭。她只是把自己提前备好的提报邮件、版本留档和源文件提交给招标办复核。开标结果公示前一分钟，顾承彦才知道，今天丢掉的不会只是一个项目，还有他这些年最习惯轻贱的那个人。

## 为什么现在开这条

1. 这条仍吃到已经验证过的主航道：`强关系失位 + 公开场 + 男主后知后觉`
2. 但它明确避开了已过密的旧壳：
   - `离婚当天 / 民政局`
   - `亲子鉴定 / 私生子`
   - `冷静期 / 前夫跪求`
3. 它把“后悔”换成更硬的公开利益场：
   - `竞标会`
   - `方案署名`
   - `源文件时间戳`
4. 女主不是靠哭闹逼男主回头，而是靠机构复核当场打脸，爽点更硬

## 这条题从爆款里继承什么

基于 `离婚那天，他在民政局外站了一整夜` 的后台复盘，这次保留的是它真正跑出来的三件套：

1. `时间节点`
   - 从 `离婚那天` 换成 `竞标会开标那天`
2. `明确地点`
   - 从 `民政局外` 换成 `竞标会 / 招标办`
3. `异常举动`
   - 从 `站了一整夜` 换成 `招标办先调出了源文件时间戳`

补充继承的情绪逻辑：

- 女主先在公开场被轻视
- 男主先以为她不会走、不敢翻
- 女主先不吵，直接抽掉他最稳的那块台子
- 男主的后悔必须晚到，而且来不及

## 核心冲突

### 外部冲突

1. 女主做了三年的核心方案，被男主临场署给白月光
2. 白月光以“品牌顾问 / 联合主创”身份站上主讲位
3. 竞标会是公开场，女主若当场发作，会立刻被打成“不顾大局”
4. 招标结果、公司声誉和行业关系全压在同一天

### 内部冲突

1. 女主曾经以为，顾承彦再偏也不会动她最核心的成果
2. 她最痛的不是项目被抢，而是他把她多年熬出来的东西递给另一个女人去领功
3. 她真正的成长，是从“替他守项目”转成“先把自己的名字拿回来”

## 情绪钩子

- 竞标会当天，主讲台上站的不是她，是白月光
- 她的方案被改了署名
- 男主当众让她“先别闹”
- 她没闹，招标办先把源文件时间戳调了出来
