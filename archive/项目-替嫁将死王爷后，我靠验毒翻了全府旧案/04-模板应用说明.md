# 模板应用说明｜替嫁将死王爷后，我靠验毒翻了全府旧案

## 题型归类

- 赛道：古言替嫁冲喜
- 变体：验毒翻旧案型
- 核心结构：替嫁入死局 + 第一夜验出慢毒 + 王府旧案浮出 + 夫妻联手翻案

## 本项目重点模板

### 1. 开头钩子模板

- 直接用“替嫁 + 将死王爷 + 催命药”三重钩子开场
- 前 200 字内明确：王爷不是病，是毒
- 开局先让女主用验毒能力打出差异化

### 2. 死局翻案模板

- 不是单纯写后院争宠
- 要把药房、膳房、旧案、娘家货线并成一条翻案线
- 每翻一层，都让“病”更像局，“替嫁”更像阴谋

### 3. 男女主关系模板

- 前期互相试探，不急着升温
- 中段靠查毒与查案建立信任
- 后期落到“夫妻联手翻案”而不是单向被救

### 4. 结局兑现模板

- 结局必须同时兑现两件事：
  1. 王爷毒解、旧案翻明
  2. 女主从替嫁弃子翻成真正王妃

## 情绪落点

- 第一落点：替嫁入府第一夜就验出催命药
- 第二落点：所有人都说王爷病弱，其实根本是慢毒
- 第三落点：娘家把她送来，不只是替嫁，更是灭口
- 第四落点：她不是来守寡，是来翻案的

## 发布建议

- 适合番茄短篇古言强钩子路线
- 标题必须保留“替嫁”“将死王爷”“验毒翻旧案”三个核心爆点
- 前 30%优先强化：催命药、假病真毒、后院有鬼、旧案开口
