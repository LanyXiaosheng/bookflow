# 项目说明｜今天也被他们争着宠

## 项目定位

- 平台方向：番茄短篇 / 女频甜宠副池 / 约 `1w字`
- 题材：现言甜宠 / 双男主争宠 / 书咖日常 / 修罗场 / 三人HE
- 核心卖点：女主经营书咖，先后被两个截然不同的男人闯进生活。一个清冷克制、稳得像月光，一个痞帅直球、热得像野火。两人从暗中较劲到明目张胆争宠，女主原本以为自己必须二选一，后来却被他们一起认真接住

## 一句话故事

苏栀在老城区开着一家安静的小书咖，原本只想把日子过得平稳。直到宋砚带着一册淋湿的诗集走进来，江野抱着她走丢的猫撞进门，她才发现自己同时被两个男人盯上了。一个不声不响地替她收拾所有麻烦，一个明晃晃地把偏爱都摆到她面前。等她终于承认自己谁都舍不得时，他们也给了她一个意料之外却足够温柔的答案。

## 核心冲突

- 外部：旁人默认感情只能二选一，女主家里催相亲，周围人也等着看这段关系翻车
- 内部：女主既贪恋宋砚给她的安稳，也舍不得江野带来的热烈；两个男主都想独占她，却又谁都不想逼她委屈自己
