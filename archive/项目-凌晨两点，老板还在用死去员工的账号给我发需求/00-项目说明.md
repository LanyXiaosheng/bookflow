# 项目说明｜凌晨两点，老板还在用死去员工的账号给我发需求

## 项目定位

- 平台方向：番茄短篇
- 题材：AI热题 / 职场惊悚 / 深夜聊天异象 / 悬疑怪谈
- 核心卖点：已经猝死半年的同事账号深夜上线发需求，老板却装作一切正常

## 一句话故事

入职新公司的第三周，沈屿在凌晨两点收到一条新需求，发送人竟是半年前就猝死的前项目经理。她本以为是账号没注销，直到对方发来一句：别交代码，老板在拿死人训练AI。

## 当前阶段目标

第一阶段先完成：
1. 完整故事大纲
2. 10章细纲
3. 爆点节奏表
4. 标题简介AB版

## 读点判断

- 深夜需求 + 死人账号，开局极强
- 职场读者代入感强，AI剥削感明确
- 适合短篇快节奏推进，章尾钩子密集

## 爽点 / 爆点方向

- 死人账号不是闹鬼，是被当作训练源继续榨干
- 老板越淡定，越说明公司早就默认这套黑箱流程
- 主角一边装没发现，一边顺着需求反查死人留下的后门
- 结尾可做群发曝光或线上直播翻盘
