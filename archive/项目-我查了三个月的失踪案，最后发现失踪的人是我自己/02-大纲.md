# 大纲｜我查了三个月的失踪案，最后发现失踪的人是我自己

## 故事定位

- 平台方向：番茄短篇
- 题材：悬疑 / 失踪案 / 身份谜局 / 记忆反转 / 旧案翻案
- 关键词：失忆、江边苏醒、匿名委托、监控脸、假身份、内鬼
- 核心爽点：查案查到自己、每条线索都在反咬主角、身份真相不断翻转、最后不是找回过去，而是掀翻让他消失的人

## 一句话故事

三个月前被人从江里捞上来的失忆男人陈默，在追查一桩失踪案的第九十一天，突然发现失踪者就是自己。可更可怕的是，他的“失踪”并不是意外，而是因为他在失踪前，查到了一个不该查到的人。

## 核心设定

### 主角：陈默 / 林策

- 三个月前从江里被救起，失去全部记忆
- 现用名字“陈默”是医院给的临时身份
- 真实身份是刑侦信息分析员林策
- 失踪前正在追查多起表面无关、实则相连的失踪案

### 关键助力：许棠

- 派出所实习警员
- 前期把主角当成热心线人
- 中段开始站到主角这边
- 作用是帮主角调监控、验指纹、拿卷宗

### 关键关联人：苏芷

- 林策失踪前的固定联系人
- 表面是前女友，实则是共同查案的线人律师
- 中段确认主角真实身份
- 掌握主角失踪前留下的第二层线索

### 主要反派：赵衡

- 失踪案专班负责人
- 对外是办案老手，对内是抹掉关键证据的人
- 与多起失踪案背后的利益链存在勾连
- 主角失踪，就是因为先一步查到了他

## 故事主线

### 第一阶段：监控里的人，和我长得一模一样

- 主角查失踪案第九十一天，在监控里看到失踪者正脸
- 失踪者就是自己
- 同步收到匿名短信，确认“你查的人就是你”
- 故事从失踪案瞬间切成身份谜局

### 第二阶段：所有证据开始指向我就是失踪者

- 指纹、旧疤、租房记录、手写笔记逐步吻合
- 主角确认自己真实身份是林策
- 但他仍不知道，自己为什么会失忆，为什么会出现在江里
- 匿名信封继续按节奏送来，像是过去的自己在给现在的自己布题

### 第三阶段：主角发现自己失踪前就在查一条更大的线

- 林策失踪前追查的并不是普通人口失踪，而是多起被人为抹平的“意外失联”
- 这些人都在失踪前接触过同一批卷宗
- 苏芷现身，确认主角当时已经怀疑到赵衡
- 主角意识到，自己不是被随机袭击，而是被灭口未遂

### 第四阶段：恢复的不是完整记忆，而是作局痕迹

- 主角回到自己失踪前租的安全屋
- 里面藏着给“失忆后的自己”准备的线索墙、录音和硬盘
- 录音里明确告诉他：如果你看到这些，说明赵衡已经先动手了
- 主角终于知道，匿名委托人其实就是失踪前的自己

### 第五阶段：原来我不是消失了，我是被人从系统里抹掉了

- 主角查到自己的报案记录、住院记录和身份调档都被人篡改
- “陈默”这个身份不是巧合，而是赵衡安排出来方便盯梢的壳
- 赵衡一直在观察主角有没有恢复记忆
- 主角正式从追身份转入反杀

### 第六阶段：把我变成失踪者的人，终于被我翻出来了

- 主角和许棠、苏芷联合，把赵衡引到旧码头仓库
- 现场拿到失踪案总账、篡改记录和主角遇袭视频
- 赵衡以为主角记忆残缺，结果主角提前布下发布链
- 真相被同步放出去，主角完成“找回自己”和“翻出黑手”双收束

## 核心反转设计

1. 失踪案的失踪者，就是正在查案的主角自己
2. 匿名委托人不是别人，是失踪前的主角给未来失忆的自己留的线
3. 主角并不是普通失忆受害者，而是因为查到内鬼才被抹掉身份
4. “陈默”不是新人生，而是反派给他的监视壳

## 结局方向

- 赵衡翻车，多起旧失踪案重启调查
- 主角恢复真实身份“林策”，但会保留“陈默”这三个月带来的新视角
- 结尾情绪点不是“我想起一切了”，而是：
  即便忘了自己是谁，我还是会把真相查出来
