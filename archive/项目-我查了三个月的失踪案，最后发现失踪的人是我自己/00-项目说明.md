# 项目说明｜我查了三个月的失踪案，最后发现失踪的人是我自己

## 项目定位

- 平台方向：番茄短篇
- 题材：悬疑 / 失踪案 / 身份谜局 / 记忆反转 / 都市翻案
- 核心卖点：查失踪案查到自己头上、主角失忆但能力还在、所有线索都在指向“你就是失踪者”、最后兑现身份与旧案双反转

## 一句话故事

三个月前，陈默被人从江里捞上来，失去了全部记忆。三个月后，他在监控里看见失踪者抬头，那张脸和自己一模一样。

## 核心冲突

### 外部冲突
1. 主角查了三个月的失踪案，结果所有证据都在指向自己
2. 警方、匿名委托人和旧案相关人都在同时盯着他
3. 他越接近真相，越发现自己的失踪不是意外，而是有人想让他永远回不来

### 内部冲突
1. 主角最怕的是自己真是凶手或帮凶
2. 他没有记忆，只能一边查案一边怀疑自己
3. 真正的成长，是在“我是谁”彻底崩塌后，仍然敢把真相追到底

## 情绪钩子

- 失踪者的脸就是我自己
- 匿名委托人持续给主角送线索
- 主角的真名、旧身份和过去的工作都被人刻意抹掉
- 结尾不是单纯恢复记忆，而是找回自己为什么会消失
