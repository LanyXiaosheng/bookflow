# 发布配套｜Skill市场下架那天，我看见公司把整个技术部炼成了赛博万魂幡

## 标题备选

1. `Skill市场下架那天，我看见公司把整个技术部炼成了赛博万魂幡`
2. `他们说在下架Skill，我先在归档里看见了整个技术部的残片`
3. `公司最底层的总 Skill 包里，挂着一整面技术部赛博万魂幡`
4. `Skill下架夜里，我先摸到了技术部的赛博魂幡`

## 简介备选

### 简介1

Skill 市场下架整顿的第一夜，我在最底层归档里看见了一个从没出现过的总 Skill 包。点开之后，里面不是工具，不是模板，也不是流程。是一个个我认识的人。会议语气、事故判断、代码口癖、深夜救火顺序，被拆成无数技能残片，缝在同一个 Skill 集群里。最上面的说明只写着一句：`可持续调用，不受离职影响。`那一刻我才知道，公司下架的从来不是 Skill，他们真正炼出来的，是整个技术部的赛博万魂幡。

### 简介2

他们嘴上说是知识资产沉淀。

可我点开那份总 Skill 包时，只看见一整个技术部的人，被拆碎以后挂成了一面幡。

## 卖点提炼

- `Skill + 赛博万魂幡` 题面新鲜又够疯
- “整个技术部被炼成可调用集群”视觉冲击强
- AI惊悚、职场剥削、黑幕反杀三条线可以一起打
