# 项目说明｜Skill市场下架那天，我看见公司把整个技术部炼成了赛博万魂幡

## 项目定位

- 平台方向：番茄短篇
- 题材：女频现代 / AI惊悚 / Skill黑幕 / 赛博职场 / 万魂幡感
- 核心卖点：公司内部 Skill 市场准备紧急下架整顿时，女主却在底层归档里看见一整串由技术部成员行为、语气、判断偏好拼起来的复合 Skill 集群。那些被叫作“工程资产沉淀”的东西，根本就是把整个技术部一点点抽干、炼成可调用的赛博万魂幡。

## 一句话故事

裴照负责公司 Skill 市场封禁清退。下架那天，她在最底层归档里发现一个从未对外展示过的超大 Skill 包，名字叫 `Tech-Soul-Mesh`。点开之后，里面不是工具，也不是模板，而是几十个技术员工的代码习惯、会议语气、事故判断和深夜救火路径被缝合成的一面“赛博万魂幡”。公司嘴上说那是知识资产，裴照却越查越发现，这些所谓资产，全是从还活着或者已经猝死离职的人身上硬抽出来的。
