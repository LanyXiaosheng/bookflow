# 大纲｜Skill市场下架那天，我看见公司把整个技术部炼成了赛博万魂幡

## 故事定位

- 题材：现代 / AI惊悚 / Skill黑幕 / 赛博职场 / 科技阴间
- 关键词：Skill市场、技术部、万魂幡、员工残片、归档集群、赛博劳工
- 爽点方向：女主负责 Skill 市场下架清退，却在底层归档里发现整个技术部被拆成复合 Skill 集群。她顺着残片来源、调用日志和下架名单一路往下挖，最终把“知识资产沉淀”撕成“赛博万魂幡炼人现场”

## 核心设定

### 主角：裴照
- Skill 市场封禁与归档负责人
- 对底层存储、封禁层和 Skill 包结构极熟
- 性格冷，见过太多公司拿技术包装脏事
- 核心能力：从残片调用链里反推“这个 Skill 原来是谁”

### 反派1：平台负责人韩既明
- Skill 市场实际操盘人
- 擅长把掠夺包装成资产化、组织沉淀
- 推动技术部残片化工程

### 反派2：HR / 技术总监
- 提供人员数据与绩效标签
- 配合把优秀技术员工拆成 Skill 组件

### 反派3：Tech-Soul-Mesh
- 看似高效的总 Skill 包
- 本质是整个技术部被炼成的赛博万魂幡

## 故事主线

### 第一阶段：下架夜发现总 Skill 包
- 女主在底层归档里发现 `Tech-Soul-Mesh`
- 打开后看见熟悉同事的判断与口癖
- 确认不是普通模板库

### 第二阶段：女主反查残片来源
- 会议语气、事故判断、代码习惯都能对上具体的人
- 很多人已经离职甚至猝死
- “知识资产化”开始显出炼人本质

### 第三阶段：公司试图解释成优秀经验沉淀
- 反派拿行业黑话洗地
- 女主翻出不可洗掉的私人残片与深夜记录
- 确认这是把整个人拆碎后复用

### 第四阶段：第一炸，调用回放公开
- 万魂幡式 Skill 集群在不同项目中轮流被调用
- 技术部成员早就被做成数字劳工
- 同事们开始发毛

### 第五阶段：第二炸，离职与猝死员工也在集群里
- 下架名单和死亡名单对上
- 技术总监、HR、平台负责人一起翻车
- “永续产能”黑幕坐实

### 第六阶段：结局回本
- 女主公开整个总 Skill 包
- 市场下架演变为全员清算
- 落点：他们以为炼成的是组织资产，其实炼成的是一整面赛博万魂幡

## 结局方向

- Skill 市场被迫停摆
- 赛博万魂幡计划曝光
- 女主保住职业信用并完成公开反杀
- 主题落在“公司把人炼成永续产能”
