# 大纲｜认尸那天，法医忽然问我：你确定死的人是你姐姐吗

## 故事定位

- 平台方向：番茄短篇
- 题材：女频悬疑 / 豪门假死局 / 姐妹互救 / 身份翻案
- 关键词：认尸、火化单、耳后旧疤、延时语音、疗养院、遗产授权、假死夺位
- 核心爽点：所有人都想让女主尽快签字火化，女主偏要在灵堂前证明“死的人不是我姐姐”

## 一句话故事

豪门太太宋听岚“坠海身亡”后，妹妹宋南栀被叫去认尸。法医一句“尸体耳后没有你姐姐的旧疤”，让宋南栀意识到姐姐不是死了，而是被人用另一具尸体顶替了身份。她顺着姐姐生前留下的延时语音，一路查到私人疗养院和一份被急着生效的遗产授权书，才发现这场假死局真正要吞掉的，从来不只是一个人，而是姐姐手里那份足以掀翻陆家的证据链和控制权。

## 核心设定

### 女主：宋南栀

- 宋听岚的亲妹妹
- 和姐姐关系复杂，过去一直活在姐姐光环下
- 反应快，擅长整理影像和电子资料
- 一开始只是想搞清楚姐姐到底死没死，后面被逼成救人和翻案的人

### 核心失踪者：宋听岚

- 陆家儿媳，掌握丈夫陆承泽的资产转移证据
- 出事前已经在准备离婚和撤销部分授权
- 预判自己可能会“被死亡”，提前留了延时语音和线索

### 关键助力：程叙白

- 负责本次尸检的法医
- 说话冷，但专业硬
- 因为认出尸体特征不对，成为第一个撬开假死局的人

### 主要反派：陆承泽

- 宋听岚的丈夫
- 表面深情守丧，实则急着让“妻子死亡”生效
- 真实目的，是吞掉宋听岚名下授权、压掉财务旧账，再把所有问题推给“已死之人”

## 故事主线

### 第一阶段：认尸现场先炸

- 宋南栀赶到停尸房认尸
- 程叙白指出尸体耳后没有宋听岚小时候留下的缝针疤
- 陆家却强压流程，要求尽快签火化单
- 女主第一次意识到：所有人都比她更想让姐姐快点“死透”

### 第二阶段：姐姐生前留下的延时线索开始回流

- 宋南栀在姐姐旧手机云端里收到定时语音
- 语音第一句就是：“如果他们催你签火化单，别签。”
- 她顺着线索找到姐姐寄存在摄影工作室里的存储卡
- 卡里有陆承泽转移公司资金和伪造债务的片段证据

### 第三阶段：假死不是为了情感，是为了夺位

- 宋南栀查到宋听岚名下一份“死亡即自动生效”的授权安排
- 陆承泽正借“丧偶”身份准备董事会和资产切割
- 死者的身份被急着坐实，是为了让姐姐替所有旧账背锅
- 女主明白：如果认错尸，姐姐就真的回不来了

### 第四阶段：真姐姐没死，但被关在看不见的地方

- 存储卡第二段视频指向一家私人疗养院
- 宋南栀和程叙白查到姐姐被伪造“精神不稳”记录
- 真相是陆承泽把宋听岚控制在疗养院，等外界先认定她已死亡
- 而停尸房那具尸体，是被拿来顶替她身份的司机助理

### 第五阶段：灵堂和董事会一起掀桌

- 陆承泽准备在追悼会后同步推进授权生效和董事会表决
- 宋南栀抢在他完成切割前，把火化叫停、把尸检疑点甩上台面
- 程叙白补上医学证明，疗养院监控和授权撤销记录也同步公开
- 宋听岚被救出，活人回场，假死局当场反噬陆承泽

### 第六阶段：真正被埋的不是尸体，是他们想吞掉的那个活人

- 顶替尸身份查明，命案和非法拘禁并案
- 陆承泽翻车，陆家守丧人设崩塌
- 宋南栀第一次不是在姐姐影子里活，而是亲手把姐姐带回来了
- 宋听岚拿回决定自己人生和资产的权力

## 核心反转设计

1. 尸体不是姐姐，停尸房第一句就把故事掀开
2. 假死局的目的不是“骗情”，而是“让死亡先于真相生效”
3. 姐姐不是单纯失踪，而是被人伪造成精神异常后秘密控制
4. 最终要翻的不只是认尸错误，而是整个授权夺位链

## 结局方向

- 宋听岚获救，顶替尸身份被查清
- 陆承泽因非法拘禁、伪造文书、财务犯罪同时翻车
- 宋南栀和姐姐重新站到同一边
- 最后收束不是哭灵，而是姐妹二人一起撕掉那张差点把活人写成死人的火化申请
