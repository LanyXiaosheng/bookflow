# 项目说明｜认尸那天，法医忽然问我：你确定死的人是你姐姐吗

## 项目定位

- 平台方向：番茄短篇
- 题材：女频悬疑 / 豪门隐案 / 假死夺位 / 姐妹互救 / 身份翻案
- 核心卖点：认尸现场第一句就起炸点；所有人都催着火化；女主顺着一具“不该是姐姐”的尸体，把豪门假死局和资产吞并局一起掀了
- 当前阶段：`2026-04-21` 首轮立项

## 一句话故事

姐姐坠海身亡后，宋南栀被叫去认尸。可法医在停尸房里看着那具尸体，忽然问了她一句：“你确定死的人是你姐姐吗？”一句话，让宋南栀意识到这场死亡通告从一开始就是假的。真正死去的人另有其人，而真正失踪的姐姐，正被人按在看不见的地方，等着被宣布“已经死了”。

## 当前阶段目标

第一阶段先完成：

1. 钉死前 `30%` 的认尸钩子和火化死局
2. 完成 `00 / 02 / 03 / 04 / 07` 五件套
3. 把悬疑线收束成“身份错认 + 假死夺位 + 活人救援”的短篇可写结构

## 读点判断

- `认尸` 自带高压和代入
- 法医第一句直接打掉“这就是姐姐”的确定感
- 火化时限让全篇天然有倒计时
- 真正的爽点不是查鬼，而是查活人如何把另一个活人做成“死人”

## 爽点 / 爆点方向

- 停尸房认尸时第一刀先落下
- 女主不是哭崩，而是当场卡住火化流程
- 中段不断回流：姐姐的延时语音、被删掉的监控、被伪造的签字
- 结尾不做阴森收束，做公开翻案和活人回场
