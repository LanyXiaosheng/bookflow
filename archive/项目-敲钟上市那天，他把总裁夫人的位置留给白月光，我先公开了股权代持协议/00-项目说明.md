# 项目说明｜敲钟上市那天，他把总裁夫人的位置留给白月光，我先公开了股权代持协议

## 项目定位

- 平台方向：番茄短篇
- 题材：现言 / 婚恋背刺 / 公司上市 / 股权反杀 / 追妻火葬场
- 核心卖点：男主为了上市形象和白月光双双站上敲钟台，把原配彻底晾在台下。所有人都以为女主只会当场失态，结果她反手公开股权代持协议，让所有投资人知道，这家公司从来不是他一个人的。
- 当前阶段：`2026-04` 下半月主航道优先立项

## 一句话故事

顾行舟创业那几年，林晚宁替他垫钱、跑资源、扛风波，还把自己名下的股份拆成代持留给他过会。公司终于敲钟上市那天，顾行舟却让白月光以“品牌顾问”的身份站上台，把原本属于林晚宁的总裁夫人位置堂而皇之让了出去，甚至当众暗示林晚宁别在现场闹。林晚宁没有闹，她只是把早已备好的股权代持协议、资金流水和董事会留档一起公开。直播镜头前，所有人才第一次看清，这个被顾行舟当成“前台门面”的男人，连手里最值钱的股份都不是干净握着的。

## 当前阶段目标

第一阶段先完成：

1. 钉死标题和简介压强
2. 保证前 `30%` 内出现：
   - 敲钟现场失位
   - 白月光顶位
   - 股权代持第一炸
3. 后续再判断是否进入完整项目生产

## 读点判断

- `敲钟上市` 自带强围观场和公开羞辱场
- `总裁夫人位置被白月光抢走` 是明确失位
- `股权代持协议` 是非常硬的翻盘物件
- 这题不靠“他后悔”，而是靠“他以为上市成功就能抹掉我”

## 爽点 / 爆点方向

- 开局就是上市敲钟现场座位和站位之争
- 女主不是去哭闹，而是带着协议和留档进场
- 第一炸是代持协议公开
- 第二炸是资金流水和董事会留痕回流
- 结尾要做到：他想借上市把女主从公司和婚姻里一起抹掉，女主先把他最值钱的资本外衣撕了
