# 大纲｜敲钟上市那天，他把总裁夫人的位置留给白月光，我先公开了股权代持协议

## 故事核心

顾行舟创业那几年，林晚宁出钱、出资源、出人脉，还为了帮他过会，把自己名下的一部分股份做成代持留给他。公司终于上市敲钟这天，顾行舟却让白月光顶掉林晚宁的位置，把她彻底晾在台下，还当众警告她别闹。林晚宁没有闹，她直接公开股权代持协议、资金流水和董事会留档，让投资人和媒体一起看清，顾行舟今天站上的不是自己的高台，而是她替他搭出来的台阶。故事后半程不写她回头，而写她如何把被偷走的股份、身份和话语权一层层拿回来。

## 主线五段

1. 上市敲钟现场失位开局  
   顾行舟和白月光站上高台，林晚宁被挡在台下，男主当众让她体面一点。

2. 股权代持协议第一炸  
   女主不争吵，直接在最公开的场子里把代持协议和早年出资证据放出来，打穿“顾氏全靠顾行舟”的神话。

3. 资金来源和旧账回流  
   媒体、投资人、董事会开始倒查。白月光的人设、顾行舟的创业叙事、婚姻里对女主的长期压榨一起崩。

4. 男主想补救，女主只谈权益  
   顾行舟试图压舆论、谈补偿、谈感情。林晚宁不接情绪，只要求实名权益、股份清算和婚姻切割。

5. 女主拿回资本身份，男主失去控制权  
   公司和婚姻都不再是顾行舟单方面定义的舞台。林晚宁以真正股东身份站回台前，顾行舟则被留在自己亲手制造的后悔里。
