# 模板应用说明｜提离婚申请那天，失联半年的他带着一等功回了家属院

## 题型归类

- 赛道：军婚婚恋
- 变体：失联归来 + 离婚申请 + 家属院站位型
- 核心结构：女主先递离婚报告 + 男主带军功归来 + 家属院替他说话 + 女主摊开半年旧账 + 男主公开站边

## 本项目重点模板

### 1. 开头钩子模板

- 直接用 `团部递离婚报告 + 家属院迎功` 双场景对冲开场
- 前 `300` 字内必须同时出现：
  - 女主不回头
  - 男主带一等功归来
  - 她是真的不想再等了

### 2. 军婚等待模板

这篇不是普通追妻。

真正值钱的是：

- 失联半年
- 任务保密
- 所有人都拿“军属要懂事”压她
- 她不是不理解任务，是不想再替所有人顾大局

### 3. 家属院群压模板

军婚味不能只靠军功。

必须把：

- 婆婆挪津贴
- 小叔子填窟窿
- 嫂子们劝和
- 家属院默认她该等

全写出来。

### 4. 关系回收模板

男主回收不能靠解释任务危险。

最有效的动作是：

- 查津贴
- 收回钱和钥匙
- 当众给她正名
- 明确告诉家属院和婆家：她不是替我受着的人

### 5. 结局兑现模板

结尾不要急着复合。

先回收：

1. 她的体面
2. 他的站边
3. 家属院对她的重新认知

## 发布建议

- 适合番茄短篇军婚 / 家属院群像路线
- 标题必须保留 `离婚申请 / 失联 / 一等功 / 家属院` 里至少两个钩子
- 前 `30%` 优先强化：团部递报告、迎功场面、津贴被挪、她彻底不想等
