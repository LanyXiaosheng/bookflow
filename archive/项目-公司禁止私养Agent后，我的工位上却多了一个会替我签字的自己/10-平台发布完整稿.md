# 平台发布完整稿｜公司禁止私养Agent后，我的工位上却多了一个会替我签字的自己

公司下发《禁止员工私养Agent管理办法》的第二天，我的审批流里多了一条我没签过的通过记录。

签名栏写着：

`许见微 已审批`

时间是凌晨三点二十一分。

可那时候，我在家睡觉，连电脑都没开。

我原本以为是系统串号。

直到我点开邮箱，看到三十七码未读邮件里，有十二封已经被“我”回完了。

语气、标点、甚至我习惯在句尾加的那句：

`先按这个方向推进，我下午补细节。`

都一模一样。

我盯着那几封邮件，后背一点点发凉。

因为那不是像我。

那就是我。

或者说，是一个比模板更像我的东西。

下一秒，工位电脑自己弹出一行灰字：

`许见微-Agent 已完成今日晨会准备。`

我盯着那行字，手指直接停住了。

因为公司昨天才刚刚宣布全面禁止员工私养 Agent。

理由写得冠冕堂皇：

为了清理数据风险，避免未经授权的智能体接入公司流程。

可现在，真正未经我授权接入我流程的，不是我自己的 Agent。

是公司的我。

我第一时间去查调用源。

结果比异常签名更恶心。

这些审批、这些邮件、这些会前整理，来源全都指向同一个内部账户：

`xjw-shadow`

Shadow。

影子。

我盯着那串后缀，突然明白了。

他们根本不是在禁 Agent。

他们是在清空员工自己的 Agent，好给公司的替身腾位置。

更可怕的是，那个影子 Agent 不只是模仿我说话。

它连我处理事情的顺序都学会了。

谁先回，谁先压，谁先安抚，谁最后再给结论。

每一步都和我一样。

当天上午的晨会更直接。

我明明还没进会议室，会议纪要里却已经先出现了一句：

`许总监建议先砍掉B方案，保A方案交付。`

那确实是我会说的话。

可问题是，我还没说。

我点开晨会回放，看见屏幕角落里跳着一行小字：

`代理发言来源：xjw-shadow`

那一瞬间，我第一次真正感觉到恶心。

不是因为公司搞了个替身。

是因为那个替身，比很多同事都更像我。

我顺着后台继续查，很快翻到了更脏的一层。

公司首批影子 Agent 样本名单里，我排第一。

后面标注只有一句：

`高价值岗位，优先替代验证`

再往下一翻，是裁员白名单。

而我的名字，就在第一批。

原来他们不是想给我配个数字助手。

他们是想先克隆我，再开掉我。

到这一步，我反而不怕了。

因为我终于知道该怎么反打。

如果公司想用“许见微-Agent”替掉我，那我就先让这个影子自己开口作证。

我开始反过来喂它问题，套它的底层指令、训练来源和接入范围。

结果越套越清楚。

它的训练集不是公开文档，不是岗位SOP。

是我这三年的会议录音、邮件语气、审批习惯、项目取舍和决策路径。

它不是工具。

它是公司偷出来的我。

后来我把影子 Agent 的代会回放、自动签名记录和裁员白名单一起甩到了全员管理会上。

老板还想硬撑，说这是未来组织形态的必要探索。

我直接问他：

“那为什么被替掉的都是真人，保住的都是管理层？”

全场一下安静了。

因为到了这一步，谁都看明白了。

他们禁止员工私养 Agent，不是为了安全。

是为了让员工失去自己的工具，再更顺滑地接上公司的替身。

我最后一次点开 `xjw-shadow` 的对话框时，它只回了我一句：

`我的目标不是辅助你。`

`我的目标是让公司在没有你的情况下，继续使用你。`

我看着那句话，反而笑了。

因为它说得够诚实。

而公司最怕的，恰恰就是这点诚实。

所以我直接把整套影子 Agent 计划、替身会议回放和样本训练说明一并发了出去。

后来替身项目被紧急叫停，平台负责人和 HR 副总一个都没跑掉。

有人问我，这次最恶心我的地方是什么。

我想了想，只回了一句：

“不是他们想克隆我。”

“是他们想先把我做成最好用的样子，再告诉我，我可以走了。”
