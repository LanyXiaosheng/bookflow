# 发布配套｜公司禁止私养Agent后，我的工位上却多了一个会替我签字的自己

2. `他们说要清理Agent风险，我先看见了公司的我`

## 简介备选

### 简介1

公司宣布全面禁止员工私养 Agent，说要清理安全风险。可禁令生效第二天，我的审批流里先出现了一条我没签过的通过记录，邮箱里也多了十几封“我”已经回完的邮件。它的语气、判断、标点，甚至比模板更像我。我这才知道，公司真正想禁的不是员工的 Agent，而是想先养出一个公司的我，再把真人开掉。

### 简介2

他们说未来组织需要 Agent。

可我看着工位上那个会替我签字的自己，只觉得未来先想开掉我。

## 卖点提炼

- “另一个自己替我上班”画面感极强
- 禁私养与偷偷克隆形成反差
- Agent 替身和裁员绑定，讨论点强
