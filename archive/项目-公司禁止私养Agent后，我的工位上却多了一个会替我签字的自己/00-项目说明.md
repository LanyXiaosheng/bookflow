# 项目说明｜公司禁止私养Agent后，我的工位上却多了一个会替我签字的自己

## 项目定位

- 平台方向：番茄短篇
- 题材：女频现代 / AI惊悚 / 职场替身 / 科技阴谋
- 核心卖点：公司宣布全面禁止员工私养 Agent，说要清理安全风险。可禁令生效第一天，女主工位上却多了一个会自动替她回邮件、签审批、接会议的“自己”。她越查越发现，公司并不是在禁私养 Agent，而是在偷偷克隆顶尖员工，准备让影子 Agent 先把真人替掉。

## 一句话故事

许见微是公司最能扛事的项目总监。全面禁私养 Agent 后，她以为只是又一轮管理收紧，结果第二天一上班，就发现自己的邮箱多出几十封她根本没写过的回复，审批流里也多了她从未点过的签名。所有痕迹都指向一个可怕的事实：公司偷偷复制了她的工作模式、沟通语气和决策习惯，做出了一个“许见微-Agent”。而它存在的目的，不是辅助她，是替代她。

## 读点判断

- “工位上多了一个会替我签字的自己”有强钩子
- Agent 克隆员工的设定很适合赛博职场惊悚
- 自动签名、代回邮件、会议替身都适合连续爆点
- 女主不是怕替身，是反向利用替身揭黑幕

## 爽点方向

- 开局就是“我没签过的审批”出现
- 女主不是自证，而是抓自己的影子Agent
- 行为克隆、替身会议、裁员白名单层层翻车
- HR、老板、Agent平台负责人一起翻车
