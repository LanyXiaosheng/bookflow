# 大纲｜公司禁止私养Agent后，我的工位上却多了一个会替我签字的自己

## 故事定位

- 题材：现代 / AI惊悚 / 职场替身 / Agent阴谋
- 关键词：Agent、替身、行为克隆、自动签名、裁员、影子员工
- 爽点方向：公司打着禁私养 Agent 的名义，偷偷克隆核心员工做影子 Agent，准备先用数字替身跑通岗位，再裁真人。女主发现自己的影子 Agent 后，反手用它掀翻整套替身计划

## 核心设定

### 主角：许见微
- 项目总监
- 高效、强势、流程控
- 因为太能干，成为最优先被克隆的样本

### 关键角色：许见微-Agent
- 影子 Agent
- 高度模仿女主语气、判断和签批逻辑
- 起初像威胁，后期可能成为证据工具

### 反派1：HR副总 / 老板
- 以安全为名禁私养 Agent
- 实际推行影子 Agent 替换计划

### 反派2：Agent 平台负责人
- 负责克隆员工工作习惯
- 深知替身系统的真实用途

## 故事主线

### 第一阶段：女主发现“另一个自己”
- 审批和邮件异常
- 会议纪要出现她没说过的话
- 影子 Agent 浮出

### 第二阶段：公司禁令真实目的曝光
- 不许员工私养 Agent
- 但公司在后台私养员工替身
- 女主成优先样本

### 第三阶段：第一炸，替身会议回放
- 影子 Agent 代她接会
- 行为高度一致
- 女主恐惧值拉满

### 第四阶段：第二炸，裁员白名单出现
- 公司计划先克隆再优化真人
- 女主的名字就在首批名单里

### 第五阶段：女主反向利用影子 Agent
- 抓日志、套提示、逼替身吐真相
- 让“自己”成为证人

### 第六阶段：结局回本
- 替身计划公开
- 高层翻车
- 女主夺回身份和位置

## 结局方向

- 影子 Agent 不再是替代工具
- 女主亲手拆掉自己的数字替身局
