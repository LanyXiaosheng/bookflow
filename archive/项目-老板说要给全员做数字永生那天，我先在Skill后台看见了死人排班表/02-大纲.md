# 大纲｜老板说要给全员做数字永生那天，我先在Skill后台看见了死人排班表

## 故事定位

- 题材：现代 / Skill / 数字永生 / 赛博惊悚 / 职场黑幕
- 关键词：数字永生、死人排班表、Skill后台、夜班、事故兜底、死后上班
- 爽点方向：老板高调宣传数字永生，女主却在 Skill 后台第一时间看见一张死人排班表。她顺着排班模块、技能残片和历史人名一路查，最终把“数字永生福利”撕成“死后继续替公司打工的赛博排班系统”

## 核心设定

### 主角：江砚白
- Skill 平台后台排班模块负责人
- 对排班逻辑、Skill 接管链和后台埋点极熟
- 理性尖锐，不信大词
- 核心能力：从排班表里挖出不该出现的人

### 反派1：老板 / 平台总监
- 推动数字永生计划
- 擅长把死后劳役包装成组织福利

### 反派2：HR / Skill运营
- 提供人物标签和历史绩效
- 把优秀员工拆成可排班工种

### 反派3：死人排班系统
- 表面是数字永生调度平台
- 本质是让死人和离职者继续上班的后台

## 故事主线

### 第一阶段：后台出现死人排班表
- 女主在测试环境里看到死人名字排夜班
- 数字永生第一时间黑掉
- 开局极强反差

### 第二阶段：女主反查排班与 Skill 包来源
- 排班不是假数据，而是真调用真值守
- 死人与离职人员被拆成 Skill 工种
- “永生”开始变成役鬼

### 第三阶段：公司试图用福利和传承话术洗地
- 女主找到历史人名、追悼记录和后台映射
- 确认不是纪念，是继续驱使
- 情绪升级

### 第四阶段：第一炸，死后夜班链公开
- 全公司知道死人还在值班
- 工位开始发毛
- 老板口径崩裂

### 第五阶段：第二炸，数字永生计划本质曝光
- 事故兜底、客户安抚、紧急需求都压给死人排班
- 组织剥削被看穿
- 高层翻车

### 第六阶段：结局回本
- 排班后台被停
- 女主公开拆局
- 落点：公司说的永生，不是让人活下去，是让他们死后也继续上班

## 结局方向

- 数字永生项目暂停
- 女主保住职业信用
- 死后排班真相曝光
- 强记忆点落在“死人夜班表”
