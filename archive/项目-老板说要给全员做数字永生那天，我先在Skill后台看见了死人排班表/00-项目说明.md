# 项目说明｜老板说要给全员做数字永生那天，我先在Skill后台看见了死人排班表

## 项目定位

- 平台方向：番茄短篇
- 题材：女频现代 / Skill / 数字永生 / 赛博惊悚 / 职场黑幕
- 核心卖点：老板高调宣布要给优秀员工做“数字永生”，所有人都以为是福利升级。只有女主在 Skill 后台第一时间看见一张死人排班表，上面排着几个三年前就已经离职、猝死甚至被内部抹掉的人名。她这才知道，公司说的永生，不是让人活下去，而是让他们死后也继续上班。

## 一句话故事

江砚白负责 Skill 平台后台排班模块。老板发布“数字永生员工计划”当天，她在测试环境里看见了一张从未公开的内部排班表，夜班、事故、客户安抚、需求兜底，全都排给了几个早已不该再出现的人名。顺着这张死人排班表查下去，她发现公司所谓的数字永生计划，其实是把优秀员工拆成 Skill 排班工种，让他们死后也继续为组织填坑。

## 读点判断

- “死人排班表”本身就有极强传播性
- 数字永生包装成福利，反转成死后继续上班，非常适合职场恐怖
- Skill 后台和排班系统能做出很强证据链
- 可写得又疯又冷，特别有赛博压迫感

## 爽点方向

- 开局就是后台出现死人夜班表
- 女主顺着排班、Skill包、历史人名一路查
- 老板讲永生，女主先讲加班鬼
- 最后把“数字永生”撕成“死后继续给公司打工”
