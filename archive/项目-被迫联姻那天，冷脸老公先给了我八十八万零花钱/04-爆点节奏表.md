# 爆点节奏表｜被迫联姻那天，冷脸老公先给了我八十八万零花钱

## 节奏总览

- 紧场：第 `1 / 2 / 3 / 4 / 6 / 8 / 9 / 10` 章
- 松场：第 `5 / 7` 章
- 松场功能：
  - 第5章：用生活细节堆出男主的稳定偏爱
  - 第7章：把“她被护着”推进到“她开始心动”

## 关键爆点

- 第1章：新婚夜冷脸丈夫先甩八十八万零花钱
- 第3章：豪门堂妹嘲她拜金，男主一句“她花的是我的钱”完成第一轮护短
- 第4章：女主娘家来吸血，男主直接律师清场
- 第6章：家宴站位公开偏向女主，联姻摆设身份开始翻盘
- 第9章：男主承认不是被迫联姻，是他亲自选了她
- 第10章：公开认爱，联姻婚姻变真婚姻

## 前30%卡点

- 最好卡在：`八十八万到账 -> 豪门轻视 -> 男主第一轮护短`
- 要求：
  - 前 `500` 字内必须出现 `联姻 + 八十八万`
  - 前 `1000` 字内必须出现 `豪门轻视`
  - 前 `30%` 内必须完成：
    - `零花钱到账`
    - `主卡给到女主`
    - `男主公开说她可以花`

## 最大甜点

- 男主不是忽然变温柔，而是从第一天起就在替她兜底
- 女主不是一味依附，而是在被尊重里慢慢敢相信这段婚姻

## 结尾兑现

- 公开护短
- 公开身份
- 公开认爱
- “八十八万零花钱”从交易感，回收到偏爱感
