# 项目说明｜被迫联姻那天，冷脸老公先给了我八十八万零花钱

## 项目定位

- 平台方向：番茄短篇
- 题材：现言甜宠 / 豪门联姻 / 先婚后爱 / 冷脸老公 / 护短偏爱
- 核心卖点：女主被迫联姻，本以为自己要去豪门受气，结果新婚第一晚，冷脸丈夫先扔来一张银行卡，每月固定打八十八万零花钱；嘴上说只是联姻工具，行动上却处处护她、宠她、给她撑腰

## 一句话故事

宋晚澄被家里推去联姻那天，已经做好了豪门受委屈的准备。可新婚第一晚，傅沉砚把一张银行卡放到她面前，淡声说：“每月八十八万，别委屈自己。”她以为自己只是嫁给了一个冷脸金主，后来才发现，这个全京圈最难接近的男人，早就把偏爱都给了她。

## 核心冲突

- 外部：联姻婚姻没有感情基础、豪门亲属轻视、女主娘家拿她当资源交换口、外界都在等这段婚姻翻车
- 内部：女主以为自己只是“被安置”，男主却在相处里一点点让她知道，她不是工具人，而是被他认真选中的妻子
