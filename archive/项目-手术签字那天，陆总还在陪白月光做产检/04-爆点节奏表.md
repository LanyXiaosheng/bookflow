# 爆点节奏表｜手术签字那天，陆总还在陪白月光做产检

## 节奏总览

- 紧场：第 `1 / 2 / 3 / 4 / 5 / 7 / 8 / 9 / 10` 章
- 松场：第 `6` 章
- 松场功能：
  - 第6章：在高压证据回流后，给白月光翻车和女主切割一个更清晰的缓冲场，让后面的离婚与情绪回本更重

## 爆点类型覆盖

- 生死冲突：第 `1 / 2 / 4 / 8` 章  
  手术、高危出血、值班医生证词、手术单回收
- 关系反转：第 `3 / 7 / 9 / 10` 章  
  女主从求助到切割，男主从缺席到追悔
- 信息揭示：第 `4 / 5 / 6 / 8` 章  
  监控、陪诊记录、挂号单、未接电话、产检真相
- 情绪失衡：第 `1 / 3 / 7 / 8 / 10` 章  
  手术签字缺席、醒来离婚、正面摊牌、男主崩塌、最终回收

## 第1章炸点

- 女主宫外孕大出血被推上手术台
- 医生要求配偶签字，男主始终不接电话
- 女主自己签字进手术室

## 第3章爆点

- 女主醒来后不哭不闹，直接拟离婚协议
- 男主还想用“你先冷静”压事
- 女主第一次彻底不解释，只切割

## 第5章爆点

- 男主查出林晚晚那天并非急症
- 陪诊不是无奈，是他主动的选择
- 读者对男主的怒点在这里被二次拉高

## 第8章兑现点

- 男主拿到正式手术记录和签字副本
- 配偶栏是他的名字，签字栏却不是他
- 他终于确认，自己错过的是她活命的那一刻

## 前30%试读卡点

- 最好卡在：她从手术室醒来，刷到陆沉舟陪白月光产检的照片
- 要求：
  - 前 `300` 字内出手术和签字死局
  - 前 `800` 字内出男主缺席事实
  - 前 `30%` 内必须出现 `手术单 / 未接电话 / 离婚动作`

## 最大反转点

- 真正让男主崩塌的，不是离婚协议，而是那张写着他名字、却由她独自完成的手术同意书
- 他以为自己只是晚到，实际是在她最需要的时候亲手缺席

## 情绪回本点

- 女主不是靠哭赢，而是靠彻底抽身赢
- 白月光不再享有“被补偿”的位置
- 男主最终拿到全部真相，却再也没有补签和重来的资格

## 余波场设计

- 第4章：医生证词出来后，男主第一次真正慌
- 第6章：白月光翻车后，女主态度更冷，切割更彻底
- 第9章：离婚落地时，男主带着手术单站在民政局外，形成迟来的情绪回锤
