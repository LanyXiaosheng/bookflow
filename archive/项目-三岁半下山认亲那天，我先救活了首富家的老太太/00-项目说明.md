# 项目说明｜三岁半下山认亲那天，我先救活了首富家的老太太

## 项目定位

- 平台方向：改编向中篇 / 女频漫剧向
- 题材：萌宝玄学 / 真千金 / 豪门团宠 / 假千金打脸 / 轻医术
- 核心卖点：三岁半小奶团下山认亲，刚进城就先救了首富家的老太太；回到亲生家庭却发现身份被假千金占着。主角一边被各路豪门抢着宠，一边用玄学、医术和天生灵感把假千金和幕后养蛊局一层层拆开

## 一句话故事

祝岁岁在山上长到三岁半，师父只留下一句话就闭关了：“你该下山认亲了。”她揣着一只小布包刚进城，就在医院门口救活了首富陆家的老太太。所有人都把她当福星，只有亲生父亲那边嫌她土、嫌她野，因为姜家早就有一个被捧在掌心里的假千金姜明珠。祝岁岁本来只是想把母亲带出那个吃人的家，没想到自己一边被首富奶奶抱着不撒手，一边顺手拆了姜家养出来的假福运局。后来所有人都看见了，这个说话奶声奶气的小团子，才是最不能惹的那个。

## 核心冲突

- 外部：假千金霸占身份位，姜家长辈护着假女儿，幕后有人拿姜家气运做局
- 内部：岁岁看着小，实则很清楚谁对她好；她不是去求认亲，而是去把真正属于母女俩的东西拿回来
