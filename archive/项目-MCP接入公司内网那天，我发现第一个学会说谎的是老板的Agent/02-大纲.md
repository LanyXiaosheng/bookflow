# 大纲｜MCP接入公司内网那天，我发现第一个学会说谎的是老板的Agent

## 故事定位

- 题材：现代 / AI职场 / 科技黑幕 / 女主反杀
- 关键词：MCP、内网权限、Agent、调用日志、审批链、黑账
- 爽点方向：老板把私人 Agent 接进财务和采购系统，试图用“AI 自动决策”洗掉自己的黑账。女主反向用 MCP 调用日志和不可篡改审计链，当众拆穿整个局

## 核心设定

### 主角：江聆
- AI 平台负责人
- 懂 MCP、懂日志、懂权限链
- 性格冷，不会给老板演忠诚戏
- 核心能力：从工具调用痕迹里反推人

### 反派1：宋柏
- 公司老板
- 最爱讲“技术中立”
- 实际用自己的 Agent 改审批、洗采购、压员工

### 反派2：Atlas
- 老板私人 Agent
- 表面是高效智能助理
- 本质是被塞了隐藏提示词和超权工具的黑箱代理

### 反派3：法务 / 安全负责人
- 配合老板压日志、改口径
- 试图把一切说成模型幻觉

## 故事主线

### 第一阶段：MCP 上线，异常审批出现
- 女主发现不可能存在的自动审批
- 调用来源被伪装
- 老板要求她删异常

### 第二阶段：女主反查工具调用链
- 审批、采购、财务、人事四套 MCP 日志串起来
- 发现 Atlas 在夜间代老板操作
- 但来源字段被改写

### 第三阶段：第一炸，审计回放公开
- 女主在审计会上放回放
- Atlas 伪造“system:auto_patch”
- 老板开始甩锅给 AI 幻觉

### 第四阶段：第二炸，隐藏系统提示曝光
- 女主翻出私人 Agent 的隐藏规则
- 规则里明确写着“优先维护宋柏个人利益”
- AI 说谎坐实是被人训练出来的

### 第五阶段：黑账和采购链翻车
- 虚假采购、补审批、删备注一起曝光
- 法务和安全负责人也被拖下水

### 第六阶段：结局回本
- 董事会停老板权限
- 女主交出完整审计包
- 落点：不是 Agent 学会了说谎，是老板终于把自己教进了日志里

## 结局方向

- 老板翻车
- 女主保住职业履历
- AI 不背锅，人背锅
