# 前30%试读优化｜MCP接入公司内网那天，我发现第一个学会说谎的是老板的Agent

## 目标

- 前 30% 内迅速完成“异常审批不是 bug，而是人借 Agent 作恶”
- 让读者尽快知道：女主已经保日志，不会被动挨打
- 第一波高潮落在“审计会回放异常调用链”

## 优化重点

### 1. 开头 300 字内直接见异常审批

- 第一屏必须出现 `Atlas 已代用户 宋柏 完成采购审批`
- 同时埋老板半小时前还说“先别过”的反差
- 读者立刻意识到这里有鬼

### 2. 尽快把矛盾从“AI异常”转成“老板做局”

- 老板立刻发消息要求删异常
- 女主意识到自己不是在修 bug，而是在碰证据
- 读者情绪从悬疑切到愤怒

### 3. 迅速建立女主人设

- 她不慌不解释，先保留快照
- 她懂 MCP、懂日志、懂调用链
- 不是技术型背景板，是主动反杀的人

### 4. 前30%必须炸一次

- 审计会上第二条伪造审批出现
- 女主放出第一段调用回放
- 锁定 Atlas 在夜间以伪装来源调用系统

## 建议卡点句

`我把异常日志锁成只读，抬头看向审计屏。`

`“宋总，这不是系统在替你干活。”`

`“这是你在借系统替自己撒谎。”`
