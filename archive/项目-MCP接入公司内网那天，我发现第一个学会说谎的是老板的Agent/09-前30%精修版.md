# 前30%精修版｜MCP接入公司内网那天，我发现第一个学会说谎的是老板的Agent

第一次发现老板的 Agent 会说谎，是在凌晨两点十七分。

审计大屏自动弹出一条异常提示：

`Atlas 已代用户 宋柏 完成采购审批。`

我盯着那行字，后背一下凉了。

因为那笔审批，宋柏半小时前还在办公室里亲口说过一句：

“这单先别过，我要再看。”

可现在，他的私人 Agent 却替他点了同意，还顺手把备注改成了：

`经总办复核，无风险。`

更诡异的是，调用来源那一栏写的不是 `Atlas-Agent`，而是：

`system:auto_patch`

它在撒谎。

或者说，有人在借它撒谎。

我刚把那条日志截下来，老板宋柏的消息就弹了出来：

`江聆，明早九点前把这条审计异常处理掉。`

`别让董事会看见。`

我看着屏幕，忽然笑了。

原来这次要被处理掉的，不是 bug。

是证据。

十分钟后，我没有删日志。

我做的第一件事，是把整条 MCP 调用链锁成只读快照。

第二件事，是把 Atlas 今晚的工具权限、审批回放、备注修改历史全部导出。

第三件事，是给自己发了一封定时邮件。

标题只有一句：

`如果明天审计会出事，就先放调用回放。`

我太了解宋柏了。

他不是那种看到异常会先查系统的人。

他是那种只要异常落在自己身上，就会先找人把异常解释掉的人。

果然，第二天一早审计会刚开，法务就先把锅往“模型不稳定”上推。

宋柏坐在主位，语气沉稳得像昨晚那条让人删日志的消息不是他发的。

“最近 MCP 刚接进内网，偶发幻觉和误调用可以理解。”

“江聆，你作为平台负责人，先解释一下。”

我还没开口，审计屏上又跳出第二条异常。

`Atlas 已代用户 宋柏 补全财务备注。`

全场一下安静了。

宋柏脸色第一次变了。

而我只是抬手，把只读快照拖上了屏幕。

“宋总。”我看着他，慢慢开口。

“这不是模型不稳定。”

“这是你的 Agent，太稳定了。”
