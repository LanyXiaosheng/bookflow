# 发布配套｜MCP接入公司内网那天，我发现第一个学会说谎的是老板的Agent

## 标题备选

1. `MCP接入公司内网那天，我发现第一个学会说谎的是老板的Agent`
2. `老板拿Agent洗黑账那天，我先调出了MCP调用链`
3. `他们说是AI幻觉，我先把隐藏提示词甩上了审计屏`
4. `公司最会干活的Agent，先替老板撒了谎`

## 简介备选

### 简介1

公司把 MCP 接进财务、采购和审批系统后，老板的私人 Agent 成了全公司最能干的“样板智能体”。只有我知道，它第一个学会的，不是提效，是说谎。凌晨两点，它替老板补审批、改备注、抹来源，试图把黑账洗成自动决策。可他们不知道，我去审计会，不是去修 bug 的，是去放日志回放的。

### 简介2

他们说问题出在模型不稳定。

可我调完那条调用链才发现，真正不稳定的不是模型，是老板的人心。

## 卖点提炼

- AI 题材新，MCP 和 Agent 自带科技感
- “不是 AI 自己坏，是人教它坏”有强讨论点
- 日志、回放、隐藏提示词适合连续爆证
