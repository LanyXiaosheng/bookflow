# 大纲｜粮道被断前夜，我先烧了那封求援军令

## 故事定位

- 平台方向：番茄短篇
- 题材：男频历史翻盘 / 边城粮道 / 抗命求生 / 军粮反杀
- 关键词：押粮校尉、求援军令、粮道、伏兵、路书、内鬼
- 核心爽点：男主在满城都想送粮求活的死局里，先烧假令保住最后军粮，再顺着路书、印角和运粮时序找出内鬼，最终把敌军设好的伏兵口变成反埋杀场

## 一句话故事

北陵孤城被围第九日，押粮校尉顾砚接到州府求援军令，要他连夜打开西粮道，把城内最后一批军粮送去接援。可顾砚一眼看出军令上的印角和时辰都不对。所有人都劝他别抗命，只有他先烧了那封令，随后才知道，外头等着这批粮的根本不是援军，而是拿着粮道路书的敌骑伏兵。

## 核心设定

### 主角：顾砚

- 边城押粮校尉
- 熟悉粮道、封仓和运粮流程
- 擅长从印记、时序和路书找漏洞
- 核心成长：从只管粮车的小校尉，到能以粮控局的破局者

### 核心反派

- 监仓使孙峤：主推连夜送粮
- 城中绸商何迁：真正把粮道路书卖出去的人
- 敌军伏兵：专等最后一批粮出城

### 关键助力

- 老仓吏薛伯：认得州府旧印
- 守西门都头韩炽：最终愿意站边

## 故事主线

### 第一阶段：假求援令落进粮仓

- 粮尽城危
- 求援军令到手
- 男主发现印角与时辰不对

### 第二阶段：先烧军令，截断开粮道流程

- 男主当众烧令
- 抗命压力拉满
- 粮道之争正式爆开

### 第三阶段：援军是假，伏兵是真

- 路书、驿差时差、火漆印被核对
- 敌军伏兵意图坐实
- 城内内鬼浮出

### 第四阶段：拿粮设局，反钓内外两条线

- 男主假装妥协
- 假粮车、真埋伏成形
- 内鬼被逼着出手

### 第五阶段：敌军想吞粮，却先吞了我给他们的死口

- 伏兵上钩
- 粮道路口反杀
- 内鬼链彻底坐实

### 第六阶段：烧掉那封令的人，最后保住了全城的粮

- 假令案定性
- 全城活路保住
- 男主完成身份翻盘

## 核心反转设计

1. 真正要命的不是断粮，而是“送粮接援”这条活路本身就是假的
2. 男主烧令看似疯，实则是唯一来得及截断流程的动作
3. 内鬼卖出去的不是一般情报，而是粮道路书与出城时辰
4. 男主最后赢的不是死守仓库，而是把伏兵想吞的粮车变成钓他们的饵

## 结局方向

- 西粮道未失
- 最后一批军粮保住
- 男主从押粮校尉翻成边城首功
