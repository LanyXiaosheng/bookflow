# 模板应用说明｜粮道被断前夜，我先烧了那封求援军令

## 一、标题模板命中

本项目命中以下结构：

1. `极限资源死局 + 先手破局动作`
2. `边城断粮 + 假求援令 + 烧令抗命`
3. `低位押粮校尉 + 全城活路翻案`

当前标题：

`粮道被断前夜，我先烧了那封求援军令`

优势：

- “粮道被断前夜”直接给出高压时间线
- “先烧了军令”动作狠且反直觉
- 历史男频里“粮”和“城”的生死利益都能拉满

## 二、开篇钩子结构

采用的是：

`求援军令落地 -> 男主看出漏洞 -> 当众烧令`

这样前三屏可以完成：

1. 死局压迫
2. 军令异常
3. 主角极强动作

## 三、冲突升级逻辑

- 求援军令到手
- 烧令抗命
- 路书与时辰核对
- 内鬼链浮出
- 假粮车真埋杀
- 伏兵与内鬼双收

## 四、爽点设计

爽点不只是“烧得狠”，还包括：

- 从印角和时辰切令
- 从粮道路书反推内鬼
- 最后把粮车变成埋伏诱饵

## 五、后续扩写标准

统一抓住：

1. 军令漏洞是否足够快
2. 烧令动作是否够早够狠
3. 粮道与伏兵逻辑是否清楚
4. 内鬼链是否撑得起中后段
5. 结局是否回收到“保住最后一批粮”
