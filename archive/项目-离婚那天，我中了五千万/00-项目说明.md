# 项目说明｜离婚那天，我中了五千万

## 项目定位

- 平台方向：番茄短篇
- 题材：女频现代 / 婚恋逆袭 / 离婚打脸 / 一夜暴富
- 核心卖点：丈夫出轨、小三逼宫、婆家羞辱，女主被迫净身出户。所有人都以为她离了婚只能狼狈收场，结果她在离婚当晚意外中得五千万，从被嫌弃的家庭主妇，逆袭成前夫一家高攀不起的人。

## 一句话故事

林晚结婚三年，辞职顾家，照顾婆婆，换来的却是丈夫周成出轨、小三登门和婆家联手逼她签下净身出户协议。离婚那天，周成还冷着脸告诉她：“你离了我，什么都不是。”可就在她拖着行李离开周家后，一张被揉皱的彩票突然开出五千万大奖。前夫一家以为甩掉的是包袱，没想到错过的，是他们这辈子都再也碰不到的翻盘机会。

## 读点判断

- “离婚当天中大奖”天然具备强钩子，开局即有传播感
- 出轨 + 净身出户 + 一夜暴富，情绪压抑和爽感释放对比强烈
- 前夫一家从嫌弃到争钱、从高高在上到跪求复婚，打脸路径清晰
- 女主不仅是中奖翻身，还要完成自我觉醒，补足情绪回本

## 爽点 / 爆点方向

- 开局就是小三上门、婆婆羞辱、前夫逼签离婚协议
- 女主刚被净身出户，转头就中奖五千万，形成极强反差
- 前夫得知消息后想分奖金、婆家上门闹事，矛盾持续升级
- 小三发现前夫没捞到钱后翻脸，前夫事业和感情双崩
- 结尾要做到：女主真正赢的不是钱，而是不再回头、不再把人生交给任何人定义
