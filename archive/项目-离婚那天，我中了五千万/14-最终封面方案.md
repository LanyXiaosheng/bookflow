# 最终封面方案｜离婚那天，我中了五千万

## 封面成品信息

- 书名：离婚那天，我中了五千万
- 作者名：导师说修仙要查重
- 平台方向：番茄小说 / 女频短篇 / 现言婚恋逆袭
- 封面类型：现代都市情感 + 离婚逆袭 + 一夜暴富爆款风

## 最终主文案

### 标题
离婚那天，我中了五千万

### 作者名
著：导师说修仙要查重

### 副文案
净身出户那晚，我中了五千万

## 最终视觉定位

### 人物设定
- 30岁左右女性
- 五官清秀偏美艳，气质冷静、清醒、克制
- 长发或微卷发
- 穿米白色风衣或高级感都市通勤套装
- 一手拉行李箱，一手可自然持手机或彩票
- 表情不要夸张，要有“刚从婚姻废墟里走出来但已经开始翻盘”的感觉

### 场景设定
- 夜晚都市街景
- 背景可有模糊高档小区灯光、便利店灯箱、城市霓虹
- 可弱化加入前夫背影或模糊豪车元素，作为婚变暗示
- 不要多人抢画面，核心一定是女主单人强视觉

### 氛围关键词
- 离婚
- 逆袭
- 清醒女主
- 一夜暴富
- 都市情绪感
- 番茄爆款女频

## 排版方案

### 方案A｜最稳番茄风
- 标题放中上区域，分两到三行
- “五千万”放最大，做金色高亮
- 作者名放底部中间或右下角，小一号白字
- 副文案放下半区域，小号字，增强点击感

排版示意：

离婚那天，
我中了
五千万

净身出户那晚，我中了五千万

著：导师说修仙要查重

### 方案B｜更强冲击感
- 标题整体靠中部偏上
- “离婚那天”用白字
- “五千万”用金色粗体或发光字
- 作者名放底部边缘，别抢画面

## 字体建议

- 书名主字：粗黑体 / 海报体 / 现言封面常用加粗标题体
- “五千万”建议单独做描边、金属光泽或发光效果
- 作者名：简洁无衬线字体即可

## 颜色建议

- 主色：金色 / 米白 / 夜景蓝
- 辅色：黑灰 / 暖黄灯光
- 避免：土味大红、荧光粉、杂色太多

## 封面执行原则

- 女主必须比背景更抢眼
- 封面只讲一个信息：离婚后逆袭暴富
- 不堆太多元素，避免显得廉价
- 重点突出“女性独立 + 爆款爽点 + 都市质感”
