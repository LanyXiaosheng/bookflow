# 项目说明｜被逐出侯府那天，我在县试榜上改回了母姓

## 项目定位

- 平台方向：改编向中篇 / 男频短剧向
- 题材：古代历史 / 科举逆袭 / 侯府弃子 / 权谋打脸 / 事业崛起
- 核心卖点：主角被嫡母逐出侯府、毁名毁姓，却在县试榜上改回亡母姓氏，以案首身份重新入场。后续不只复仇，还接 `县试 / 府学 / 旧案 / 盐账 / 朝堂`

## 一句话故事

顾砚安原是定远侯府不被承认的庶子，母亲死后，他被嫡母污成家门耻辱，赶出侯府时连姓氏都不配留。可县试放榜那天，榜首上写的不是侯府给他的名字，而是他亡母的姓。所有人都以为他只是赌气改名，只有顾砚安自己知道，他这一步不是离开侯府，而是正式开始向上走。等他一步步走到府学、贡院和朝堂前时，当年把他踩进泥里的侯府，才发现自己亲手放走的是一把最锋利的刀。

## 核心冲突

- 外部：嫡母和嫡兄毁他功名、抹去母系身份，侯府和外戚链路一起压他
- 内部：主角从“只想活下来”升级成“既要功名，也要真相”
