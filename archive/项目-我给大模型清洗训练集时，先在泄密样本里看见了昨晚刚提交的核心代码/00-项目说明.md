# 项目说明｜我给大模型清洗训练集时，先在泄密样本里看见了昨晚刚提交的核心代码

## 项目定位

- 平台方向：番茄短篇
- 题材：女频现代 / 大模型 / 代码泄密 / 职场黑幕 / 技术悬疑
- 核心卖点：女主负责给公司大模型清洗训练集，本以为只是做数据合规，结果却在一批“匿名开源代码样本”里，看见了自己昨晚才提交到私有仓的核心函数。她顺着样本指纹往回查，发现公司嘴上在抓码奸，实际真正把私有代码源源不断喂给模型的人，正是负责这套模型项目的高层。

## 一句话故事

程漪是公司大模型训练数据清洗负责人。模型上线前夕，她在去重样本里看到一段只存在于公司私有仓、而且是自己昨晚刚提交的风控函数。所有人都说那是“相似实现”，可程漪比谁都清楚，那几行注释和变量命名，不可能撞得这么巧。她越查越发现，公司所谓的代码合规审查只是幌子，真正把核心仓库偷偷拆进训练集、再对外包装成“模型自学能力”的，竟是技术线最会讲 AI 故事的那批人。

- 女主的反击不是嘴炮，而是靠 commit 指纹、注释习惯、时间线和样本溯源狠狠干

- 最终把“模型能力神话”打回“偷代码喂出来的假天才”
