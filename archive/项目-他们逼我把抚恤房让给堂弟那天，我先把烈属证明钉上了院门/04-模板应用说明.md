# 模板应用说明｜他们逼我把抚恤房让给堂弟那天，我先把烈属证明钉上了院门

## 题型归类

- 赛道：四合院年代反杀
- 变体：烈属房争夺 / 院门口公开打脸型
- 核心结构：堂叔逼让房 + 烈属证明钉门 + 街道办介入 + 代领补助翻账 + 抚恤房保住

## 本项目重点模板

### 1. 开头钩子模板

- 直接用“新门锁拍上桌”起爆
- 前 `300` 字内必须明确：
  - 这是抚恤房
  - 堂叔一家来抢房
  - 女主当众把烈属证明钉上院门

### 2. 公开羞耻模板

这篇最值钱的动作不是私下争。

而是把：

- 烈属证明
- 抚恤房批文
- 代领补助旧账

都变成院门口人人能看的东西。

这样“你们不是讲情分吗”才会反过来打脸。

### 3. 证据反杀模板

这篇证据链要分三层：

1. 烈属证明和批文先坐实房屋归属
2. 代领补助记录坐实堂叔占便宜
3. 原始档案坐实母女才是真正被欺负的人

### 4. 情绪推进模板

- 第一落点：堂叔拿“男丁结婚”压人
- 第二落点：全院帮着说“先让一步”
- 第三落点：女主钉证据，公开撕脸
- 第四落点：让房会变成追补助旧账会

### 5. 结局兑现模板

结局必须回收：

1. 抚恤房保住
2. 代领补助被追回

如果只保住房，不翻补助旧账，力度会不够狠。

- 标题必须保留 `抚恤房 / 堂弟 / 烈属证明 / 院门` 至少两个钩子
- 前 `30%` 优先强化：新门锁拍桌、烈属证明钉门、街道办介入、代领补助线出现
