# 赛道总纲｜军魂短篇

## 赛道定位

这个赛道不是泛男频，也不是普通历史翻盘。

它专门承接：

- 军阵死局
- 孤城守夜
- 假军令翻案
- 粮道断绝反杀
- 小人物在军中翻盘

核心关键词：

- 军魂
- 守城
- 小兵逆袭
- 粮道
- 军令
- 内奸
- 家国
- 袍泽

## 为什么现在必须补这个赛道

1. 能直接打散当前 `离婚 / 白月光 / 前夫` 的高重复关系库
2. 爽点依旧成立，且更适合做强动作开局
3. 当前工作区里已经有一批成熟历史军阵项目，可直接拆出来独立放大
4. 能把男频历史翻盘从“大杂烩”里拎出来，单独形成稳定供给

## 适合的核心题型

- 待斩小兵发现假军令
- 孤城校尉先斩监军
- 粮道押运官烧令保粮
- 守城书吏烧降书抓内奸
- 斥候 / 火头军 / 军医在大战前夜翻案

## 标准结构

- 开头：死局压脸，军令、敌情或粮道立刻出错
- 中段：男主先做逆命动作，再被全营、全城或上官围杀
- 后段：军令、印角、报时、路书、军报逐层翻开
- 结尾：保城、保粮、保营成功，内奸被当场清算

## 角色去重要求

- 不要连续写两个“小兵待斩”
- 不要连续写两个“校尉守城”
- 同一周内要轮换 `小兵 / 校尉 / 押粮官 / 书吏 / 斥候 / 火头军 / 军医`
- 场景也要轮换 `军营 / 城门 / 粮道 / 烽火台 / 漕道 / 营帐`

## 当前阶段建议

- 先用已成稿项目把军魂赛道跑出阅读反馈
- 再补 `守城 / 满城投降` 这两条到完整发布链路
- 后续优先沉淀 `军令漏洞`、`城防图`、`粮道路书` 这类证据模板

## 资产建设重点

- 军阵标题模板
- 军令 / 粮道 / 守城开局模板
- 袍泽与内奸关系模板
- 先斩后奏类情绪台词模板
