# 赛道总纲｜军婚

## 赛道定位

这个赛道不是普通现言换一身军装。

它真正值钱的地方在于：

- 军婚
- 随军
- 家属院
- 任务与等待
- 纪律感与偏爱
- 冷硬男主的行动兑现

核心关键词：

- 军婚
- 军官
- 随军
- 家属院
- 探亲
- 津贴
- 调岗
- 转业

## 为什么现在要补这个赛道

1. 能保留女频婚恋的高情绪，但换掉 `前夫 / 白月光 / 民政局` 这套高重复模板
2. 军婚自带纪律、距离、等待、保护欲，比普通豪门婚恋更容易拉开差异
3. 家属院和部队体系天然适合写公开站队、公开打脸、公开护短
4. 能和 `军魂短篇` 形成男女频两条不同的军系分支

## 适合的核心题型

- 提离婚申请时他突然归队
- 随军名额下来，婆家先来抢位置
- 家属院都说她配不上他，他却当众护短
- 任务失联归来，先处理的是她被谁欺负
- 转业安置、津贴、调岗、孩子户口引发的婚姻冲突

## 标准结构

- 开头：探亲、随军、离婚申请、调岗通知、归队消息直接起爆
- 中段：家属院舆论、婆家占便宜、任务保密带来的误会一起压上来
- 后段：男主行动站边，女主拿证据或规则反打，情感和体面一起回收
- 结尾：不是单纯和好，而是让关系重新站稳，让所有人知道他站谁那边

## 角色去重要求

- 不要连续两篇都写“失联归来”
- 不要连续两篇都写“婆家吃津贴”
- 同一周轮换 `连长 / 营长 / 团长 / 转业军官 / 军医 / 军嫂`
- 场景轮换 `团部 / 家属院 / 探亲站 / 随军宿舍 / 转业安置会`

## 当前阶段建议

- 先补赛道资产，不急着立刻上排班
- 先从“离婚申请 / 随军名额 / 家属院护短 / 津贴账本”四个切口做首批立项
- 军婚一定要先过一遍“读者为什么读”，否则很容易写成普通现言换皮

## 资产建设重点

- 军婚标题模板
- 家属院群像关系模板
- 随军 / 津贴 / 转业证据模板
- “他怎么站她那边”行动兑现模板
