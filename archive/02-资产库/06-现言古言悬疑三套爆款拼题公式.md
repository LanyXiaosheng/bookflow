# 现言古言悬疑三套爆款拼题公式

## 这份文档解决什么问题

这不是再讲“方向”。

这份文档只回答一件事：

- 一个题，怎么从素材拼成能用的项目名
- 一个项目，怎么从项目名反推到开头结构

目标是把你现在最重要的三条线，拆成：

1. `现言主航道公式`
2. `古言副航道公式`
3. `悬疑副池公式`

---

## 总原则

现在最稳的拼题顺序，不是先想剧情，而是先拼这四格：

1. **事件场**
2. **被逼失位**
3. **翻盘物件**
4. **公开翻盘动作**

能把这四格拼清楚，题就有了。

拼不清楚，就容易写成：

- 抽象情绪题
- 旧题换壳
- 看着热闹但点不开

---

## 一、现言主航道爆款拼题公式

## 现言公式 A：公开场抢位反杀

### 公式

- `公开场 + 他把我的位置给了白月光 + 我先公开了硬证据`

### 适合素材

- 敲钟上市
- 发布会
- 官宣
- 年会
- 招标会
- 董事会

### 适合物件

- 股权代持协议
- 创始合伙协议
- 原始手稿
- 源文件时间戳
- 原始提报记录
- 审计台账

### 现成例子

- 敲钟上市那天，他把总裁夫人的位置留给白月光，我先公开了股权代持协议
- 品牌官宣那天，他让白月光顶替我站上主理人位置，甲方先认出了我的旧手稿

### 爽点结构

1. 第一场景就公开降位
2. 男主压她别闹
3. 女主不闹，直接上证据
4. 现场从庆典变成翻车场

---

## 现言公式 B：协议压脸财产反杀

### 公式

- `办理节点 + 他们逼我签协议 + 系统/机构先打脸`

### 适合素材

- 婚房解押
- 过户
- 信托解封
- 分家
- 继承

### 适合物件

- 赠与协议
- 财产保全回执
- 共同账户冻结
- 购房录像
- 分家文书
- 公证书

### 现成例子

- 婚房解押那天，他逼我签赠与协议，银行先冻结了他的共同账户
- 奶奶分家那天，他们逼我把药铺让给堂兄，我先调出了旧分家文书

### 爽点结构

1. 协议先压到脸上
2. 亲情牌 / 婚姻牌一起打
3. 女主亮回执或旧文书
4. 银行、公证、机构替她把脸打回去

---

## 现言公式 C：关系背刺 + 成果署名反打

### 公式

- `成果公开节点 + 他们把我的东西署给白月光 + 原始记录回流`

### 适合素材

- 校庆
- 科研成果发布
- 竞标会
- 作品官宣
- 项目颁奖

### 适合物件

- 实验台账
- 原始底稿
- 文件时间戳
- 内部审批记录
- 评审组存档

### 现成例子

- 周年校庆那天，他们把我的科研成果刻上白月光名字，评审组先公开了原始实验台账
- 竞标会开标那天，他把我做了三年的旗舰方案署给白月光，招标办先调出了源文件时间戳

### 爽点结构

1. 女主被降位
2. 成果被顶名
3. 女主不解释前情，直接上原始记录
4. 甲方 / 评审 / 审计替她锤实

---

## 现言主航道禁忌

本月不要再高频拼这些：

- `离婚那天 + 前夫后悔`
- `民政局 + 回头`
- `私生子 + 亲子鉴定`
- `捐骨髓 / 捐肾`

不是不能写，是当前库里已经太密。

现言接下来最好的新变量是：

- 股权
- 投票权
- 设计稿
- 科研成果
- 药铺 / 房子 / 老宅 / 信托

## 二、古言副航道爆款拼题公式

## 古言公式 A：关键夜按印背锅反杀

### 公式

- `关键夜 + 他们逼我按印认账 + 我先把关键封/签/钥送进权力机关`

### 适合素材

- 赈灾银
- 漕粮
- 军粮
- 祭银
- 河工石料

### 适合物件

- 火漆封条
- 门签
- 牌签
- 库钥
- 借调令
- 路单

### 现成例子

- 赈灾银入库那夜，他们逼我认下亏空账，我先把火漆封条送到了御前

### 爽点结构

1. 第一场景就是银库 / 仓场
2. 父亲、继母、未婚夫一起逼按印
3. 女主发现封条或牌签不对
4. 她按印不是认命，是借流程送证

---

## 古言公式 B：宗族资源被夺反杀

### 公式

- `宗族节点 + 继母/嫡兄逼我让资源 + 我先把旧契/族契送进宗正寺`

### 适合素材

- 春祭开祠
- 宗祠分家
- 祭田
- 宗产
- 祖坟地契

### 适合物件

- 旧契
- 地契
- 宗谱
- 族契
- 印匣

### 现成例子

- 春祭开祠那日，继母逼我把母亲祭田让给嫡兄，我先把旧契送进了宗正寺

### 爽点结构

1. 开祠 / 分宗是公开场
2. 女主被逼当众让田 / 让产
3. 她先顺势，再先递旧契
4. 宗正寺 / 族老当众翻案

---

## 古言公式 C：宫廷试毒 / 册礼翻车

### 公式

- `册礼前夜 + 逼我替嫡姐/别人试毒 + 我先把册簿/凤印簿送进太医院`

### 适合素材

- 册礼
- 试毒
- 凤印
- 太医院
- 脉案

### 适合物件

- 凤印簿
- 脉案
- 御药牌签
- 试药名单

### 现成例子

- 封后册礼前夜，继母逼我替嫡姐试毒，我先把凤印簿送进了太医院

### 爽点结构

1. 册礼前夜时间紧
2. 女主被推出去替毒
3. 她先把册簿或脉案递出去
4. 太医院先验，宫里再翻

---

## 古言公式 D：猎场换位清算

### 公式

- `回营日/猎场 + 庶妹让位 + 通敌/军情证据先被抬出`

### 适合素材

- 春猎
- 回营
- 世子
- 庶妹
- 通敌密信

### 现成例子

- 春猎回营那日，世子逼我给庶妹让位，猎场先抬出了他的通敌密信

### 爽点结构

1. 当众羞辱
2. 女主先不争位
3. 直接抬出更大的案子
4. 世子从换位者变成待审者

---

## 古言副航道禁忌

本月不要继续高频拼：

- 替嫁残王
- 冲喜世子
- 病王夜夜装病
- 泛宅斗争宠

古言现在最好的新变量是：

- 封条
- 库钥
- 路单
- 地契
- 凤印簿
- 密信
- 婚书焚毁

## 三、悬疑副池爆款拼题公式

## 悬疑公式 A：封闭场景 + 不该说话的东西先叫你名字

### 公式

- `封闭场景值夜 + 多出来的人/尸体/账号 + 它先叫你名字`

### 适合素材

- 停尸房
- 医院值夜
- 办公楼夜班

### 现成例子

- 停尸房值夜那晚，第七具尸体忽然开口叫了我的名字

### 爽点结构

1. 单一场景
2. 不该存在的对象出现
3. 主角不是乱跑，是先观察规则
4. 真相最终回扣身份错位或旧案

---

## 悬疑公式 B：群聊里最先说话的人，其实早就死了

### 公式

- `封楼/断电/暴雨 + 群里第一个报平安的人 + 现实里已经死了`

### 适合素材

- 业主群
- 家族群
- 同事群

### 现成例子

- 暴雨封楼那夜，业主群里那个最先报平安的人其实三天前就死了

### 爽点结构

1. 封闭场景制造压迫
2. 线上身份和线下死亡错位
3. 主角顺着聊天记录查旧案
4. 群聊不是氛围，是证据链

---

## 悬疑副池禁忌

不要再继续拼：

- 电梯第十八层
- 医院多一层
- 病房编号怪谈

这些库里已经够多了。

悬疑后续更好的新变量是：

- 停尸房
- 群聊
- 报平安
- 尸体开口
- 线上身份反噬

## 四、三套公式怎么快速用

## 现言

先选：

1. 公开场
2. 白月光 / 堂兄 / 甲方 / 董事会
3. 协议 / 手稿 / 台账 / 分家文书
4. 机构公开打脸

拼法：

- `公开场 + 对方抢我位置/成果 + 我先公开物件`

## 古言

先选：

1. 关键夜 / 关键礼 / 回营日
2. 继母 / 嫡兄 / 未婚夫 / 世子
3. 封条 / 路单 / 地契 / 凤印簿
4. 御前 / 宗正寺 / 太医院 / 皇城司

拼法：

- `关键节点 + 他们逼我背锅/让位 + 我先把关键物件送进权力机关`

## 悬疑

先选：

1. 封闭场景
2. 不该存在的人/尸体/账号
3. 主角与其的私人关联
4. 旧案或身份错位

拼法：

- `封闭场景 + 不该存在的对象先叫主角 + 主角顺规则查旧案`

---

## 五、最后一句

以后别再从“我想写什么故事”开头。

更快的方式是先问：

1. 我要哪个场？
2. 我要谁失位？
3. 我要什么证据？
4. 我要谁来替我公开打脸？

四个空一填，题就出来了。
