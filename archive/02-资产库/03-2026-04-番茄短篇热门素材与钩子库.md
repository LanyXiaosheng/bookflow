这说明：

- 番茄短篇现在不是只吃单一言情
- 但平台明确在推“强情绪、强画面、可改编”的品类

### 你自己后台已经验证过的信号

你当前数据里真正稳定能跑的，仍然是：

- 现言婚恋火葬场
- 白月光

## 二、官方当前最有价值的 5 个信号

## 1. 官方当前在推的短篇热门品类

截至 `2026-04-01`，番茄作家活动页当前短篇重点品类是：

- 悬疑惊悚
- 宫斗宅斗
- 现言甜宠
- 年代
- 女性成长
- 玄幻仙侠
- 脑洞
- 男生生活
- 男生情感
- 男频衍生
- 女频衍生

对你最有用的不是“全做”，而是：

- 现言甜宠
- 女性成长
- 宫斗宅斗
- 悬疑惊悚

其中你当前最适配的是：

- 现言甜宠的反向用法：`甜宠壳 + 火葬场骨`
- 女性成长的落地用法：`离婚/被夺位后不回头`
- 宫斗宅斗的落地用法：`嫁妆 / 抄家 / 宗谱 / 账册 / 印信`

## 2. 官方持续强调“热门短故事”周更

番茄官方在短故事激励计划和短故事发文教程里都提到：

- 作家助手和作家后台会持续更新 `热门故事 / 热门短故事`

这代表：

- 平台在主动给创作者喂“当前表现好的短篇题型”
- 你后续要养成固定动作：每周对照一次热门故事榜单，再决定新项目

## 3. 官方明确短故事最佳字数区间

官方当前口径里，短故事：

- 篇幅在 `6000-80000` 字之间
- `10000-30000` 字最佳

对你最重要的是：

- 主号短篇尽量卡在 `9000-12000`
- 要么短得足够狠，要么长得足够稳
- 不要大量停在 `6500-8500` 这种最容易不稳的区间

## 4. 官方持续强调“强剧情冲突 + 强矛盾开头”

官方短故事说明一直在重复这个要求：

- 节奏紧凑
- 剧情跌宕起伏
- 感情张力强
- 用强剧情冲突和强矛盾内容钩子吸睛

翻译成写法就是：

- 不要慢热
- 不要背景先行
- 不要先写心情
- 先把“她被逼到哪一步”“谁在压她”“她准备怎么翻”端上来

## 5. 官方短篇现在明显更偏“可改编”

从 `千字万金`、`IP金品共创计划` 和当前活动页看，平台越来越重视：

- 短剧化
- 漫剧化
- 一眼看懂的强事件
- 强公开场
- 强身份位争夺

所以你后续做题时，脑子里要一直问一句：

- 这个题能不能一句话讲给短剧策划听？

如果一句话讲不明白，大概率就还不够狠。

## 三、结合你自己的后台，当前最值得继续放大的方向

## 1. 现言婚恋火葬场

这是你目前最强、最稳、最该继续打的方向。

后台已经验证过的高值样本：

- `离婚那天，他在民政局外站了一整夜`
- `他们逼我给私生子捐骨髓那天，我把亲子鉴定甩上了大屏`
- `豪门婚礼当天，我当众换了新郎`
- `我签下离婚协议后，前夫才知道孩子是他的`
- `我出狱那天，他才知道当年替他坐牢的人是我`

### 这个方向最值钱的钩子

- `离婚当天 / 民政局 / 签字`
- `婚礼当天 / 敲钟当天 / 发布会当天`
- `净身出户 / 让位 / 认孩子 / 捐器官 / 背锅`
- `白月光顶位`
- `男人以为她离不开，结果她直接抽身`

### 这个方向最值钱的爽点

- 大屏公开
- 亲子鉴定 / 手术记录 / 转账流水 / 股权协议
- 当众失位后反向翻盘
- 男主想补救，女主只谈权益不谈感情

### 这个方向最该继续扩的素材池

- 股权代持
- 婚房赠与
- 学术署名
- 离婚后资源切割
- 白月光顶位后公开翻车

## 2. 古言重生清算

你古言能跑，但必须是“强节点 + 立刻动手”的清算线。

已验证样本：

- `重生回抄家前夜，我先送继母进牢`
- `重回被退婚当日，我改嫁死对头`

### 这个方向最值钱的钩子

- `抄家前夜`
- `退婚当日`
- `出殡那天`
- `春猎回营`
- `册礼前夜`

### 这个方向最值钱的爽点

- 先下手
- 先递证
- 先烧婚书
- 先摔族谱
- 先送进大理寺 / 御前 / 皇城司

### 这个方向最该继续扩的素材池

- 火漆封条
- 路单
- 粮引
- 通敌密信
- 印匣
- 账册
- 断亲文书
- 婚书焚毁

## 3. 古言官场清算

这是你现在最值得培养的新副航道。

已立项新样本：

- `赈灾银入库那夜，他们逼我认下亏空账，我先把火漆封条送到了御前`

这个方向好处是：

- 跟替嫁残王完全拉开
- 和古言宅斗也有差异
- 自带制度感和案情推进

### 这个方向最值钱的钩子

- 入库夜
- 封仓夜
- 发粮前夜
- 赈灾银 / 军粮 / 漕运
- 逼按手印

### 这个方向最值钱的爽点

- 开库验封
- 封条作证
- 御前口谕
- 私仓翻车
- 女主从替罪羊变成执印人

## 4. 悬疑惊悚副池

官方在推，账号里也不是完全不能跑，但当前只能留副池。

相对还能看的样本：

- `那个每晚准时给我打电话的人，三年前就死了`
- `我值夜班那天，医院多出了一层不存在的楼`

### 这条线当前更适合的做法

- 做“单一场景 + 单一规则 + 单一追问”
- 不要做太散的世界观
- 不要写成长篇脑洞设定文

### 适合的钩子

- 值夜班
- 查寝
- 电梯停层
- 物业敲门
- 死人账号

### 适合的爽点

- 主角先发现规则漏洞
- 规则不是吓人，是给主角反制工具
- 最后的真相最好能回扣人性 / 旧案 / 身份错位

## 八、最后一句

截至 `2026-04-12`，番茄短篇“目前比较火”的，不该理解成“某一个唯一题材最火”。

更准确的理解是：

- 平台当前在推：`可改编 + 强事件 + 强画面 + 强情绪`
- 你自己当前最能打的：`现言婚恋火葬场`
- 你最值得扩的新副航道：`古言官场清算`

所以接下来不是继续撒网，而是：

1. 主号继续打 `现言婚恋火葬场`
2. 副线稳步养 `古言官场清算`
3. 每周固定去看一次官方 `热门短故事`
4. 新题先问：有没有清晰事件场、清晰翻盘物件、清晰公开翻盘动作

没有，就不立项。
