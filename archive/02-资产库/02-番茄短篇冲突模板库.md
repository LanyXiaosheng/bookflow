# 番茄短篇冲突模板库

## 模板 1：大婚羞辱

- 场景：婚礼 / 大婚夜
- 冲突：庶妹、平妻、妾轿、换亲、退婚
- 用法：开头直接把女主推入最羞辱时刻

## 模板 2：重生回关键节点

- 场景：被害前、下狱前、退婚前、抄家前
- 冲突：女主知道未来，但身边人不知道
- 用法：适合快速建立“改命”驱动

## 模板 3：替嫁入局

- 场景：替嫁、冲喜、嫁病王、嫁残王
- 冲突：所有人都以为女主进的是死局
- 用法：方便做先抑后扬

## 模板 4：和离反杀

- 场景：和离书、休妻、另娶、纳妾
- 冲突：前夫轻贱女主，后期追悔莫及
- 用法：适合追妻火葬场

## 模板 5：宅斗夺位

- 场景：嫡庶、掌家权、嫁妆、继母陷害
- 冲突：女主必须在家族内部夺回位置
- 用法：适合中段持续制造压制与反打

## 模板 6：身份位被抢

- 场景：真千金回家、嫡子换位、世子换子、未婚夫站队、被赶出家门
- 冲突：女主失去的不是单一感情，而是房间、名分、资源、家族位置
- 用法：开头先把“位置被收走”写实，再让女主快速接入新舞台反杀

## 模板 7：灵堂翻案

- 场景：病榻、出殡、灵堂、守丧、临终得知真相
- 冲突：最大骗局往往和子嗣、宗谱、爵位、骗婚绑定
- 用法：适合古言主母、二嫁权势、换子夺爵题，把丧事场变成公审场

## 模板 8：公开定罪反咬

- 场景：捉奸、围观、广播、派出所、全村看热闹、直播连麦
- 冲突：反派先抢话语权给女主扣死罪名，群众和关系人同时在场
- 用法：特别适合年代、军婚、现言误会、玄学直播题，女主必须在第一场公开场面里翻口

## 模板 9：抄家抢资源

- 场景：抄家前夜、流放前一刻、分家前、物资转移、厨房账房私库
- 冲突：争的不是面子，是钱、粮、药、衣物、孩子和活路
- 用法：适合流放、逃荒、年代分家、生存翻盘题，主角第一招先抢资源，再谈情绪反杀

## 模板 10：恶媳洗白

- 场景：沉塘、公审、冲喜、残夫、病夫、村里人围骂
- 冲突：女主一开局就背着“毒妇 / 恶媳 / 想卷钱跑路”的臭名，先要证明自己不是祸害
- 用法：适合农门、乡村、残夫冲喜、恶妻重开题，首章先靠 `救人 / 修门 / 做饭 / 治伤` 洗掉第一层恶名
