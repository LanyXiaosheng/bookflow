# 赛道总纲｜女频脑洞穿书

## 赛道定位

这是高点击、高设定、高开局压迫感的试错赛道。

重点在：

- 穿书
- 觉醒
- 炮灰逆袭
- 系统/设定感
- 反手掀桌
- 土著反外挂

## 核心关键词

- 穿书
- 炮灰嫡女
- 恶毒原配
- 献祭
- 觉醒
- 系统
- 改剧情
- 身份反转
- 土著贵女
- 假剧情
- 信息差反杀
- 拿结果的人

## 为什么做这个赛道

1. 标题天然强钩子
2. 开头容易非常猛
3. 适合快速测试读者反应
4. 适合做高概念短篇
5. 适合放大成“外挂女对照组”强钩子结构

## 适合的核心题型

- 穿成被献祭的嫡女
- 穿成恶毒原配我不走剧情了
- 穿成冲喜炮灰后我反手上位
- 觉醒后我先送全家下狱
- 土著贵女反向使用穿书女
- 穿书女会背剧情，土著女主会把剧情做成结果

## 标准结构

- 开头：穿来就是马上要死，或土著女主当场被公开羞辱
- 中段：掀桌 + 借势 + 外挂女先给答案，女主后拿结果
- 结尾：身份翻盘 + 恶人现世报 + 婚姻/权力双兑现

## 适合的项目方向

- `穿成被献祭的嫡女，我反手送全家下狱`
- `被穿书女退货的病世子，我嫁了`

- 穿书标题模板
- 高概念简介模板
- 全员恶人人物盘
- 身份反转结局模板
- 土著反外挂对标拆解
- 外挂女对照组模板
