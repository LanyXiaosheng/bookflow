# 赛道总纲｜古风志怪悬疑

## 赛道定位

这是用 `古风场景 + 志怪异象 + 悬疑推进 + 因果反噬` 驱动的短故事赛道。

重点不是大开地图修仙，而是：

- 开局先见邪事
- 中段靠线索翻案
- 后段把人心和因果一起翻出来
- 结尾必须有一次身份或报应兑现

## 核心关键词

- 炼丹
- 志怪
- 县衙
- 停尸房
- 破庙
- 长生丹
- 旧案
- 丹火
- 假仙
- 因果

## 为什么做这个赛道

1. `守丹客` 这个笔名天然适配这条线
2. 当前工作区缺少 `古风 + 悬疑 + 道门异闻` 的混合赛道
3. 这条线既能保神秘感，也能承接番茄短故事的强钩子结构
4. 跑出强题后，容易继续扩成中篇、公案单元或改编向内容

## 适合的核心题型

- 炼丹旧案翻案类
- 县衙停尸房异事类
- 破庙守夜因果类
- 宫廷禁术欺君类
- 长生骗局反噬类
- 师门秘密回魂类

## 标准结构

- 开头：前 `300` 字内必须先出异象、死人、禁物或临刑场
- 中段：至少给出 `2` 次新信息，不许只靠氛围拖
- 后段：真相必须从“怪力乱神”翻到“人心布局”
- 结尾：核心异常要兑现，同时回收因果或身份位

## 当前阶段建议

- 先做 `炼丹旧案 / 县衙尸案 / 破庙异闻` 3 条样板
- 先用 `硬物件` 带剧情，比如炉钥、脉案、尸格、药方、符纸
- 先做 `0.8 万 - 1.5 万字` 的短故事，不急着堆世界观
- 标题先追求“一句话就能看出反常识”

- 志怪开头模板
- 旧案翻回模板
- 因果反噬结尾模板
