# 古风志怪悬疑

## 模块定位

这是一条专门服务 `守丹客` 账号的赛道资产目录。

它负责沉淀：

- 赛道定位
- 选题池
- 项目清单
- 后续可复用的古风异闻写法

## 存在理由

当前工作区原有的 `悬疑反转短篇` 和 `男频短篇多元破界` 都无法完整承接：

- 炼丹
- 县衙诡事
- 志怪异闻
- 因果反噬

这类混合型内容。

因此需要单独拆出 `古风志怪悬疑`，避免题材和账号气质被冲散。

## 核心职责

这个目录负责：

- 定义 `古风志怪悬疑` 的赛道边界
- 保存第一批可直接立项的选题
- 记录该赛道当前已立和待立的项目

这个目录不负责：

- 存放具体正文
- 存放平台发布配套
- 替代项目目录里的细纲和爆点文档

## 依赖关系

- 依赖 `02-资产库/02-赛道导航.md` 作为总入口
- 被具体项目目录引用和承接
- 与 `03-项目生产/03-批量立项清单.md` 共同维护推进状态
