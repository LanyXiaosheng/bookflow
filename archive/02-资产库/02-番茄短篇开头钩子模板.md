# 番茄短篇开头钩子模板

## 使用原则

番茄短篇开头不要慢热。

前 200 到 500 字内，最好直接完成这 3 件事：

1. 抛出女主当前死局
2. 明确谁在压她、害她、羞辱她
3. 立刻给出她要反打或改命的动作

也就是：

`惨境先上桌 -> 恶人立刻出现 -> 女主马上掀桌`

---

## 模板 1：婚礼羞辱开局

### 适合题材

- 重生大婚
- 替嫁
- 错嫁
- 庶妹抢婚
- 平妻 / 妾轿 / 退婚

### 标准结构

1. 开头就是婚礼现场
2. 女主被羞辱、被换婚、被逼认命
3. 恶人当众说最狠的话
4. 女主不哭，直接反击或冷笑

### 模板句式

> 大婚当日，庶妹抬着妾轿进门时，我才知道，原来他们打算让我这个正妻给她让路。

> 满堂宾客都在等我发疯，可我只是抬起头，看着那个我前世爱到发疯的男人，轻轻笑了。

### 可改写方向

- 正妻变平妻
- 替嫁给病弱王爷
- 当众退婚
- 新婚夜塞进妾室

---

## 模板 2：死后重生开局

### 适合题材

- 重生复仇
- 改命逆袭
- 和离追妻
- 抄家前夜

### 标准结构

1. 先写前世死亡瞬间
2. 快速抛出最大恨点
3. 下一段立刻切回重生节点
4. 女主第一反应就是改命，而不是哭

### 模板句式

> 我死在一个雪夜。咽下最后一口血时，我才知道，真正害我的人，从来不是外人。

> 再睁眼时，铜镜里的我还活着，而窗外那场雨，正好落在我家抄家前的那个晚上。

### 可改写方向

- 死后才知夫君爱她
- 被毒死后重生
- 流放路上重生
- 斩首前回魂

---

## 模板 3：穿书即死局开局

### 适合题材

- 穿书宅斗
- 穿成炮灰嫡女
- 穿成替嫁女
- 穿成恶毒原配

### 标准结构

1. 开头直接遭遇灌药、绑人、沉塘、替嫁、献祭
2. 第二段交代“我穿书了”
3. 第三段说明原身马上要死
4. 第四段女主决定掀桌

### 模板句式

> 我被人按在地上灌药时，脑子里只剩一个念头：这开局，未免也太地狱了。

> 下一瞬，属于原身的记忆灌进脑海，我才知道，我穿成了书里那个活不过三章的炮灰嫡女。

### 可改写方向

- 献祭冲喜
- 替庶妹受死
- 沉塘前觉醒
- 被卖去冲喜前醒来

---

## 模板 4：当众退婚开局

### 适合题材

- 退婚打脸
- 死对头上位
- 前任后悔流

### 标准结构

1. 开头就是前厅、宴席、众目睽睽
2. 前未婚夫当众退婚
3. 白月光 / 情敌在场
4. 女主直接断婚，不再挽留

### 模板句式

> 我被一杯滚烫的茶泼在脸上时，正跪在陆家前厅。

> 满堂宾客都在看我笑话，可这一次，我没像前世那样哭着求他回头。

### 可改写方向

- 改嫁死对头
- 退婚后嫁皇叔
- 被弃后反手高嫁

---

## 模板 5：家族灭门倒计时开局

### 适合题材

- 抄家前夜
- 全家流放
- 家族旧案
- 内鬼递刀

### 标准结构

1. 先写前世家破人亡
2. 切回重生关键节点
3. 明确“今晚”就是转折点
4. 女主立刻出手抓人 / 抓证据

### 模板句式

> 我被押上刑台时，顾家满门已经死得差不多了。

> 再睁眼时，滴漏指向子时三刻，而我知道，父亲书房里的那本账册，今晚就会被人换掉。

### 可改写方向

- 抄家前夜
- 流放前一晚
- 圣旨下达前一刻
- 仇人递证据前半夜

---

## 模板 6：和离开局

### 适合题材

- 追妻火葬场
- 先和离后回头
- 前夫后悔流

### 标准结构

1. 先给前世误会或死亡真相
2. 回到婚内节点
3. 女主第一件事就是提和离
4. 男主第一次失控或愣住

### 模板句式

> 前世我到死才知道，他爱我。可重活一世，我醒来做的第一件事，却是让丫鬟去请他来写和离书。

### 可改写方向

- 死后知真爱
- 被休后重生
- 追妻火葬场反转

---

## 开头禁忌

不要这样开：

- 先讲世界观
- 先讲人物背景一大段
- 先讲女主童年经历
- 先写环境、天气、心情，半天不出事
- 前 500 字还没出现核心冲突

## 一句话标准

好开头不是“写得优美”，而是：

`一上来就让读者知道她惨在哪、谁在害她、她准备怎么翻盘。`

这部分来自 `02-付费小说TXT拆解训练.md` 的抽样结论，重点不是照抄长篇，而是把它们最会抢首屏的地方压缩给短篇用。

## 模板 7：医院签字开局

### 适合题材

- 现言婚恋
- 追妻火葬场
- 白月光误会
- 流产 / 孩子 / 手术单

### 标准结构

1. 开头就是医院、手术、确诊、签字
2. 女主已经在生死线上
3. 男主却陪着别人或迟迟不到
4. 女主第一次真正死心

### 模板句式

> 医生把手术同意书递到我手里时，我才知道，原来连生死，都可以等不到他亲自来签字。

> 电话接通那一刻，他在陪白月光做检查，而我正躺在手术床上，等着失去最后一个孩子。

## 模板 8：捉奸社死开局

### 适合题材

- 年代军婚
- 现言误会
- 穿书翻车
- 群体围观型反杀

### 标准结构

1. 开头就是“门被踹开”或“众人围观”
2. 主角先落入羞辱局
3. 反派抢先定罪
4. 主角立刻反咬证据链

### 模板句式

> 门被一脚踹开时，所有人都以为是来抓我偷情的，可我抬头第一眼，看见的却是站在门口的他。

> 满堂人都等着看我丢脸，我却擦了把眼泪，先把真正设局的人名字叫了出来。

## 模板 9：认亲砸钱开局

### 适合题材

- 假千金 / 真千金
- 豪门回归
- 直播玄学
- 被全家嫌弃后反杀

### 标准结构

1. 上来就是“给你一笔钱”
2. 豪门方口气高高在上
3. 认亲不是温情，是资源羞辱
4. 主角拒绝低头，局面立刻有反差

### 模板句式

> 他把银行卡放到桌上，说只要我肯回去，就替我付清所有医药费。可我看着那张卡，只觉得恶心。

> 他们以为我是来认亲的，可我心里很清楚，这不是回家，这是换一个地方继续被他们吃。

## 模板 10：倒计时改命开局

### 适合题材

- 重生
- 末日囤货
- 抄家前夜
- 流放前一晚

### 标准结构

1. 第一段直接亮出倒计时
2. 说明前世最惨死法
3. 切回关键节点
4. 主角第一反应是抢时间，不是抒情

### 模板句式

> 再睁眼时，墙上的日期停在灾难来临前一个月，而我知道，真正该先清算的不是天灾，是身边的人。

> 我重生回到抄家前夜，连哭都来不及，第一件事就是把那本会害死全家的账册先抢回来。

## 模板 11：灵堂出殡开局

### 适合题材

- 古言主母
- 守寡二嫁
- 换子夺爵
- 病榻重生

### 标准结构

1. 开头就是灵堂、病榻、临终或出殡
2. 女主当场得知最大骗局：换子、骗婚、夺爵、逼位
3. 她不是先哭，而是先改流程、先布人、先截证据
4. 丧事场面立刻变成公审或翻案起点

### 模板句式

> 灵堂上哭得最凶的那个妾室，怀里抱着的，却是我亲生儿子的命。

> 我重生回到给他出殡那天，第一件事不是守寡，而是先把稳婆和族谱都叫进院子。

## 模板 12：被扫地出门开局

### 适合题材

- 假千金 / 真千金
- 豪门驱逐
- 娱乐圈黑料
- 直播反杀

### 标准结构

1. 开头就是拖着行李离场或被当众赶走
2. 真千金、养母、未婚夫或豪门家人同时站到对立面
3. 女主失去的不只是感情，是房间、身份和资源
4. 下一场立刻切到新舞台，让退场变成登场

### 模板句式

> 真千金回家的车刚停稳，养母就让我拖着行李滚出去，顺手还叫人把我的房间清空了。

> 他们忙着把我从豪门门口赶走，我却在新家的桌前打开了直播间，准备先算算谁会倒霉。
