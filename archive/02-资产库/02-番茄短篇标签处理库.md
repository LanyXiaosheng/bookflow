# 番茄短篇标签处理库

## 这份库怎么用

不是给你“多写几个标签”，而是帮你在发书时少犯两种错：

1. 标签太散，系统不知道该把书推给谁
2. 标签太满，结果主分类、情节、情绪互相打架

默认按这 5 层来配：

1. 主分类
2. 情节
3. 角色
4. 情绪
5. 背景

建议总量控制在 `6-9` 个有效标签。

---

## 一、主分类库

主分类只定大盘，先保 `1` 个。

常用：

- 婚姻家庭
- 女生生活
- 男生生活
- 现言甜宠
- 虐心婚恋
- 青春虐恋
- 男生情感
- 女性成长
- 悬疑惊悚
- 玄幻仙侠
- 宫斗宅斗
- 男频衍生
- 女频衍生
- 年代
- 纯爱
- 其他
- 古言甜宠
- 古风世情
- 都市日常
- 男频脑洞
- 女频脑洞
- 民国旧影
- 古言虐恋
- 历史古代

错误示例：

- 把 `离婚`、`重生`、`白月光` 当主分类
- 自己发明主分类，例如 `现代言情 / 古代言情 / 历史`

快捷判断：

- 现言虐爽婚恋优先 `虐心婚恋`
- 家庭、婆家、孩子、财产资源冲突优先 `婚姻家庭`
- 女主脱身和成长更强时可用 `女性成长`
- 古言内宅、嫡庶、王府争斗优先 `宫斗宅斗`
- 古言替嫁和先婚后爱甜线更强时优先 `古言甜宠`
- 古言和离、前夫后悔、虐恋感强时优先 `古言虐恋`
- 四合院、家属院、分房、进厂、津贴优先 `年代`
- 守城、粮道、军令、降书优先 `历史古代`
- 系统、穿书、重生外挂优先 `女频脑洞 / 男频脑洞`

- 养崽文

- 游戏动漫
- 规则怪谈
- 民间奇闻
- 影视

- 都市异能

规则：

- 一次选 `2-4` 个平台现成情节标签
- 不要把 `离婚 / 白月光 / 宫外孕 / 房契 / 假军令` 这类具体事件词硬写成情节标签
- 具体事件词统一放进 `补充关键词`

情节标签和补充关键词的分工：

- `情节标签`：负责平台分发大方向
- `补充关键词`：负责补足具体卖点和标题承诺

例如：

- `婚恋 / 追妻火葬场 / 重生 / 打脸逆袭 / 权谋 / 架空`
  适合进情节标签
- `离婚 / 隐婚 / 白月光 / 宫外孕 / 难产 / 分房 / 假军令 / 替嫁`
  适合进补充关键词

规则：

- 优先使用平台现成角色标签
- 一般 `1-3` 个就够
- 不在角色池里的具体关系位，统一下沉到 `补充关键词`

角色标签和补充关键词的分工：

- `角色标签`：负责平台识别的人设大盘
- `补充关键词`：负责补具体关系位和身份冲突

例如：

- `白月光 / 霸总 / 医生 / 病娇 / 萌宝 / 特种兵`
  适合进角色标签
- `前夫 / 嫡姐 / 王爷 / 校尉 / 军官 / 军嫂 / 庶女`
  适合进补充关键词

## 四、情绪标签库

情绪回答：

`读者点进来最想得到什么情绪回报？`

常用：

- 先虐后甜
- 甜宠
- 虐文
- 爽文
- 救赎
- 惊悚
- 励志
- 沙雕搞笑

规则：

- 最好 `1-2` 个
- 优先使用平台现成情绪口径
- `追妻火葬场 / 清醒离场 / 后悔反噬 / 生死反噬 / 打脸 / 复仇`
  这类更细的情绪卖点，统一下沉到 `补充关键词` 或卖点提炼
- 不要把 `甜宠` 和 `虐文` 这类互斥词强塞在一起

情绪标签和补充关键词的分工：

- `情绪标签`：负责平台大盘期待
- `补充关键词`：负责更细的情绪兑现点
- 不要把 `甜宠` 和 `生死虐恋` 这类互斥词强塞在一起

## 五、背景标签库

背景回答：

`故事主要发生在什么盘子里？`

现言常用：

- 家庭
- 职场
- 校园
- 娱乐圈
- 现代
- 豪门世家

古言常用：

- 古代
- 豪门世家

现实向常用：

- 家庭
- 现代

规则：

- 优先使用平台现成背景口径
- `医院 / 王府 / 侯府 / 家属院 / 四合院 / 边城 / 粮道 / 工厂 / 院门口`
  这类更细的场域词，统一下沉到 `补充关键词`
- 背景不是越多越好，一般 `1-2` 个

背景标签和补充关键词的分工：

- `背景标签`：负责平台识别的场域大盘
- `补充关键词`：负责更具体的发生地点和权力场

## 十二、错位标签黑名单

下面这些情况尽量避免：

1. 正文不甜，却硬挂 `甜宠`
2. 开头根本没重生，却挂 `重生`
3. 没有豪门盘，却乱挂 `豪门总裁`
4. 全文是现实打脸，却挂太多轻松治愈词
5. 同时堆太多近义词：
   - `打脸 / 虐渣 / 爽文 / 反击 / 反杀`
   选最能代表正文的，不要全上

---

## 十三、出书时的最简模板

每次发书，先填：

```text
主分类：
情节标签：
补充关键词：
角色标签：
补充角色关系：
情绪标签：
背景标签：
推荐标签组合：
不建议使用的错位标签：
```

如果这 7 行填不出来，说明这本书的卖点还没钉死。
