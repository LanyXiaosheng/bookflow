# 选题库｜改编向中篇

## 使用原则

这个赛道挑题时，最重要的不是“短篇够不够疯”，而是：

- 能不能拉出稳定主线
- 能不能做人物弧线
- 能不能拆成多段卡点
- 能不能让短剧和漫剧都一眼看见改编感

---

## 第一批题型

### 1. 女频短剧｜婚后拉扯甜宠

1. 婚后住进老宅第一天，冷脸丈夫先替我给全家立了规矩
2. 新婚回门那天，冷脸老公先把给我继妹准备的嫁妆单撕了
3. 所有人都等我在豪门受气，只有冷脸老公每天准点回家接我下班
4. 结婚七天后他还叫我沈小姐，却替我把娘家账一本本收了回来

### 2. 女频短剧｜年代糙汉甜宠

1. 被婆家卖给老鳏夫那夜，村东头最凶的糙汉先踹开了院门
2. 恶婆婆把我赶出门那天，生产队最凶的男人先替我把嫁妆抬回了家
3. 前夫家逼我净身出户那天，村里最野的糙汉把户口本塞进了我手里
4. 分粮那天他们说我克夫，退伍糙汉先把工分本拍上了桌

### 3. 男频短剧｜古代小人物崛起

1. 被逐出侯府那天，我在县试榜上改回了母姓
2. 嫡母毁我功名那夜，我先拿下了县试案首
3. 被赶出侯府那天，我带着亡母的策论进了贡院
4. 他们夺我族谱那天，我把名字写上了皇榜

### 4. 女频漫剧｜萌宝玄学真千金

1. 三岁半下山认亲那天，我先救活了首富家的老太太
2. 下山认亲那天，玄门奶团先把假千金的平安符撕了
3. 豪门都嫌我是土包子，只有首富奶奶把我抱上了主位
4. 他们骗我投个好胎，我三岁半落地先拆了假千金的福运局

### 5. 男频漫剧｜风水玄学满级大佬

1. 豪门迁坟那天，所有人都等我出丑，我先挖出了断子绝孙局
2. 葬礼那天，我一眼看出棺材里躺的不是我师父
3. 封山三十年后，我为被剜天眼的徒弟下了山
4. 他们说我是江湖骗子，直到我把真龙脉从祖坟里挖了出来

---

## 选题筛选标准

- 开头必须直接进死局、羞辱场或异象场
- 主角必须先拿行动权，不能只挨打
- 前 `3` 章内必须出现第一次反击
- 每条题至少能拆出 `3` 个以上可视化爆点
- 结尾不能只赢一口气，必须回收到 `身份 / 关系 / 利益 / 权力`
