# 赛道总纲｜四合院年代反杀

## 赛道定位

这个赛道的核心不是单纯“年代感”，而是：

- 四合院 / 家属院 / 胡同群像
- 分房 / 工位 / 户口 / 抚恤 / 房契
- 邻里联手施压
- 女主或男主当众反杀

核心关键词：

- 四合院
- 年代
- 家属院
- 分房
- 工位
- 房契
- 街道办
- 广播站

## 为什么现在要补这个赛道

1. 能直接替代一部分现言婚恋的“资源争夺爽点”
2. 同样适合番茄短篇的公开打脸，但角色库完全不同
3. 能把“前夫 / 白月光 / 王爷 / 世子”切换成“院里邻居 / 街道办 / 厂办 / 继兄 / 堂弟”
4. 对平台来说，这是明显不同的一套时代皮和冲突皮

## 适合的核心题型

- 分房抢房反杀
- 顶岗进厂名额被抢
- 抚恤房 / 工伤补偿 / 烈属待遇被侵占
- 返城知青回院后房屋被占
- 邻里造谣逼婚 / 逼让房 / 逼让工位

## 标准结构

- 开头：分房、公示、返城、招工、街道办通知当场起爆
- 中段：院里联手压人，亲戚和邻居一起抢资源
- 后段：房契、户口、工位档案、广播站通报、街道办证明逐层翻开
- 结尾：房子、名额、补偿或工位回到主角手里，全院打脸

## 角色去重要求

- 不要连续两篇都写“继母抢房”
- 不要连续两篇都写“进厂名额被顶”
- 同一周轮换 `继兄 / 堂弟 / 邻居 / 三叔 / 街道办干事 / 厂办主任`
- 场景轮换 `院门口 / 街道办 / 广播站 / 工厂公告栏 / 分房会`
