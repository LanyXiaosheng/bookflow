# 写作实时监控表｜海岛家属院离婚冷静期

## 每 10 章自检一次

### 一、读者为什么还在读

1. 这一段是在兑现“公开站边”还是只在重复拉扯？
2. 这一段有没有新的军婚专属压力，而不是普通现言矛盾？
3. 这一段女主有没有更进一步把自己的位置立住？
4. 这一段男主有没有拿出动作，而不是只会想和忍？

### 二、有没有写偏

1. 去掉“海岛家属院”后，这一段还能成立吗？
2. 去掉“军婚规则道具”后，这一段还剩什么？
3. 这一段是不是已经开始像总裁文、婆媳文或白月光文？
4. 这一段是不是只剩男女主谈感情，没有群像和公共场景？

### 三、必须保留的元素

1. 公共场景
2. 规则道具
3. 群像压力
4. 女主专业能力
5. 男主公开动作

少掉两项以上，就说明军婚味在变淡。

## 章节级红线

1. 不连续三章都只有室内对话。
2. 不连续两次冲突都来自婆家。
3. 不连续两次高光都只给男主。
4. 不用“误会解除就和好”替代真正的婚姻修复。
5. 不把任务线写成专业说明书。

## 真正的爽点提醒

这本书最值钱的爽，不是打谁的脸。

而是：

- 她终于不被默认懂事
- 他终于学会把偏爱放到明面
- 一群原本沉默的女人开始彼此撑腰

## 如果卡文，优先回到这 4 个问题

1. 这一章谁在公共场景里失去体面？
2. 谁先动手去把体面拿回来？
3. 这件事为什么只有军婚环境才会成立？
4. 这一章之后，男女主的站位有没有发生变化？
