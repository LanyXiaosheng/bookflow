# 卷别与爆点规划｜海岛家属院离婚冷静期

## 总体节奏

- 总章数建议：96 章
- 节奏结构：18 + 20 + 20 + 18 + 20
- 每卷必须同时推进：婚姻线、群像线、身份线

## 第一卷：上岛的三十天

- 章节：1 到 18
- 读者为什么读：想看她都递了离婚协议，为什么还会被迫留在他的世界里
- 核心爆点：
  1. 开篇就是离婚冷静期和登岛
  2. 第一次家属院公开冲突
  3. 女主写出第一份申诉书
  4. 台风夜公共护短
- 卷尾钩子：手续没办成，但所有人已经默认她会留下来

## 第二卷：家属院不是避风港

- 章节：19 到 38
- 读者为什么读：想看她怎么从“周既明的妻子”变成“家属院都来找的沈律师”
- 核心爆点：
  1. 家属就业冲突升级
  2. 孩子入学名额风波
  3. 周母上岛施压
  4. 男主第一次在家属大会公开站边
- 卷尾钩子：顾海莲正式把她当成眼中钉

## 第三卷：沉默的人开始改口

- 章节：39 到 58
- 读者为什么读：想看男主能不能把“我支持你”从私下变成正式动作
- 核心爆点：
  1. 女主争取驻岛法律援助合作
  2. 对手放出“她借军婚身份牟利”的流言
  3. 男主晋升窗口受影响
  4. 两人第一次并肩处理同一场公开危机
- 卷尾钩子：女主决定撤回最后一次离岛申请，但还没有撤回离婚

## 第四卷：风暴眼里的夫妻

- 章节：59 到 76
- 读者为什么读：想看经历真正的长时间分离后，他们还能不能做到互相托底
- 核心爆点：
  1. 男主长期任务离岛
  2. 女主独撑家属院危机
  3. 顾海莲旧账被撬开
  4. 两个人摊开五年婚姻旧账
- 卷尾钩子：不是和好，而是第一次认真谈“如果继续，婚姻规则要怎么改”

## 第五卷：重新做一次夫妻

- 章节：77 到 96
- 读者为什么读：想看两个都拥有离开能力的人，为什么还会重新选择彼此
- 核心爆点：
  1. 驻地调整和搬迁分流
  2. 男主面临远航或岸岗选择
  3. 女主拿到城里高薪邀请
  4. 家属服务中心挂牌
  5. 公开确认关系与身份
- 终极回收：她被认的不只是“家属”，而是她自己

## 必须反复出现的高价值画面

1. 码头、渡船、海风、台风预警这些海岛场景
2. 家属院开会、张榜、签字、递材料这些公共动作
3. 男主在众目睽睽下的站边动作
4. 女主拿规则和证据把混乱理清的瞬间
5. 女性群像之间从观望到结盟的变化
