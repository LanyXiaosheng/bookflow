# 项目说明｜都劝我做懂事军嫂，可我偏要他在全院先认我

## 项目定位

- 平台方向：女频长篇
- 题材：现代军婚 / 海岛家属院 / 成年婚姻修复 / 群像成长
- 预计体量：28 万到 35 万字，约 90 章到 100 章
- 核心卖点：不是“军装滤镜 + 甜宠”，而是把军婚里最值钱的纪律感、等待感、公开站边、家属院群压和成年人的重新结盟写透
- 核心爽点：所有人都要她懂事，偏偏她不忍了；所有人都觉得他不会表态，偏偏他被逼得只能在全院先认她

## 最终书名

《都劝我做懂事军嫂，可我偏要他在全院先认我》

## 备用书名

1. 《离婚冷静期上岛后，我成了他家属院里最难惹的人》
2. 《离婚冷静期那三十天，整个家属院都在等他先低头》
3. 《海岛随军第一天，我把家属院的规矩掀了》

## 标题打法

这题的标题不能只写“军婚”和“海岛”，那样有识别度，但不够爽。

必须同时满足 3 件事：

1. 有军婚身份词，比如 `军嫂 / 家属院 / 随军 / 全院`
2. 有公开场景词，比如 `全院 / 家属院 / 当众 / 上岛第一天`
3. 有反击动作词，比如 `先认我 / 最难惹 / 掀了规矩 / 等他低头`

真正能打的标题，不是偏文艺，而是让读者一眼就知道：

`这女主不忍了，这男主必须公开站位。`

## 一句话故事

劳动仲裁律师沈见夏和海军护卫舰副舰长周既明结婚五年，走到离婚冷静期尽头。为了办完最后手续，她跟着一纸调令上了南方海岛家属院，却意外卷进一连串军属权益风波。她原本只想离开，最后却在替别的军嫂讨体面时，逼得那个最会沉默的丈夫第一次把“站她这边”落成了公开动作。

## 核心卖点

### 1. 军婚味从“家属院系统”里出来

- 驻地住房
- 家属牌
- 随迁就业
- 子女入学
- 转业去留
- 批文和申诉

这些都是普通现言没有的硬道具。

### 2. 不是老套追妻，而是离婚冷静期里的二次结盟

- 她不是回头等爱
- 他也不是一夜开窍
- 两个人是在一次次公共事件里，重新决定还要不要做夫妻

### 3. 女主有职业能力，不是纯受气军嫂

沈见夏的武器不是眼泪，是证据链、申诉书和对规则的理解。

### 4. 男主价值不靠嘴，靠动作兑现

周既明的高光不是“我爱你”，而是：

- 当众纠正家属院对她的称呼
- 在亲属施压时先切断默认站位
- 在正式场合承认她的名字、职业和位置

## 为什么它适合做长篇

这题不止有一段婚姻矛盾。

它还能持续展开：

- 家属院群像
- 军属现实问题
- 成年婚姻修复
- 女性事业再建立
- 男主从“责任正确”到“情感正确”的成长

所以它不是短篇题硬拉长，而是天然有多卷推动力。

## 本项目的硬性去重要求

1. 不写年代重生、穿书、空间、一胎多宝。
2. 不写白月光误会和抓奸换皮。
3. 不写男主失联归来就能一次性洗白。
4. 不写女主全程等男主拯救。
5. 不写任务细节炫技，任务线只给关系施压。
6. 去掉“军婚”标签后，如果故事还能原样成立，说明写偏了。
