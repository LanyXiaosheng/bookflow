# 模板应用说明｜夜班进厂第一天，考勤机上多了一个死人名字

## 一、标题模板命中

本项目命中以下高点击结构：

1. `强身份 + 第一时间异常`
2. `日常场景 + 死人名字 + 即时兑现`
3. `规则怪谈 + 系统异常 + 旧案翻出`

当前标题：

`夜班进厂第一天，考勤机上多了一个死人名字`

这个标题的优势是：

- “夜班进厂第一天”自带低位和陌生环境
- “考勤机”是高日常感设备
- “死人名字”形成强反差

## 二、开篇钩子结构

采用的是：

`入厂打卡 -> 死人名字出现 -> 事故公示对上 -> 第一波恐惧落地`

这样处理能在前三屏内完成：

1. 场景建立
2. 异常落地
3. 危险来源明确

## 三、冲突升级逻辑

不是单点闹鬼，而是整套厂区系统联动异常：

- 考勤机先出问题
- 巡检枪和工位终端继续跟进
- 门禁和广播把危险推到整厂
- 最后落到“未下班人员”回收逻辑

## 四、爽点设计

男频爽点不放在单纯熬夜躲鬼，而放在：

- 男主主动摸规则
- 用工控逻辑反推系统漏洞
- 反过来用结班程序给旧夜班关机

## 五、后续扩写标准

后续所有版本统一抓住 5 件事：

1. 死人名字是否首屏落地
2. “未下班人员”标签是否足够危险
3. 火灾旧案是否成为主线驱动力
4. 男主是否尽快从被动转主动
5. 结局是否落到“补最后一张下班卡”
