# 爆点节奏表｜宠妾灭妻那夜，我先把休书贴上了宗祠

## 节奏总览

- 紧场：第 `1 / 2 / 3 / 4 / 5 / 6 / 8 / 9 / 10` 章
- 松场：第 `7` 章
- 松场功能：
  - 第7章：把今夜公审和前世旧案并线，让读者从“看她掀桌”升级到“看她为什么必须先掀桌”

## 爆点类型覆盖

- 场面炸点：第 `1 / 3 / 9 / 10` 章  
  贴休书、开宗祠、全族围观、和离离府
- 信息揭示：第 `4 / 5 / 6 / 7 / 8` 章  
  嫁妆账、乳母账、宗谱样本、接生证词、偏院旧案
- 利益冲突：第 `3 / 4 / 8 / 9` 章  
  争的不是外室进门，而是主母位、宗谱、嫁妆和侯府体面
- 情绪回本：第 `1 / 2 / 7 / 10` 章  
  前世惨死、今夜反打、旧案回锤、最终切割

## 第1章炸点

- 外室抱子进门，侯府逼主母认局
- 女主不哭不闹，先把休书贴上宗祠
- 私辱被她强行改成全族公审

## 第4章爆点

- 嫁妆册、乳母账一起抬进祠堂
- 读者意识到侯府不是临时起意，而是早就在给外室母子铺路
- 情绪从“恶心”升级成“系统性夺位”

## 第6章爆点

- 接生婆和车夫证词被拖进来
- 侯府说辞开始前后打架
- 女主把今夜换局和前世死局连接起来

## 第8章爆点

- 女主把族规和宗谱反手压回去
- 谢承砚和老夫人同时破防
- 侯府第一次面对“她真能让全京城知道”的现实压力

## 第10章兑现点

- 和离、清账、切谱一次完成
- 女主带走嫁妆和名声
- 侯府保住了门匾，却保不住脸

## 前30%试读卡点

- 最好卡在：宗祠门前贴休书，女主第一句问“这孩子，你们打算按什么身份进谱？”
- 要求：
  - 前 `300` 字内出外室抱子进门死局
  - 前 `600` 字内出“贴休书 + 开宗祠”动作
  - 前 `30%` 内必须出现 `账册 / 宗谱 / 人证` 三者至少两项

## 最大反转点

- 侯府要抬外室进门不是简单宠爱，而是早就规划好的夺位和切谱
- 前世女主不是输给外室，而是输给了自己替侯府顾全的那点体面

## 情绪回本点

- 女主不是等着被休，而是先让祖宗牌位见证侯府失德
- 夫君和婆母从高高在上，走到宗祠里被她逐项清算
- 结尾不是“留下掌权”，而是“带着主动权体面离开”

## 余波场设计

- 第5章：柳姨娘第一次露怯，让读者知道她并不是稳赢
- 第7章：偏院旧案回收，把今夜反打从爽点抬到命运回收
- 第9章：消息外流后，侯府最怕的“丢脸”终于落地
