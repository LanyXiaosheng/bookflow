# 项目说明｜宠妾灭妻那夜，我先把休书贴上了宗祠

## 项目定位

- 平台方向：番茄短篇
- 题材：古代言情 / 主母反杀 / 宠妾灭妻 / 祠堂公审 / 和离打脸
- 核心卖点：侯府要女主给外室腾路，女主却抢在被休之前先开祠堂、贴休书，把私辱拉成全族公审

## 一句话故事

裴云昭替侯府操持三年，替夫君挡下账烂、人烂、外室烂，到头来只等来一句“让出正妻位，给孩子腾宗谱”。前世她忍了，所以死在偏院。这一世，宠妾灭妻那夜，她没等侯府给她休书，而是先把休书贴上宗祠，当着祖宗牌位、族老和满府下人的面，把侯府最想藏的脏事一件件撕开。

## 核心冲突

### 外部冲突

1. 侯府要抬外室进门，还要把孩子塞进宗谱
2. 夫君、婆母、族中长辈都想用体面压死女主
3. 女主若不先动手，就会再次成为“侯府丑事”的背锅人

### 内部冲突

1. 女主前世困在“主母就该顾全大局”的规训里
2. 这一世她必须先学会把体面砸回侯府脸上
3. 她要赢的不只是和离，而是彻底拿回自己的人生、嫁妆和名声

## 情绪钩子

- 他们要她给外室腾位，她先把休书贴上宗祠
- 他们想私下羞辱，她偏要全族围观
- 她不是等着被休，而是先让侯府在祖宗面前丢尽脸
- 前世她死在偏院，这一世她先送婚事上路

## 适配原因

这个题适合当前工作区主方向：

- 古言主母 / 宅斗 / 二嫁权势是当前高稳方向
- `宠妾灭妻 + 宗祠 + 休书` 的情绪点非常直接
- 开局就能形成强场面，适合番茄短篇前段起爆
- 礼法、族规、宗谱都能成为女主反杀工具，利于写爽感和权威感
