## 核心设定

- **主角**：宋以宁，婚前是顶级律所合伙人，婚后被前夫江承以"公司需要你"为由劝辞职，离婚时他说"你不过是个家庭主妇，离了我什么都不是"
- **死局**：离婚协议签完，宋以宁净身出户，带走的只有一个律师执照和三年没用的专业技能
- **反杀手段**：离婚后重回职场，三年内做到某顶级律所首席法务官；江承公司上市，法律尽调和合规审查全程由她主导，她用职业身份帮他过了所有关卡，他直到敲钟那天才知道那个"宋律师"是谁
- **最大读点**：宋以宁接这个案子不是为了报复，是因为这是她职业生涯最重要的一单；她帮他过关，是因为她是专业的，不是因为她还爱他。敲钟那天他找她，她说："江先生，我们是甲乙方关系，服务费已结清。"

## 言情向标注

- **类型**：爽文向
- **经典套路**：离婚逆袭、职场打脸、前夫追妻
- **反套路破局**：女主帮前夫不是因为爱，是因为职业操守；她的逆袭不靠男人，靠的是三年没荒废的专业能力；结局她不回头，前夫追不追是他的事
- **信息差机制**：读者第1章知道宋以宁就是那个"宋律师"，江承直到第8章敲钟现场才知道；江承的白月光全程以为宋以宁在家带孩子，第7章被打脸
