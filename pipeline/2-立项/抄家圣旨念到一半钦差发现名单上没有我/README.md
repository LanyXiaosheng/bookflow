## 核心设定

- **主角**：谢映雪，谢府嫡长女，三年前以"冲撞圣驾"为由被皇帝当众斥责、逐出谢府，实为她主动设局，借皇帝之手把自己从谢府除籍，另立独立户籍
- **死局**：谢府因谢父通敌被满门抄斩，所有人都以为谢映雪也在劫难逃
- **反杀手段**：圣旨宣读时，钦差发现名单上没有谢映雪——她三年前已不是谢府之人，法理上与谢府无关；她不仅活下来，还凭独立户籍和三年积累的产业，成为谢府唯一的善后人
- **最大读点**：谢父通敌是真的，谢映雪三年前就知道，她设局除籍不是为了逃，是为了在谢府覆灭后有能力收拾残局；她救下了谢府的旁支和无辜家眷，用的是她自己的钱和关系

## 言情向标注

- **类型**：虐爽向
- **经典套路**：抄家、除籍、重生式预判
- **反套路破局**：女主不是重生，是真的三年前就预判了结局；她"被逐出"是她自己求来的，不是受害者；男主是钦差，他宣读圣旨时发现名单漏了她，第一反应不是补上，而是去查她为什么不在名单里
- **信息差机制**：读者第1章知道除籍是谢映雪自己设的局，钦差第5章才查清楚；谢父直到被押走前都以为女儿是被皇帝厌弃，不知道她是故意的
