# 产检报告寄到婆家那天全家才知道孩子不是他的

## 基本信息

- **赛道**：现言婚恋火葬场 / 虐爽向
- **类型**：虐爽向
- **一句话卖点**：「被出轨的妻子 + 在产检报告曝光的死局里 + 用一份DNA鉴定反杀全家」

## 核心设计

- **经典套路**：出轨 + 孕期背叛 + 婆媳矛盾
- **反套路破局**：孩子不是丈夫的——但真相不是女主出轨，而是丈夫不是婆家亲生的（信息反转）
- **信息差**：读者比所有人都早知道"丈夫不是婆家亲生"这个真相，形成优越感+期待感双驱动
