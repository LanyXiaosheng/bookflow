## 核心设定

- **主角**：谢云舒，前朝遗臣之女，三年前偶然得到皇帝私通敌国的密信原件，一直藏着未用，以此换取家族平安
- **死局**：太后以"赐婚"为名将她送入宫，实为人质，断绝她手里把柄的威胁；皇帝以为她会用把柄要挟，已备好灭口方案
- **反杀手段**：入宫前一夜，她把密信原件装进匣子，亲手送还皇帝，附一张字条："物归原主，我从未打算用它"；皇帝的灭口计划当场作废，他反而陷入被动
- **最大读点**：谢云舒三年前就知道那封密信是皇帝故意让她"发现"的——是一个测试，测她会不会用把柄要挟。她选择藏而不用，是因为她看穿了这是陷阱；送还，是因为她要让他知道，她从一开始就没有上钩

## 言情向标注

- **类型**：虐爽转甜宠
- **经典套路**：宫斗、赐婚、把柄博弈
- **反套路破局**：女主不是被动入宫的棋子，她入宫前就已经完成了最关键的一步棋；皇帝以为自己在布局，其实从第一天起就被她看穿
- **信息差机制**：读者第1章知道谢云舒早就看穿了密信是陷阱，皇帝第6章才知道；太后以为赐婚是制衡，第8章发现自己反而成了谢云舒借力的跳板
