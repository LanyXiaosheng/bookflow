## 核心设定

- **主角**：林晚，离婚两年，外婆是她最亲的人；前夫顾淮在婚姻里沉默寡言，离婚时她以为他不在乎这个家
- **死局**：外婆去世，遗产公证现场，母亲和舅舅都以为老宅归林晚，公证员念出的受益人是前夫顾淮
- **反杀手段**：公证员同时宣读外婆的亲笔信——外婆知道是顾淮三年来每个月偷偷替她付医药费，知道是他在林晚不知情的情况下陪外婆做了最后一次手术；外婆改遗嘱，不是要给顾淮财产，是要让林晚知道，她离婚时以为"他不在乎"的那个人，其实一直在
- **最大读点**：顾淮从未告诉林晚他做过这些，因为他知道她不需要被感动，她需要的是被平等对待；外婆的遗嘱是最后一封信，替他说出了他三年没说的话

## 言情向标注

- **类型**：虐心转甜宠
- **经典套路**：离婚、遗产、前夫追妻
- **反套路破局**：反转不是"前夫其实很坏"，而是"前夫其实一直很好，只是不会说"；外婆不是工具人，她是真正看见了顾淮的人；林晚的成长是从"我以为他不在乎"到"我从来没有认真看过他"
- **信息差机制**：读者第2章知道顾淮一直在付医药费，林晚直到公证现场才知道；母亲和舅舅以为顾淮是来争遗产的，第7章被外婆的信打脸
