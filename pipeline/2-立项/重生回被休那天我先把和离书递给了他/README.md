# 重生回被休那天我先把和离书递给了他

## 赛道
古言重生打脸 / 虐爽向

## 一句话卖点
重生嫡女 + 在被休弃的死局里 + 先一步递出和离书让全京城看他的笑话

## 类型标签
- 类型：虐爽向
- 经典套路：重生、被休、复仇
- 反套路破局：不是被动等着被休再反击，而是重生第一秒就主动递和离书——让所有人措手不及
