## 核心设定

- **主角**：孟迟，31岁，社区儿童图书馆负责人，离婚五年，独自带女儿
- **奶宝**：孟星星，5岁，爱画星星，生日愿望是“妈妈以后不要那么累”
- **死局**：女儿生日会上，前夫周砚舟带着父母和改姓申请出现，要求女儿改姓周，并以“周家血脉”名义争生日和探视主导权
- **反杀手段**：孟迟拿出五年抚养费记录、医院缴费单、户口迁移材料和拒收转账截图，证明周家从未养过孩子，却想在孩子长大后摘果子
- **最大读点**：前夫以为改姓是认祖归宗，结果被女儿一句“我跟妈妈姓，是因为妈妈没有丢下我”击穿
