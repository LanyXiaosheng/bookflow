## 核心设定

- **主角**：沈意，某律所合伙人，三年前以个人信用为前男友林珩的公司提供上市担保，此后两人维持着"分手但未正式解除担保"的模糊关系
- **死局**：婚礼请柬寄到沈意公司，她才知道林珩三个月前已与白月光江晴订婚，他一直没告诉她，因为担保解除需要她本人签字，他在等上市过会
- **反杀手段**：沈意当天联系证监会律师，依法撤回个人担保函，上市材料当日作废；同时将林珩三个月来以"维系关系"为由套取她签字的系列文件整理成证据，向监管机构举报信披违规
- **最大读点**：林珩的白月光江晴其实早就知道沈意的存在，她默许林珩拖着沈意是因为她自己也需要上市套现——江晴是林珩公司的早期投资人，上市是她退出的唯一通道

## 言情向标注

- **类型**：爽文向
- **经典套路**：白月光、商战、被利用后反杀
- **反套路破局**：沈意不是被动受害者，她第1章就察觉到异常，只是在等一个合法的撤回时机；江晴不是单纯的情敌，她和林珩是利益共谋，最后被沈意一并清算
- **信息差机制**：读者从第1章知道沈意已经在准备撤回担保，林珩直到第7章才意识到她早有准备；江晴以为沈意不知道她的投资人身份，读者第2章就知道沈意查清楚了
