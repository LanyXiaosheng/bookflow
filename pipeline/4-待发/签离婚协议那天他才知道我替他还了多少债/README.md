## 核心设定

- **主角**：谢宁，婚后五年独自扛起家庭债务，丈夫陆晟始终以为是白月光苏晴出手相助，对苏晴感激备至、对谢宁日渐冷漠
- **死局**：陆晟提出离婚，理由是"我们之间早就没感情了"，并暗示想和苏晴在一起；谢宁同意，委托律师办理
- **反杀手段**：离婚协议签署现场，律师出示五年来谢宁的还款流水和债务转让协议，三百万的债是谢宁一笔一笔还的，苏晴从未出过一分钱；谢宁当场提出财产分割，按贡献比例，她拿走婚后所有资产的85%
- **最大读点**：苏晴其实知道真相，她一直在领陆晟的感激、坐收渔利，却从未澄清；谢宁早就知道苏晴在撒谎，她选择沉默是因为她在等一个足够体面的离场时机

## 言情向标注

- **类型**：虐爽向
- **经典套路**：白月光、火葬场、离婚
- **反套路破局**：谢宁的闺蜜是律师，从第1章就在帮她准备证据；苏晴不是单纯的小三，她有自己的算计，最后被谢宁一并清算
- **信息差机制**：读者从第1章看见谢宁的还款记录和她对苏晴的了解，陆晟直到签字现场才知道真相；苏晴以为谢宁不知道她在撒谎，读者第2章就知道谢宁全清楚
