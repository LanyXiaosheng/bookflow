## 核心设定

- **主角**：沈窈，侯府庶女，外柔内刚，精通毒理和医术，前世被嫡姐算计死在将军府
- **死局**：嫡姐临嫁前装病，庶女被迫顶替嫁给"克妻煞星"裴渊，娘家还在嫁妆里藏了和离书，打算等她站稳脚跟再接回来当棋子
- **反杀手段**：洞房夜当着裴渊的面烧掉和离书，宣布自己不走；随后用医术治好裴渊的暗伤，揭出嫡姐才是真正的毒手
- **最大读点**：裴渊其实是当朝摄政王秘密身份，他早知道沈窈被换，却选择接受——因为他查过，只有沈窈没有参与那场针对他的阴谋

## 言情向标注

- **类型**：虐爽转甜宠
- **经典套路**：替嫁、克妻煞星、隐藏身份
- **反套路破局**：婆母（将军府老夫人）第一章就站沈窈，因为她看出嫡姐才是祸根；"克妻"之名是裴渊自己放出去的，为了筛掉所有图谋他的人
- **信息差机制**：读者从第1章就知道裴渊有隐藏身份和目的，沈窈第5章才知道；娘家藏在嫁妆里的和离书读者第1章看见，裴渊第2章就发现了
