## 核心设定

- **主角**：顾云棠，镇北侯府嫡长女，前世被庶弟顾明川联合继母伪造族谱、捏造私生子身份，导致侯府被抄、父亲下狱、她本人被发卖
- **死局**：重生回抄家前夜，距离钦差登门只剩一夜，族谱已被动过手脚，父亲毫不知情
- **反杀手段**：连夜入宗祠，用前世记住的真实族谱内容将伪造痕迹一一还原，并在族谱末页附上庶弟生母的真实来历证明——她是敌国细作，庶弟才是真正的私生子
- **最大读点**：前世顾云棠以为继母是主谋，重生后发现继母也是被庶弟利用的棋子，庶弟才是从头到尾布局十年的人
