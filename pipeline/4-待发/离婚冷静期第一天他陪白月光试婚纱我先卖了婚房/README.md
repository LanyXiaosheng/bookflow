## 核心设定

- **类型**：虐爽向 / 婚恋火葬场。
- **经典套路**：离婚冷静期 + 白月光 + 婚房财产争夺 + 追妻火葬场。
- **反套路破局**：女主不撕小三、不等男主回头，而是先切财产、切住处、切共同债务，让“冷静期”变成她的清算期。
- **信息差机制**：男主以为婚房是夫妻共同财产，实际上首付、装修、贷款流水都能证明女主贡献更大；白月光以为能直接入住，结果房子已被女主合法挂牌并锁定买家。
- **主角**：许知晚，31 岁，家居品牌运营总监，情绪稳、手腕硬，擅长合同和预算，不靠哭闹争尊严。
- **死局**：离婚冷静期第一天，她去婚纱店退当年没穿成的礼服，却看见丈夫周砚陪白月光顾明棠试婚纱，婆婆还催她把婚房腾出来。
- **反杀手段**：她现场拍下试婚纱证据，立刻联系中介挂牌婚房、冻结共同账户大额支出、整理装修发票和贷款流水，要求周砚承担婚内赠与返还与共同债务分割。
- **最大读点**：所有人以为她会争男人，结果她只争自己的钱、房和自由；周砚签完财产协议才知道，婚房从来不是他给她的，是她把他从烂账里托起来的。
