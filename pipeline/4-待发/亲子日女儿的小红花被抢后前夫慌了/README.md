## 核心设定

- **主角**：许晚，30岁，儿童康复机构课程顾问，离婚四年，独自养女儿
- **奶宝**：许糖糖，4岁，轻微过敏体质，嘴甜但敏感，最怕别人说她“没爸爸”
- **死局**：幼儿园亲子日，前夫江砚带白月光和白月光儿子出现，想用父亲身份抢走糖糖的入园名额和展示机会
- **反杀手段**：许晚拿出疫苗本、出生记录、急诊缴费单和四年照护记录，证明江砚长期缺位，也揭出白月光孩子冒用糖糖资料申请名校名额
