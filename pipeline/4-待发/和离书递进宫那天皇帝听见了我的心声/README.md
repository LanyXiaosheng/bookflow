## 核心设定

- **类型**：虐爽转甜宠。
- **经典套路**：和离 + 读心术 + 前世背锅 + 帝王护短。
- **反套路破局**：皇帝不是高高在上的裁判，而是通过心声发现女主才是保住江山的人。
- **信息差**：皇帝能听见女主心声，女主不知道；读者知道皇帝每次护她都有原因。
- **主角**：姜蘅，前将军夫人，前世替丈夫和朝堂背锅惨死，今生只想和离保命。
- **死局**：丈夫拿军功逼她继续忍受白月光和婆母羞辱，朝臣也想用她堵流言。
