# 言情向爆款短故事共性

适用范围：番茄短篇、微百小说网同类言情向短故事。用于选题评分、立项大纲、前 30% 试读区检查。

---

## 一、总原则

言情短故事不是单纯写恋爱，而是用关系冲突承载情绪兑现。

核心判断：

1. 女主有没有清醒、稳定、可传播的人设标签。
2. 男主是否提供明确且唯一的情绪价值。
3. 开局是否借用熟悉套路，但后续用反套路破局。
4. 爽点、甜点、虐点是否绑定女主自我价值，而不是只靠男主宠爱。
5. 每 1000 字至少给读者一次认知变化或情绪升级。

---

## 二、甜宠向模型

### 1. 爆款共性

- **女主内核稳定**：独立清醒，不依附渣男或原家庭，关系里有主动权。
- **男主坚定护短**：情感指向清晰唯一，把女主放在平等位置，不用控制欲冒充深情。
- **经典套路切入**：替嫁、真假千金、契约婚姻、白月光、先婚后爱都可以用。
- **反套路破局**：配角不脸谱化，原本应当为难女主的人可以成为同盟。
- **小事发糖**：记偏好、给选择权、公开站队、在关键场合替她撑腰。

### 2. 立项公式

`经典死局 + 清醒女主先破局 + 反套路配角站队 + 真男主坚定选择 + 女主赢得漂亮`

可用开局：

- 白月光回归，渣男要女主退位，长辈却先把渣男踢出局。
- 替嫁冲喜，所有人等着看笑话，病弱夫君却第一晚递给她府库钥匙。
- 契约婚姻到期，女主准备走人，男主先公开所有权益归她。
- 女主想找“男老婆”，男主主动承担生活照料，但不牺牲自尊和能力。

### 3. 甜宠检查卡

| 检查项 | 通过标准 |
|--------|----------|
| 女主主体性 | 女主的赢不是男主施舍，而是自己先做出选择 |
| 男主苏感 | 男主护短不双标，不在关键时刻装瞎 |
| 配角新鲜度 | 至少 1 个配角跳出脸谱化，如婆婆站女主、情敌成同盟 |
| 发糖质感 | 甜点推动事业、打脸、关系进展三者之一 |
| 反套路程度 | 读者以为要雌竞，实际转向女性互助或共同打脸 |

## 三、虐爽向模型

### 1. 爆款共性

- **信息差强**：弹幕、读心术、系统旁白、隐藏身世、未来记忆都可以制造读者先知。
- **熟题微创新**：重生、替身、火葬场、白月光、伪兄妹、带球跑都能用，但必须加一个新变量。
- **高密度反转**：章章有钩子，前 30% 必须完成一次公开翻脸或不可逆决定。
- **先抑后扬**：前期可以虐，但女主必须越来越清醒，不能一直被动挨打。
- **情绪闭环**：背叛要有反击，误会要有真相，真心要有补偿，伤害要有代价。

### 2. 万能结构

`错位认知 → 极致守护/背叛 → 真相揭晓 → 破局圆满`

执行要求：

1. **错位认知**：主角误判关系、身份、动机；读者通过信息差知道更深一层。
2. **极致守护/背叛**：把人物推到极限，让爱或背叛变成不可忽视的行动。
3. **真相揭晓**：反转必须改变局势，不只是解释背景。
4. **破局圆满**：女主完成反击或新生，情绪账结清。

### 3. 人设标签

采用 `1 个核心特质 + 1 个反差行为`。

示例：

- 微醺迷糊女主 + 底线极硬。
- 重生学霸少女 + 救赎偏执男主。
- 看似柔弱女主 + 满级证据链大佬。
- 高冷霸总 + 只能听见女主心声。
- 复仇女主 + 只信事实不信眼泪。

### 4. 虐爽检查卡

| 检查项 | 通过标准 |
|--------|----------|
| 信息差 | 读者至少比主角多知道 1 个关键信息 |
| 新变量 | 熟题中有一个可传播的新钩子，如弹幕、遗嘱、AI记忆、孕检单 |
| 反击速度 | 前 3000 字内女主必须做出不可逆动作 |
| 反派动机 | 坏人有逻辑动机，不是只会发疯的工具人 |
| 情绪兑现 | 每个虐点后面都有对应爽点回收 |

## 四、前 30% 试读区模板

前 30% 必须完成四件事：

1. **第一屏起爆**：用物件、台词、证据或公开场合制造冲突。
2. **主角不按套路反应**：不哭闹，不自证，先做不可逆动作。
3. **抛出信息差**：弹幕、录音、孕检单、遗嘱、族谱、账本、监控等。
4. **卡在更大翻脸入口**：章尾让读者知道下一章会公开打脸或真相升级。

禁用开局：

- 先介绍家庭背景。
- 先写男女主如何相爱。
- 先解释世界观。
- 女主被羞辱三章还没有反击动作。

---

## 五、立项加分项

- 配角清醒站队，尤其是婆婆、长辈、情敌、继母等传统阻碍位反向支持女主。
- 男主的爱通过行动兑现，而不是只会说“我错了”。
- 女主事业线和情感线互相加成。
- 标题里有强物件：孕检单、离婚协议、族谱、婚书、遗嘱、账本、弹幕。
- 结尾不是单纯复合，而是女主完成选择权回收。
