# 爆点节奏

番茄短篇的核心逻辑：前 3000 字决定生死，中段不能泄，结尾要回本。

---

## 节奏骨架

| 位置 | 功能 | 要求 |
|------|------|------|
| 第 1 章 | 起爆 | 直接给冲突或证据，不铺背景 |
| 第 2 章 | 升温 | 新信息加入，压力升级 |
| 第 3 章 | 第一炸 | 公开对峙或重大揭露 |
| 第 4 章 | 喘息 | 短暂缓释，但埋下一轮伏笔 |
| 第 5 章 | 反转 | 局势逆转，读者预期被打破 |
| 第 6 章 | 深挖 | 揭示更深层的真相或动机 |
| 第 7 章 | 蓄力 | 为高潮做最后准备 |
| 第 8 章 | 高潮 | 最大冲突爆发 |
| 第 9 章 | 收网 | 所有线索汇聚 |
| 第 10 章 | 兑现 | 给读者承诺的爽感 |

---

## 试读区（前 30%）硬规则

番茄的冷启动窗口极短，前 30% 是唯一的生存区。

1. **第一屏**：直接给主冲突或主证据
2. **前 500 字**：读者必须知道这篇最值钱的刀是什么
3. **前 1000 字**：第一炸必须完成
4. **前 3000 字**：必须卡在更大证据、反转或公开翻脸入口

### 试读区禁止

- 不允许前 3 章还在铺背景
- 不允许用回忆开场
- 不允许第一章只有内心独白
- 不允许前 3000 字没有对手出场

---

## 防流水账 6 条

1. 每个核心情节补足 `铺垫 → 过程 → 余波`
2. 每章至少 2 个变化点（1 事件推进 + 1 关系/认知变化）
3. 每场戏开写前先回答：这场戏改变了什么
4. 每场戏至少有 目标/阻力/代价，缺一项就是空场景
5. 每场戏至少留 1 个信息差和 1 个细节锚点
6. 不要只写解释和概述，要写现场

---

## 松紧交替

不能从头到尾都是高潮，也不能连续两章都在缓释。

- **紧场**（短句、快节奏、高密度信息）：第 1、3、5、8、10 章
- **松场**（长句、情绪沉淀、关系推进）：第 2、4、6、7、9 章

松场不是无事发生，而是：
- 揭示人物内心
- 埋下一轮伏笔
- 制造虚假安全感（为下一个炸点服务）

---

## 中段防塌

中段（第 4-7 章）最容易写成流水账。防塌方法：

1. 每章必须给新信息（新证据、新人物、新规则）
2. 不重复同一类冲突（不能连续三章都是「被欺负→反击」）
3. 至少有一次视角切换或信息差揭露
4. 中段结尾必须比中段开头的局势更紧张

---

## 虐爽节奏检查

短篇特有——虐点和爽点的分布必须合理：

```
理想分布：虐1 → 虐2 → 虐3 → 爽1(小) → 虐4 → 爽2(大)
禁忌分布：虐1 → 虐2 → 虐3 → 虐4 → 虐5（无爽点，读者流失）
禁忌分布：爽1 → 爽2 → 爽3 → 爽4（无铺垫，爽感疲劳）
```

检查规则：
- 虐点间隔不超过全文的 30%
- 最大爽点必须出现在全文的 70-85% 位置
- 结尾必须有情绪落点
- 情绪对等释放：虐多少补多少，反派结局关联主角

---

## 对话密度检查

| 指标 | 合格标准 | 警戒线 |
|------|----------|--------|
| 对话占全文比 | 45-65% | <30%（太干）或 >75%（太水） |
| 每章对话条数 | 12-18 条/千字 | <8 条（缺交互）或 >25 条（碎片化） |
| 伤人性对话占比 | 35-45%（虐文）/ 20-30%（爽文） | 虐文 <20%（不够痛）/ 爽文 >40%（太压抑） |

---

## 毒点速查

| 毒点 | 标准 |
|------|------|
| 爽文不爽 | 金手指效果必须展示清楚 |
| 压制无目的 | 每次压制必须服务于后续爆发 |
| 反派结局与主角无关 | 反派之死必须因主角行动导致 |
| 女主/女配降智 | 人设正常可写，老套路别写 |
| 读者期待长时间不满足 | 适时满足或引入新期待 |
| 主角行为不可理解 | 必须能理解、能共鸣 |
| 钩子不回收 | 钩子不回收 = 烂尾 |

---

## 期待感管理

期待感公式：情绪 + 情节（人设+动机）+ 信息差，三者缺一则不足。

核心循环：情报 → 收获 → 震惊 → 短平快过渡到下一个有用剧情。

管理规则：
- 两长一短不断：两个大期待之间穿插一个小满足
- 核心卖点贯穿全文，不能中途换赛道
- 每个情报都要有期待价值，关键情报拉起"然后呢？"
