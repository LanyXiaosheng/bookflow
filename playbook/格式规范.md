# 格式规范

番茄短篇的正文交付格式。写作全程执行，不因题材或风格而变。

---

## 段落格式

### 核心规则：一句一段

- 每段 1-3 句，不超 60 字
- 段与段之间不加空行（紧密排列）
- 无缩进（平台渲染器自行处理）
- 一段只做一个动作：叙事/对话/心理/动作，不混合

### 段落节奏

连续的短段落（1-2 句）制造紧张感。偶尔用 3 句的段落作为呼吸点。但绝不出现超过 60 字的大段落。

---

## 对话格式

### 对话标记

| 优先级 | 格式 | 适用平台 |
|--------|------|----------|
| 首选 | `"说话内容"` | 番茄、黑岩、点众（主流） |
| 次选 | `「说话内容」` | 部分古言、日式 |
| 平台指定 | `【说话内容】` | 仅知乎盐言故事 |

默认用 `""`。

### 对话规则

1. 对话独立成行，不嵌在叙述段落中
2. 用动作代替对话标签：不用"他说""她道"，改为动作描写 + 对话
3. 两人对话连续出现时，省略标签，靠内容区分说话人

正确示例：
```
她把杯子放下。
"你走吧。"
他没有动。
"我说，你走吧。"
```

错误示例：
```
她把杯子放下，说道："你走吧。"他没有动，她又说："我说，你走吧。"
```

## 小节（beat）结构

### 基本规则

- 每小节 800-1500 字（爽文可压缩至 500-800 字/节）
- 8-15 个小节覆盖全文（按目标字数反推：10000÷1000≈10 节）
- 每小节推进一个明确的情节点

### 小节内部结构

每个小节应该有：
1. 一个主事件 + 3-5 个子事件
2. 一个情绪变化（读者的感受如何变化）
3. 一条读者新获知的信息
4. 3-5 轮对话交锋（揭示关系/升级冲突）

### 小节之间的衔接

- 小节结尾留一个钩子（悬念/未解决的情绪/新问题）
- 下一节开头快速接续，不要重新铺垫
- 情绪跨节递进：每一节的情绪强度 ≥ 上一节

## 章节标记

| 格式 | 平台适用 | 示例 |
|------|----------|------|
| `###1.` | 黑岩、点众（主流） | `###1.` `###2.` |
| `###第一章` | 番茄 | `###第一章` `###第二章` |
| `1.`（纯数字） | 知乎 | `1.` `2.` `3.` |

全文统一一种格式，不要混用。番茄短篇推荐 `###第一章` 或 `###1.`。

---

## 平台对话格式覆盖表

| 平台 | 章节标记 | 对话格式 | 特殊要求 |
|------|----------|----------|----------|
| 番茄 | `###第一章` | `""` | 首段需有吸引力 |
| 黑岩 | `###1.` | `""` | 无 |
| 点众 | `###1.` | `""` | 无 |
| 知乎盐言 | `1.` | `【】` | 导语需单独标注 |

---

## 5 条绝对禁止

1. **禁止大段落**：超过 60 字的段落必须拆分
2. **禁止段间空行**：段落紧密排列，不留空行
3. **避免对话标签机械化**：高频或公式化的"他说""她道""他笑了笑说"用动作/上下文替代
4. **禁止缩进**：不使用全角空格或半角空格缩进
5. **禁止正文 Markdown 渲染**：除章节标记外，正文不使用加粗、斜体、标题、分隔线等

写完每一段后自查：

- [ ] 每段 ≤ 60 字？
- [ ] 段间无空行？
- [ ] 对话独立成行且用正确引号？
- [ ] 对话标签避免高频/公式化？
- [ ] 无缩进？
- [ ] 每个小节有事件 + 情绪 + 信息？
- [ ] 小节结尾有钩子？
